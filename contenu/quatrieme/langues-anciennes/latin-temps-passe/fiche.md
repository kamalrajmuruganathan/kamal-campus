# Latin : imparfait et parfait de l'indicatif

> Pour raconter le passé, le latin dispose surtout de deux temps : l'imparfait (action qui
> dure ou qui se répète) et le parfait (action achevée, ponctuelle). Apprenons à les former
> avec *amare* et *esse*.

## 1. L'imparfait de l'indicatif
On le forme sur le radical du présent + la caractéristique **-ba-** + les terminaisons.

| Personne | amare (aimer) | esse (être) |
|---|---|---|
| 1re sing. | amabam | eram |
| 2e sing. | amabas | eras |
| 3e sing. | amabat | erat |
| 1re plur. | amabamus | eramus |
| 2e plur. | amabatis | eratis |
| 3e plur. | amabant | erant |

Sens : *amabam* = « j'aimais » (action qui dure ou se répète dans le passé).

## 2. Le parfait de l'indicatif
Il se forme sur un radical spécial, le **radical du parfait** (donné par le dictionnaire),
suivi de terminaisons propres : **-i, -isti, -it, -imus, -istis, -erunt**.

Pour *amare*, le radical du parfait est *amav-* :

| Personne | amare | Traduction |
|---|---|---|
| 1re sing. | amavi | j'ai aimé / j'aimai |
| 2e sing. | amavisti | tu as aimé |
| 3e sing. | amavit | il a aimé |
| 1re plur. | amavimus | nous avons aimé |
| 2e plur. | amavistis | vous avez aimé |
| 3e plur. | amaverunt | ils ont aimé |

Pour *esse*, le radical du parfait est *fu-* : **fui, fuisti, fuit, fuimus, fuistis, fuerunt**.

## 3. Imparfait ou parfait ?
- **Imparfait** : arrière-plan, description, habitude. *Romani templa aedificabant* = « Les
  Romains construisaient des temples » (habituellement).
- **Parfait** : événement achevé qui fait avancer le récit. *Caesar venit* = « César vint / est venu ».

## 4. Les erreurs à éviter
- L'imparfait a toujours le -ba- : ne pas oublier cette syllabe (*amabat*, pas *amat*).
- Le parfait se forme sur son propre radical, souvent différent du présent (amo → amav-,
  sum → fu-, video → vid- → vidi).
- Terminaison de 3e pers. pluriel du parfait : **-erunt** (amaverunt), pas -ant.

## À retenir
- Imparfait = radical du présent + -ba- + terminaisons : amabam, amabas, amabat…
- Imparfait de esse : eram, eras, erat, eramus, eratis, erant.
- Parfait = radical du parfait + -i, -isti, -it, -imus, -istis, -erunt : amavi… ; esse : fui, fuisti, fuit…
- Imparfait = durée/habitude ; parfait = action achevée.
