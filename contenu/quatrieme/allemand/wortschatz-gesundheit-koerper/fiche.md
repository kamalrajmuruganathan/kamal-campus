# Vocabulaire : Gesundheit und Körper

> Nommer les parties du corps (**der Körper**) et parler de sa santé
> (**die Gesundheit**) : dire ce qui fait mal, aller chez le médecin,
> décrire une maladie.

## 1. Les parties du corps

| Allemand | Français |
|---|---|
| der Kopf | la tête |
| das Haar / die Haare | le cheveu / les cheveux |
| das Auge / die Augen | l'œil / les yeux |
| die Nase | le nez |
| der Mund | la bouche |
| das Ohr | l'oreille |
| der Zahn / die Zähne | la dent / les dents |
| der Arm | le bras |
| die Hand | la main |
| das Bein | la jambe |
| der Fuß | le pied |
| der Bauch | le ventre |
| der Rücken | le dos |

## 2. La santé et la maladie

| Allemand | Français |
|---|---|
| die Gesundheit | la santé |
| gesund / krank | en bonne santé / malade |
| der Arzt / die Ärztin | le médecin |
| die Apotheke | la pharmacie |
| das Medikament | le médicament |
| das Fieber | la fièvre |
| die Erkältung | le rhume |
| der Husten | la toux |
| die Kopfschmerzen | les maux de tête |

## 3. Dire que ça fait mal

On utilise **wehtun** (faire mal) : *Der Kopf tut weh.* (La tête fait mal.)
Ou **haben** + douleur : *Ich habe Kopfschmerzen.* (J'ai mal à la tête.)

## 4. Les erreurs à éviter

- « der Arzt » (homme) / « die Ärztin » (femme) : le **-in** marque le féminin.
- « wehtun » se sépare : Der Zahn **tut** weh (le préfixe weh va à la fin).
- Ne pas confondre « gesund » (en bonne santé) et « krank » (malade).
- Les noms de douleur composés finissent en **-schmerzen** : Kopfschmerzen, Bauchschmerzen.

## À retenir

- Le corps : der Kopf, das Auge, die Hand, das Bein, der Fuß.
- La santé : gesund / krank, der Arzt, die Apotheke, das Medikament.
- Dire un symptôme : Ich habe Fieber / Husten / Kopfschmerzen.
- « faire mal » = wehtun : Der Bauch tut weh.
