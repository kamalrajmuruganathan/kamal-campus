# Vocabulaire : Sport und Freizeit

> Parler de ses loisirs (**die Freizeit**) et du sport (**der Sport**), c'est
> pouvoir dire ce que l'on aime faire : *Ich spiele gern Fußball.* On associe ici
> les noms (avec article) et les verbes d'activité.

## 1. Le sport

| Allemand | Français |
|---|---|
| der Sport | le sport |
| der Fußball | le football |
| der Basketball | le basket |
| das Tennis | le tennis |
| das Schwimmen | la natation |
| das Radfahren | le vélo |
| die Mannschaft | l'équipe |
| das Spiel | le match, le jeu |
| das Tor | le but |
| der Verein | le club |
| das Training | l'entraînement |

## 2. Les loisirs

| Allemand | Français |
|---|---|
| die Freizeit | le temps libre |
| das Hobby | le loisir, le hobby |
| die Musik | la musique |
| das Kino | le cinéma |
| das Konzert | le concert |
| die Gitarre | la guitare |
| das Klavier | le piano |
| der Ausflug | l'excursion, la sortie |

## 3. Les verbes d'activité

| Allemand | Français |
|---|---|
| spielen | jouer |
| gewinnen | gagner |
| verlieren | perdre |
| trainieren | s'entraîner |
| tanzen | danser |
| singen | chanter |
| sammeln | collectionner |
| fotografieren | photographier |

Exemple : *In meiner Freizeit spiele ich gern Gitarre.* (Pendant mon temps libre,
j'aime jouer de la guitare.)

## 4. Dire ce que l'on aime : *gern*

Pour dire que l'on aime faire une activité, on ajoute **gern** après le verbe.

| Allemand | Français |
|---|---|
| Ich spiele **gern** Fußball. | J'aime jouer au football. |
| Ich schwimme **gern**. | J'aime nager. |
| Ich tanze nicht **gern**. | Je n'aime pas danser. |

## 5. Les erreurs à éviter

- Pour un sport de balle, on emploie **spielen** : *Fußball spielen*, *Tennis spielen*.
- Pour un instrument aussi : *Gitarre spielen*, *Klavier spielen* (jouer d'un instrument).
- « gern » exprime le goût pour une activité ; il ne se traduit pas par un verbe.
- Tous les noms prennent une **majuscule** : der Sport, das Hobby, die Musik.

## À retenir

- On retient chaque nom **avec son article** : der Sport, das Hobby, die Mannschaft.
- Sports : der Fußball, das Schwimmen, das Radfahren, das Training.
- Verbes clés : spielen, gewinnen, verlieren, trainieren, tanzen, singen.
- Pour dire un goût, on ajoute **gern** : *Ich spiele gern Fußball.*
