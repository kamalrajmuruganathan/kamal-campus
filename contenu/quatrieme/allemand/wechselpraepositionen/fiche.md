# Die Wechselpräpositionen (Akkusativ/Dativ)

> Neuf prépositions allemandes sont « à double cas » : selon le sens de la phrase, elles se construisent tantôt avec l'**accusatif**, tantôt avec le **datif**. La règle est simple et logique : le mouvement vers un lieu appelle l'accusatif, la position dans un lieu appelle le datif.

## 1. Les neuf Wechselpräpositionen

À connaître par cœur : **an, auf, hinter, in, neben, über, unter, vor, zwischen**.

| Préposition | Sens |
|---|---|
| an | à, au bord de, contre |
| auf | sur |
| in | dans, à |
| hinter | derrière |
| vor | devant |
| über | au-dessus de |
| unter | sous |
| neben | à côté de |
| zwischen | entre |

## 2. La règle d'or : Wohin? ou Wo?

| Question | Cas | Idée | Exemple |
|---|---|---|---|
| **Wohin?** (vers où ?) | **Accusatif** | déplacement, direction | Ich lege das Buch **auf den** Tisch. |
| **Wo?** (où ?) | **Datif** | position, endroit fixe | Das Buch liegt **auf dem** Tisch. |

Astuce : s'il y a un **mouvement vers une destination**, c'est l'accusatif ; s'il y a une **localisation stable**, c'est le datif.

| Accusatif (Wohin?) | Datif (Wo?) |
|---|---|
| Ich gehe **in die** Schule. (je vais à l'école) | Ich bin **in der** Schule. (je suis à l'école) |
| Er hängt das Bild **an die** Wand. | Das Bild hängt **an der** Wand. |
| Die Katze läuft **unter das** Bett. | Die Katze schläft **unter dem** Bett. |

## 3. Les paires de verbes typiques

Certains verbes vont avec l'accusatif (action de placer, avec mouvement), d'autres avec le datif (état, position).

| Wohin? + Akkusativ | Wo? + Dativ |
|---|---|
| **stellen** (mettre debout) | **stehen** (être debout) |
| **legen** (coucher, poser à plat) | **liegen** (être couché) |
| **setzen** (asseoir) | **sitzen** (être assis) |
| **hängen** (accrocher) | **hängen** (être accroché) |

Exemples : *Ich **stelle** die Flasche **auf den** Tisch* (acc.) / *Die Flasche **steht auf dem** Tisch* (dat.).

## 4. Les contractions courantes

| Forme longue | Contraction |
|---|---|
| in das | **ins** |
| in dem | **im** |
| an das | **ans** |
| an dem | **am** |
| auf das | **aufs** |

Exemples : *Ich gehe **ins** Kino* (Wohin? acc.) / *Ich bin **im** Kino* (Wo? dat.).

## 5. Les erreurs à éviter
- Choisir le cas « au hasard » : pose-toi toujours la question **Wohin? (acc.)** ou **Wo? (dat.)**.
- Confondre les paires *legen/liegen*, *stellen/stehen*, *setzen/sitzen*.
- Oublier que le datif pluriel prend un **-n** : *zwischen den Häuser**n***.
- Utiliser la mauvaise contraction : *ins* (acc.) ≠ *im* (dat.).

## À retenir
- Les 9 Wechselpräpositionen : **an, auf, hinter, in, neben, über, unter, vor, zwischen**.
- **Wohin? → Accusatif** (mouvement) ; **Wo? → Datif** (position).
- Paires : **stellen/stehen, legen/liegen, setzen/sitzen** (acc./dat.).
- Contractions : **ins/im, ans/am, aufs**.
