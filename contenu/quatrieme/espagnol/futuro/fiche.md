# El futuro : ir a + infinitivo y futuro simple

> L'espagnol a deux façons principales de parler du futur : « ir a + infinitivo » (le futur proche, une intention) et le « futuro simple » (une prévision, une promesse). Ce chapitre explique quand et comment employer chacun.

## 1. Le futur proche : ir a + infinitivo

On conjugue **ir** au présent, puis **a**, puis l'**infinitif**. C'est comme le français « aller + infinitif ». On l'emploie pour une intention ou un futur immédiat.

| ir | Exemple | Traduction |
|---|---|---|
| voy | **Voy a** estudiar. | Je vais étudier. |
| vas | **Vas a** comer. | Tu vas manger. |
| va | **Va a** salir. | Il va sortir. |
| vamos | **Vamos a** viajar. | Nous allons voyager. |
| vais | **Vais a** jugar. | Vous allez jouer. |
| van | **Van a** llegar. | Ils vont arriver. |

Marqueurs : **ahora, esta tarde, mañana, este fin de semana**.

## 2. Le futuro simple : formation

On ajoute les terminaisons **directement à l'infinitif** (pour tous les groupes : -ar, -er, -ir). Toutes les personnes portent un accent écrit, sauf « nosotros ».

| Personne | Terminaison | hablar | comer | vivir |
|---|---|---|---|---|
| yo | **-é** | hablar**é** | comer**é** | vivir**é** |
| tú | **-ás** | hablar**ás** | comer**ás** | vivir**ás** |
| él/ella | **-á** | hablar**á** | comer**á** | vivir**á** |
| nosotros | **-emos** | hablar**emos** | comer**emos** | vivir**emos** |
| vosotros | **-éis** | hablar**éis** | comer**éis** | vivir**éis** |
| ellos/ellas | **-án** | hablar**án** | comer**án** | vivir**án** |

## 3. Les futurs irréguliers

Quelques verbes très fréquents changent de **racine** au futuro simple, mais gardent les **mêmes terminaisons**.

| Infinitif | Racine | Exemple |
|---|---|---|
| tener | tendr- | tendré, tendrás… |
| hacer | har- | haré, harás… |
| poder | podr- | podré, podrás… |
| poner | pondr- | pondré… |
| salir | saldr- | saldré… |
| venir | vendr- | vendré… |
| decir | dir- | diré… |
| querer | querr- | querré… |
| saber | sabr- | sabré… |

Marqueurs : **mañana, pasado mañana, la semana que viene, el año que viene, algún día**.

## 4. Les erreurs à éviter
- Ne pas oublier le **a** dans « ir a + infinitif » : « voy a comer » (et non « voy comer »).
- Le futuro simple s'ajoute à l'**infinitif entier** : hablar**é** (et non « hablé », qui est l'indefinido !).
- Ne pas oublier les accents : hablar**é**, hablar**ás**, hablar**á** (sauf hablaremos).
- Ne pas régulariser les irréguliers : « teneré » est faux → **tendré**.

## À retenir
- Futur proche : **ir (au présent) + a + infinitif** (voy a estudiar).
- Futuro simple : **infinitif + é, ás, á, emos, éis, án** (hablaré, comeré, viviré).
- Accents partout sauf à « nosotros » (-emos).
- Irréguliers de racine : tendré, haré, podré, pondré, saldré, vendré, diré, querré, sabré.
