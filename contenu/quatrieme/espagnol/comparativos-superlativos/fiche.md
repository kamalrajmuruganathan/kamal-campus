# Comparativos y superlativos

> Pour comparer deux choses (plus grand, moins cher, aussi rapide) ou pour dire qu'une chose est la meilleure de toutes, l'espagnol a des structures simples et régulières. Ce chapitre les met en place une par une.

## 1. Le comparatif

On compare avec trois structures selon le sens.

| Sens | Structure | Exemple | Traduction |
|---|---|---|---|
| Supériorité | **más** … **que** | Ana es **más** alta **que** Luis. | Ana est plus grande que Luis. |
| Infériorité | **menos** … **que** | Este libro es **menos** caro **que** ese. | Ce livre est moins cher que celui-là. |
| Égalité (adjectif) | **tan** … **como** | Soy **tan** rápido **como** tú. | Je suis aussi rapide que toi. |
| Égalité (nom) | **tanto/a/os/as** … **como** | Tengo **tantos** libros **como** tú. | J'ai autant de livres que toi. |

Avec un nom, **tanto** s'accorde : tanto dinero, tanta agua, tantos libros, tantas casas.

## 2. Les comparatifs irréguliers

Quatre adjectifs ont un comparatif irrégulier (on ne dit pas « más bueno »).

| Adjectif | Comparatif | Exemple |
|---|---|---|
| bueno (bon) | **mejor** (meilleur) | Este método es **mejor**. |
| malo (mauvais) | **peor** (pire) | Su nota es **peor** que la mía. |
| grande (âge : grand) | **mayor** (plus âgé) | Mi hermano es **mayor** que yo. |
| pequeño (âge : petit) | **menor** (plus jeune) | Soy **menor** que mi primo. |

## 3. Le superlatif

Le **superlatif relatif** exprime le degré le plus haut d'un groupe : **el / la / los / las + más (ou menos) + adjectif + de**.

- Es **la** chica **más** inteligente **de** la clase. → C'est la fille la plus intelligente de la classe.
- Son **los** más **rápidos del** equipo. → Ce sont les plus rapides de l'équipe.

Le **superlatif absolu** exprime un très haut degré, sans comparaison : on ajoute **-ísimo/a** à l'adjectif (ou on met **muy** devant).

| Adjectif | Superlatif absolu |
|---|---|
| guapo | guap**ísimo** (= muy guapo) |
| fácil | facil**ísimo** |
| rico | ri**quísimo** (c → qu) |
| largo | lar**guísimo** (g → gu) |

## 4. Les erreurs à éviter
- Ne pas dire « más bueno / más malo » : on emploie **mejor / peor**.
- Pour l'âge, on utilise **mayor / menor**, pas « más grande / más pequeño » (qui parlent de taille).
- Ne pas oublier l'accord de **tanto** avec le nom : tant**as** casas.
- Ne pas oublier le **de** dans le superlatif : « el más alto **de** la clase » (et non « en la clase »).

## À retenir
- Supériorité : **más … que** ; infériorité : **menos … que** ; égalité : **tan … como** (adj) / **tanto … como** (nom).
- Irréguliers : mejor, peor, mayor, menor.
- Superlatif relatif : **el/la más … de**.
- Superlatif absolu : adjectif + **-ísimo** ou **muy** + adjectif.
