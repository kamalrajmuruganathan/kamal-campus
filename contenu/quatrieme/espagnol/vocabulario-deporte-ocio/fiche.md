# Vocabulaire : el deporte y el ocio

> Ce chapitre présente le vocabulaire du sport et des loisirs en espagnol : les sports, les activités de temps libre, les lieux et les expressions pour dire ce qu'on aime faire. Idéal pour parler de tes passe-temps.

## 1. Los deportes (les sports)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| el fútbol | le football | el baloncesto | le basket |
| el tenis | le tennis | la natación | la natation |
| el ciclismo | le cyclisme | el atletismo | l'athlétisme |
| el balonmano | le handball | el voleibol | le volley |
| la equitación | l'équitation | el esquí | le ski |

On emploie **jugar a** pour les sports de ballon : *jugar al fútbol, jugar al tenis*. Pour les autres : **hacer** (*hacer natación, hacer ciclismo*) ou **practicar**.

## 2. Las actividades de ocio (les loisirs)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| leer | lire | escuchar música | écouter de la musique |
| ver la tele | regarder la télé | jugar a videojuegos | jouer aux jeux vidéo |
| ir de compras | faire les magasins | salir con amigos | sortir avec des amis |
| bailar | danser | cantar | chanter |
| dibujar | dessiner | tocar la guitarra | jouer de la guitare |
| pasear | se promener | viajar | voyager |

## 3. Lugares y material (lieux et matériel)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| el polideportivo | le gymnase / complexe sportif | el estadio | le stade |
| la piscina | la piscine | el gimnasio | la salle de sport |
| el equipo | l'équipe | el partido | le match |
| la pelota / el balón | la balle / le ballon | el jugador | le joueur |
| ganar | gagner | perder | perdre |

## 4. Exprimer ses goûts et son temps libre
Avec **gustar** : *Me gusta el fútbol* (j'aime le foot) ; *Me gustan los videojuegos* (au pluriel : gustan). *Me encanta bailar* (j'adore danser). Le temps libre = **el tiempo libre** ; un passe-temps = **una afición / un pasatiempo**. Exemple : *En mi tiempo libre juego al baloncesto y toco la guitarra.*

## 5. Les erreurs à éviter
- On dit **jugar AL fútbol** (jugar a + article), pas *jugar fútbol*.
- **Me gusta** + singulier/infinitif ; **Me gustan** + nom pluriel.
- **hacer deporte** (faire du sport) : ne pas dire *hacer el deporte*.
- **el partido** = le match ; ne pas confondre avec *la parte* (la partie).

## À retenir
- Sports de ballon : **jugar a** ; autres sports : **hacer / practicar**.
- Loisirs : **leer, ver la tele, escuchar música, salir con amigos**.
- Goûts : **me gusta / me gustan / me encanta**.
- Gagner / perdre : **ganar / perder** ; le match : **el partido**.
