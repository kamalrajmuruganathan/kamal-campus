# Vocabulaire : la santé et le corps

> Décrire son corps, expliquer ce dont on souffre et comprendre un médecin sont des
> compétences utiles en voyage comme au quotidien. Ce chapitre rassemble le lexique
> du corps humain, des maladies et des soins.

## 1. Les parties du corps

| Anglais | Français |
|---|---|
| the head | la tête |
| the arm | le bras |
| the hand | la main |
| the leg | la jambe |
| the foot (feet) | le pied (les pieds) |
| the back | le dos |
| the stomach | le ventre, l'estomac |
| the throat | la gorge |

Exemple : *My leg hurts.* → J'ai mal à la jambe.

## 2. Parler d'une douleur ou d'une maladie

| Anglais | Français |
|---|---|
| a headache | un mal de tête |
| a stomachache | un mal de ventre |
| a sore throat | un mal de gorge |
| a cold | un rhume |
| a temperature / a fever | de la fièvre |
| to be ill / to be sick | être malade |
| to hurt | faire mal |
| pain | la douleur |

Exemple : *I have got a sore throat.* → J'ai mal à la gorge.

## 3. Les soins et le médecin

| Anglais | Français |
|---|---|
| a doctor | un médecin |
| a nurse | un infirmier, une infirmière |
| medicine | un médicament |
| a pill / a tablet | un comprimé |
| a chemist's | une pharmacie |
| to rest | se reposer |
| Get well soon! | Bon rétablissement ! |
| to take medicine | prendre un médicament |

Exemple : *You should rest and take some medicine.* → Tu devrais te reposer et prendre un médicament.

## 4. Les erreurs à éviter

- Pour dire « j'ai mal à… », l'anglais utilise souvent **have got a + -ache**
  (*headache*, *stomachache*, *toothache*) ou **my … hurts**.
- « medicine » (médicament) est différent de « a medicine cabinet » ; ne le confonds
  pas avec « médecine » comme étude, qui se dit aussi *medicine* mais indénombrable.
- « to be sick » signifie « être malade » (britannique) mais aussi « vomir » ; le
  contexte lève l'ambiguïté.
- Le pluriel de « foot » est **feet** (irrégulier), et celui de « tooth » est **teeth**.

## À retenir

- Le corps : *head*, *arm*, *hand*, *leg*, *foot / feet*, *back*, *throat*.
- Les maux : *a headache*, *a sore throat*, *a cold*, *a temperature*.
- Dire qu'on a mal : *My … hurts.* / *I have got a …ache.*
- Les soins : *doctor*, *nurse*, *medicine*, *chemist's*, *to rest*.
- Pluriels irréguliers : *foot → feet*, *tooth → teeth*.
