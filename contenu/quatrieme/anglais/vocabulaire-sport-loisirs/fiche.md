# Vocabulaire : le sport et les loisirs

> Parler de ses activités préférées, de son sport ou de son temps libre est
> incontournable pour se présenter et échanger. Ce lexique t'apprend aussi le
> point délicat des trois verbes *play*, *go* et *do* devant un sport.

## 1. Les sports

| Anglais | Français |
|---|---|
| football | le football |
| basketball | le basket |
| tennis | le tennis |
| swimming | la natation |
| running | la course à pied |
| cycling | le vélo, le cyclisme |
| rugby | le rugby |
| skiing | le ski |
| athletics | l'athlétisme |
| horse riding | l'équitation |

Exemple : *My favourite sport is swimming.* → Mon sport préféré est la natation.

## 2. Play, go ou do ?

Le choix du verbe dépend du type de sport.

| Verbe | Emploi | Exemple |
|---|---|---|
| **play** | sports d'équipe et de ballon/raquette | play football, play tennis |
| **go** | sports en -ing (activités) | go swimming, go running, go skiing |
| **do** | sports individuels / arts martiaux | do judo, do athletics, do yoga |

Exemple : *I play basketball and I go swimming.* → Je joue au basket et je fais de la natation.

## 3. Le vocabulaire du match

| Anglais | Français |
|---|---|
| a team | une équipe |
| a match / a game | un match |
| a player | un joueur |
| a coach | un entraîneur |
| a referee | un arbitre |
| to win | gagner |
| to lose | perdre |
| to score | marquer (un but, un point) |
| a stadium | un stade |

Exemple : *Our team won the match 2–0.* → Notre équipe a gagné le match 2–0.

## 4. Les loisirs et le temps libre

| Anglais | Français |
|---|---|
| a hobby | un loisir, un passe-temps |
| free time | le temps libre |
| reading | la lecture |
| drawing | le dessin |
| dancing | la danse |
| singing | le chant |
| photography | la photographie |
| video games | les jeux vidéo |
| to be good at | être bon en / doué pour |

Exemple : *In my free time, I like reading.* → Pendant mon temps libre, j'aime lire.

## 5. Les erreurs à éviter

- On dit **play football** (sans *the*), pas *play the football*. En revanche, pour un
  instrument : *play the piano* (avec *the*).
- Après *to be good at*, le verbe se met en **-ing** : *I'm good at swimming*.
- Ne confonds pas *win* (gagner un match) et *earn* (gagner de l'argent).
- « sport » se dit *a sport* au singulier ; « faire du sport » se dit *to do sport* /
  *to play sport*.

## À retenir

- **play** + sports de ballon/équipe ; **go** + sports en -ing ; **do** + individuels.
- Le match : *team*, *player*, *coach*, *referee*, *win*, *lose*, *score*.
- Loisirs : *reading*, *drawing*, *dancing*, *photography*, *video games*.
- *to be good at* + verbe en **-ing**.
- *play football* (sans *the*), mais *play the piano* (avec *the*).
