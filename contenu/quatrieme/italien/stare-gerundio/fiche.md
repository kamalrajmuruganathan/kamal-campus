# Stare + gerundio

> Pour insister sur une action **en train de se dérouler**, l'italien utilise *stare* + gérondif. C'est l'équivalent du français « être en train de… ».

## 1. La formation
On conjugue le verbe **stare** au présent, puis on ajoute le **gérondif** du verbe.

| Personne | stare |
|---|---|
| io | sto |
| tu | stai |
| lui/lei | sta |
| noi | stiamo |
| voi | state |
| loro | stanno |

Le **gérondif** se forme sur le radical :

| Infinitif | Terminaison | Gérondif |
|---|---|---|
| parl**are** | -ando | parl**ando** |
| scriv**ere** | -endo | scriv**endo** |
| dorm**ire** | -endo | dorm**endo** |

Exemple : *Sto studiando.* (Je suis en train d'étudier) — *Stanno mangiando.* (Ils sont en train de manger).

## 2. L'emploi
On l'utilise pour une action en cours au moment où l'on parle. On peut aussi l'employer à l'imperfetto pour une action en cours dans le passé : *Stavo dormendo quando hai telefonato.* (Je dormais quand tu as téléphoné.)

## 3. Les gérondifs irréguliers
*fare → facendo, dire → dicendo, bere → bevendo.*

## 4. Les erreurs à éviter
- Confondre le gérondif italien avec le participe présent : on ne dit pas *sto studiante*, mais *sto studiando*.
- Utiliser *essere* au lieu de *stare* : ❌ *sono mangiando* → ✅ *sto mangiando*.
- Oublier que les verbes en -ere ET -ire prennent tous les deux **-endo**.

## À retenir
- Stare (au présent) + gérondif = action en cours.
- Gérondif : -are → -ando ; -ere / -ire → -endo.
- Irréguliers : facendo, dicendo, bevendo.
