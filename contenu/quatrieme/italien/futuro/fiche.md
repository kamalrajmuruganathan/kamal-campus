# Il futuro semplice

> Le *futuro semplice* exprime une action à venir, une prévision ou une hypothèse. Attention : les verbes en -are changent leur -a- en -e- au futur.

## 1. La formation
| Personne | -are (parlare) | -ere (credere) | -ire (dormire) |
|---|---|---|---|
| io | parl**erò** | cred**erò** | dorm**irò** |
| tu | parl**erai** | cred**erai** | dorm**irai** |
| lui/lei | parl**erà** | cred**erà** | dorm**irà** |
| noi | parl**eremo** | cred**eremo** | dorm**iremo** |
| voi | parl**erete** | cred**erete** | dorm**irete** |
| loro | parl**eranno** | cred**eranno** | dorm**iranno** |

Remarque : *parlare* devient *parl**erò*** (le -a- devient -e-), comme les verbes en -ere.

## 2. Les particularités orthographiques
- Verbes en **-care / -gare** : on ajoute un **h** pour garder le son dur → *cercare → cerc**herò***, *pagare → pag**herò***.
- Verbes en **-ciare / -giare** : on **perd le -i-** → *cominciare → cominc**erò***, *mangiare → mang**erò***.

## 3. Les verbes irréguliers fréquents
| Verbe | Futur (io) |
|---|---|
| essere | **sarò** |
| avere | **avrò** |
| fare | **farò** |
| andare | **andrò** |
| venire | **verrò** |
| dovere | **dovrò** |
| potere | **potrò** |
| volere | **vorrò** |

## 4. Les erreurs à éviter
- Garder le -a- des verbes en -are : ❌ *parlarò* → ✅ *parlerò*.
- Oublier le -h- de *cercherò, pagherò*.
- Oublier les doubles consonnes des irréguliers : *verrò, vorrò* (deux r).

## À retenir
- Futur = radical + -erò/-erai… (les -are deviennent -erò).
- -care/-gare → +h ; -ciare/-giare → on perd le -i-.
- Irréguliers clés : sarò, avrò, farò, andrò, verrò, dovrò, potrò, vorrò.
