# Vocabulaire : la tecnología y las redes sociales

> Ce chapitre réunit le vocabulaire de la technologie, d'Internet et des réseaux sociaux en espagnol : les appareils, les actions en ligne et les mots pour donner son avis sur les écrans. Un lexique indispensable pour parler du monde numérique.

## 1. Los aparatos (les appareils)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| el ordenador | l'ordinateur | el portátil | l'ordinateur portable |
| el móvil / el teléfono | le portable / le téléphone | la tableta | la tablette |
| la pantalla | l'écran | el teclado | le clavier |
| el ratón | la souris | los auriculares | les écouteurs |
| la cámara | l'appareil photo / la caméra | el cargador | le chargeur |

En Amérique latine on dit souvent **la computadora** (l'ordinateur) et **el celular** (le portable).

## 2. Internet y las acciones (Internet et les actions)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| la red | le réseau | la contraseña | le mot de passe |
| navegar | naviguer | descargar | télécharger |
| subir | mettre en ligne / téléverser | buscar | chercher |
| enviar un mensaje | envoyer un message | chatear | tchatter |
| conectarse | se connecter | apagar / encender | éteindre / allumer |
| el correo electrónico | l'e-mail | el enlace | le lien |

## 3. Las redes sociales (les réseaux sociaux)

| Espagnol | Français | Espagnol | Français |
|---|---|---|---|
| la red social | le réseau social | el usuario | l'utilisateur / le pseudo |
| la publicación / el post | la publication | compartir | partager |
| seguir a alguien | suivre quelqu'un | el seguidor | l'abonné |
| dar «me gusta» | mettre un like | el comentario | le commentaire |
| la aplicación / la app | l'application | subir una foto | poster une photo |

## 4. Donner son avis sur la technologie
Verbes d'opinion : **creo que**, **pienso que**, **me parece que** + phrase. Utile : *En mi opinión* (à mon avis), *por un lado... por otro lado* (d'un côté... de l'autre). Exemples : *Creo que las redes sociales son útiles pero peligrosas.* — *Paso demasiado tiempo delante de la pantalla.* (Je passe trop de temps devant l'écran.)

## 5. Les erreurs à éviter
- **el ordenador** (Espagne) = **la computadora** (Amérique latine) : les deux existent.
- **el móvil** (Espagne) = **el celular** (Amérique latine).
- **la red** = le réseau (Internet) ; **la red social** = le réseau social.
- Attention à l'accent : **la aplicación**, **la conexión**, **el móvil**.

## À retenir
- Appareils : **el ordenador/portátil, el móvil, la tableta, la pantalla**.
- Actions : **navegar, descargar, subir, enviar, conectarse, compartir**.
- Réseaux sociaux : **la red social, seguir, el seguidor, dar «me gusta»**.
- Opinion : **creo que / pienso que / me parece que** + phrase.
