# Por y para

> Les deux se traduisent souvent par « pour » en français, et c'est justement le piège. **Por** regarde vers la **cause**, l'origine, le moyen ; **para** regarde vers le **but**, la destination, le destinataire.

## 1. Les emplois de *para* (but, destination)
On utilise **para** pour exprimer :

| Valeur | Exemple | Traduction |
|---|---|---|
| But / objectif | Estudio **para** aprobar. | J'étudie pour réussir. |
| Destinataire | Este regalo es **para** ti. | Ce cadeau est pour toi. |
| Destination | Salgo **para** Madrid. | Je pars pour Madrid. |
| Échéance | Es **para** el lunes. | C'est pour lundi. |
| Opinion | **Para** mí, es fácil. | Pour moi, c'est facile. |

Astuce : *para* + infinitif = « pour (faire) », un but.

## 2. Les emplois de *por* (cause, moyen, échange)
On utilise **por** pour exprimer :

| Valeur | Exemple | Traduction |
|---|---|---|
| Cause / motif | Lo hago **por** ti. | Je le fais pour toi (à cause de toi). |
| Lieu de passage | Paseo **por** el parque. | Je me promène dans le parc. |
| Durée | Estudié **por** dos horas. | J'ai étudié pendant deux heures. |
| Moyen | Hablo **por** teléfono. | Je parle au téléphone. |
| Échange / prix | Lo compré **por** diez euros. | Je l'ai acheté pour dix euros. |

## 3. Comparer les deux
Le sens change complètement selon la préposition.

| Avec *para* (but) | Avec *por* (cause/moyen) |
|---|---|
| Trabajo **para** ganar dinero. (dans le but de) | Trabajo **por** dinero. (motivé par) |
| Lo hago **para** ti. (à ton intention) | Lo hago **por** ti. (à cause de toi) |

## 4. Expressions figées avec *por*
À connaître par cœur : *por favor* (s'il vous plaît), *por eso* (c'est pourquoi), *por qué* (pourquoi), *por fin* (enfin), *por supuesto* (bien sûr), *por ejemplo* (par exemple).

## 5. Les erreurs à éviter
- « pour » ne se traduit pas toujours par *para* : la cause, c'est *por*.
- Le but avec infinitif = **para** : *para aprender*, jamais ~~por aprender~~ (sauf sens de cause).
- La durée et le lieu de passage = **por** : *por dos horas, por la calle*.
- *¿Por qué?* (pourquoi, question) s'écrit en deux mots ; *porque* (parce que) en un seul.

## À retenir
- **Para** = but, destination, destinataire, échéance, opinion.
- **Por** = cause, moyen, lieu de passage, durée, échange/prix.
- Test rapide : but à atteindre → *para* ; motif/cause → *por*.
- Expressions figées avec *por* : *por favor, por eso, por fin, por supuesto*.
