# Vocabulaire : la technologie et internet

> Les nouvelles technologies sont partout : ordinateurs, smartphones, réseaux
> sociaux. Ce lexique te permet de décrire tes usages du numérique, de comprendre
> un article sur internet et d'aborder les questions de sécurité en ligne.

## 1. Les appareils

| Anglais | Français |
|---|---|
| a computer | un ordinateur |
| a laptop | un ordinateur portable |
| a smartphone | un smartphone |
| a tablet | une tablette |
| a screen | un écran |
| a keyboard | un clavier |
| a mouse | une souris |
| a charger | un chargeur |
| headphones | un casque, des écouteurs |

Exemple : *I do my homework on my laptop.* → Je fais mes devoirs sur mon ordinateur portable.

## 2. Internet et le web

| Anglais | Français |
|---|---|
| a website | un site web |
| a web page | une page web |
| a browser | un navigateur |
| a search engine | un moteur de recherche |
| a link | un lien |
| a password | un mot de passe |
| an account | un compte |
| to download | télécharger (vers soi) |
| to upload | mettre en ligne (envoyer) |
| to click | cliquer |

Exemple : *Click on the link to open the website.* → Clique sur le lien pour ouvrir le site.

## 3. Les réseaux sociaux et les actions

| Anglais | Français |
|---|---|
| a social network | un réseau social |
| an app | une application |
| to post | publier |
| to share | partager |
| to follow | suivre (un compte) |
| a follower | un abonné |
| to like | aimer (un contenu) |
| to log in | se connecter |
| to log out | se déconnecter |
| to update | mettre à jour |

Exemple : *She posts a photo and her followers like it.* → Elle publie une photo et ses abonnés l'aiment.

## 4. La sécurité en ligne

| Anglais | Français |
|---|---|
| online | en ligne |
| offline | hors ligne |
| a file | un fichier |
| data | les données |
| a virus | un virus |
| a hacker | un pirate informatique |
| a scam | une arnaque |
| fake news | les fausses informations |

Exemple : *Never share your password online.* → Ne partage jamais ton mot de passe en ligne.

## 5. Les erreurs à éviter

- **download** (télécharger vers son appareil) ≠ **upload** (envoyer vers le réseau).
- « data » est souvent employé comme **indénombrable** : *the data is…*, pas *datas*.
- Ne confonds pas *to log in* (se connecter) et *to sign up* (créer un compte).
- « a mouse » (une souris d'ordinateur) a le même mot que l'animal ; au pluriel
  informatique on trouve *mouses* ou *mice* selon les sources — préfère *mice*.
- « an app » est l'abréviation courante de *an application*.

## À retenir

- Appareils : *computer*, *laptop*, *smartphone*, *tablet*, *screen*, *keyboard*.
- Web : *website*, *browser*, *search engine*, *link*, *password*, *account*.
- Actions : *to download / upload*, *to click*, *to post*, *to share*, *to log in / out*.
- Réseaux : *social network*, *app*, *follower*, *to follow*, *to like*.
- Sécurité : *online / offline*, *virus*, *hacker*, *scam*, *fake news*.
