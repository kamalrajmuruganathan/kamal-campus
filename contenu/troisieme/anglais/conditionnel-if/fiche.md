# Le conditionnel : les phrases en *if* (types 0, 1, 2)

> Les phrases en *if* relient une condition et sa conséquence. Selon que la situation est toujours vraie, possible dans le futur ou irréelle, on change de type et donc de temps.

## 1. Type 0 : la condition toujours vraie
On l'emploie pour des vérités générales, des lois, des habitudes.

**if + présent simple, présent simple**

| Exemple | Traduction |
|---|---|
| If you **heat** ice, it **melts**. | Si on chauffe la glace, elle fond. |
| If I **am** tired, I **go** to bed. | Si je suis fatigué, je vais me coucher. |

## 2. Type 1 : la condition possible (futur réel)
On l'emploie pour une condition réalisable dans le futur.

**if + présent simple, will + base verbale**

| Exemple | Traduction |
|---|---|
| If it **rains**, we **will stay** at home. | S'il pleut, nous resterons à la maison. |
| If you **study**, you **will pass** the exam. | Si tu travailles, tu réussiras l'examen. |

Attention : après **if**, on ne met **jamais** *will* : *If it **rains**…*, pas *If it will rain…*.

## 3. Type 2 : la condition irréelle ou improbable
On l'emploie pour une situation imaginaire, contraire à la réalité présente.

**if + prétérit, would + base verbale**

| Exemple | Traduction |
|---|---|
| If I **had** more money, I **would travel**. | Si j'avais plus d'argent, je voyagerais. |
| If I **were** you, I **would apologize**. | Si j'étais toi, je m'excuserais. |

Avec le type 2, le verbe *be* devient souvent **were** à toutes les personnes : *If I **were** rich…*

## 4. Les erreurs à éviter
- Ne jamais mettre *will* ou *would* après **if** : *If I **have** time* / *If I **had** time*.
- Type 1 : présent après *if*, *will* dans la conséquence — ne pas inverser.
- Type 2 : prétérit après *if*, *would* dans la conséquence.
- « If I was » est toléré à l'oral, mais on écrit **If I were** you.

## À retenir
- **Type 0** (vérité générale) : if + présent, présent.
- **Type 1** (futur possible) : if + présent, **will** + base verbale.
- **Type 2** (irréel présent) : if + prétérit, **would** + base verbale.
- Jamais *will* ni *would* juste après **if**.
