# Vocabulaire : Technik und Internet

> La technique (**die Technik**) et Internet (**das Internet**) font partie du
> quotidien des adolescents. Ce lexique permet de parler d'un ordinateur, d'un
> smartphone et des usages en ligne. On retient chaque nom **avec son article**.

## 1. Les appareils

| Allemand | Français |
|---|---|
| der Computer | l'ordinateur |
| der Laptop | l'ordinateur portable |
| das Handy | le téléphone portable |
| das Smartphone | le smartphone |
| das Tablet | la tablette |
| der Bildschirm | l'écran |
| die Tastatur | le clavier |
| der Drucker | l'imprimante |

Attention : **das Handy** est un « faux ami » — c'est le mot allemand courant pour
le téléphone portable, pas « handy » au sens anglais.

## 2. Internet et le vocabulaire en ligne

| Allemand | Français |
|---|---|
| das Internet | Internet |
| die Webseite | le site web |
| die E-Mail | le courriel, l'e-mail |
| die Nachricht | le message |
| das Netzwerk | le réseau |
| das Passwort | le mot de passe |
| das Konto | le compte |
| die Datei | le fichier |
| die Suchmaschine | le moteur de recherche |

## 3. Les verbes du numérique

| Allemand | Français |
|---|---|
| surfen | surfer |
| klicken | cliquer |
| herunterladen | télécharger |
| hochladen | mettre en ligne, téléverser |
| speichern | enregistrer, sauvegarder |
| löschen | supprimer |
| teilen | partager |
| suchen | chercher |

Exemple : *Ich speichere die Datei und teile sie online.* (J'enregistre le fichier
et je le partage en ligne.)

## 4. Mots utiles

| Allemand | Français |
|---|---|
| online | en ligne |
| offline | hors ligne |
| die Daten | les données |
| der Datenschutz | la protection des données |

## 5. Les erreurs à éviter

- « das Handy » = le portable (et non « pratique ») : c'est un faux ami de l'anglais.
- « herunterladen » et « hochladen » sont des verbes **à particule séparable** :
  *Ich lade das Bild herunter.* (Je télécharge l'image.)
- « speichern » = sauvegarder ; ne pas confondre avec « löschen » = supprimer.
- Tous les noms prennent une **majuscule** : das Internet, die Webseite, das Passwort.

## À retenir

- On retient chaque nom **avec son article** : der Computer, das Handy, die Webseite.
- Appareils : der Laptop, das Tablet, der Bildschirm, die Tastatur.
- En ligne : die E-Mail, das Passwort, das Konto, die Suchmaschine.
- Verbes clés : klicken, herunterladen, speichern, löschen, teilen.
