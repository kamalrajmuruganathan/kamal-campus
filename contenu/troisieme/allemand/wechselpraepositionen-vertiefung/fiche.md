# Wechselpräpositionen : Vertiefung

> Les neuf *Wechselpräpositionen* changent de cas selon le sens : **Akkusativ** quand il y a un déplacement vers un but (*wohin?*), **Dativ** quand on décrit une position sans mouvement (*wo?*). Cette fiche approfondit les couples de verbes (*stellen/stehen*…), les contractions (*im, ans*…) et les pièges les plus fréquents.

## 1. Les neuf prépositions et la règle *wo?* / *wohin?*

**an, auf, hinter, in, neben, über, unter, vor, zwischen.**

| Question | Cas | Idée | Exemple |
|---|---|---|---|
| **wohin?** (où… vers ?) | **Akkusativ** | mouvement, direction | Ich lege das Buch **auf den** Tisch. |
| **wo?** (où ?) | **Dativ** | position, lieu fixe | Das Buch liegt **auf dem** Tisch. |

Le test : si je peux poser *wohin?* → Akkusativ ; si je pose *wo?* → Dativ.

## 2. Les couples de verbes position / déplacement

Certains verbes vont presque toujours avec l'un des deux cas.

| Déplacement (Akkusativ, wohin?) | Position (Dativ, wo?) | Sens |
|---|---|---|
| **stellen** (poser debout) | **stehen** (être debout) | mettre / se tenir |
| **legen** (poser à plat) | **liegen** (être couché) | poser / être posé |
| **setzen** (asseoir) | **sitzen** (être assis) | asseoir / être assis |
| **hängen** (accrocher, faible) | **hängen** (pendre, fort) | accrocher / pendre |

| Akkusativ (wohin?) | Dativ (wo?) |
|---|---|
| Ich **stelle** die Flasche **in den** Kühlschrank. | Die Flasche **steht in dem** Kühlschrank. |
| Er **legt** das Heft **auf den** Tisch. | Das Heft **liegt auf dem** Tisch. |
| Sie **hängt** das Bild **an die** Wand. | Das Bild **hängt an der** Wand. |

## 3. Les contractions à connaître

On fusionne souvent la préposition et l'article.

| Cas | Contraction | Détail |
|---|---|---|
| Dativ | **am** = an + dem | Wo? Am Fenster. |
| Dativ | **im** = in + dem | Wo? Im Zimmer. |
| Akkusativ | **ans** = an + das | Wohin? Ans Fenster. |
| Akkusativ | **ins** = in + das | Wohin? Ins Zimmer. |

Exemples : *Wir gehen **ins** Kino* (wohin ? Akkusativ). *Wir sind **im** Kino* (wo ? Dativ).

## 4. Pièges de la déclinaison

Après le choix du cas, on décline correctement l'article :

| | Akkusativ (wohin?) | Dativ (wo?) |
|---|---|---|
| der (masc.) | in **den** Garten | in **dem** Garten |
| die (fém.) | an **die** Wand | an **der** Wand |
| das (neutre) | auf **das** Dach | auf **dem** Dach |
| pluriel | zwischen **die** Bäume | zwischen **den** Bäumen (+ -n) |

Attention au datif pluriel : le nom prend souvent un **-n** (*zwischen den Bäumen*, *unter den Kindern*).

## 5. Les erreurs à éviter
- Choisir le cas d'après le verbe seulement : c'est le **sens** (mouvement vers un but ou non) qui décide, pas l'action en elle-même. *Ich laufe **im** Park* (je cours **dans** le parc, wo?) → Dativ, même s'il y a du mouvement, car il n'y a pas de but à atteindre.
- Confondre *stellen/legen/setzen* (Akkusativ) et *stehen/liegen/sitzen* (Dativ).
- Oublier le **-n** du datif pluriel : *zwischen den Häuser**n***.
- Employer une contraction Dativ à la place d'une Akkusativ : *Ich gehe **ins** Kino* (Akk.), pas *im Kino*.

## À retenir
- 9 Wechselpräpositionen : **an, auf, hinter, in, neben, über, unter, vor, zwischen**.
- **wohin?** (déplacement vers un but) → **Akkusativ** ; **wo?** (position) → **Dativ**.
- Couples : **stellen/legen/setzen + Akk.** vs **stehen/liegen/sitzen + Dat.**
- Contractions : *am, im* (Dat.) ; *ans, ins* (Akk.).
- Datif pluriel : le nom prend un **-n** (*zwischen den Bäumen*).
