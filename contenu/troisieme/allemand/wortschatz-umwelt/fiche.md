# Vocabulaire : die Umwelt

> L'environnement (**die Umwelt**) est un thème central en 3e : parler du climat,
> des déchets, du recyclage et des gestes pour protéger la nature (**die Natur**).

## 1. La nature et l'environnement

| Allemand | Français |
|---|---|
| die Umwelt | l'environnement |
| die Natur | la nature |
| die Luft | l'air |
| das Wasser | l'eau |
| der Wald | la forêt |
| der Baum | l'arbre |
| die Pflanze | la plante |
| das Tier | l'animal |
| das Meer | la mer |

## 2. Les problèmes et les solutions

| Allemand | Français |
|---|---|
| der Klimawandel | le changement climatique |
| die Verschmutzung | la pollution |
| der Müll / der Abfall | les déchets |
| das Recycling / recyceln | le recyclage / recycler |
| die Energie | l'énergie |
| erneuerbar | renouvelable |
| nachhaltig | durable |
| umweltfreundlich | écologique, respectueux de l'environnement |

## 3. Les verbes de l'écologie

| Allemand | Français |
|---|---|
| schützen | protéger |
| sparen | économiser |
| trennen | trier (les déchets) |
| verschmutzen | polluer |

Exemple : *Wir müssen die Umwelt schützen.* (Nous devons protéger l'environnement.)

## 4. Les erreurs à éviter

- « erneuerbar » = renouvelable ; « nachhaltig » = durable : ne pas confondre.
- « schützen » (protéger) ≠ « verschmutzen » (polluer), sens opposés.
- Beaucoup de noms composés : der **Umwelt**schutz, der **Klima**wandel, die **Sonnen**energie.
- Tous les noms prennent une majuscule : die Umwelt, der Müll, das Recycling.

## À retenir

- L'environnement : die Umwelt, die Natur, die Luft, das Wasser, der Wald.
- Les enjeux : der Klimawandel, die Verschmutzung, der Müll.
- Les solutions : recyceln, erneuerbar, nachhaltig, umweltfreundlich.
- Les verbes : schützen, sparen, trennen, verschmutzen.
