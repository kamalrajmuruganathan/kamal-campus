# Choisir l'auxiliaire au passato prossimo

> Le passato prossimo est le temps du passé le plus utilisé à l'oral. Il se forme avec **avere** ou **essere** + le participe passé. Toute la difficulté est là : quel auxiliaire choisir ? Et faut-il accorder le participe ?

## 1. La formation du passato prossimo

Le passato prossimo se construit en deux morceaux : l'**auxiliaire** conjugué au présent + le **participe passé** du verbe.

| Auxiliaire | Verbe | Exemple | Traduction |
|---|---|---|---|
| **avere** (présent) | + participe passé | Ho **mangiato** una pizza. | J'ai mangé une pizza. |
| **essere** (présent) | + participe passé | Sono **andato** a Roma. | Je suis allé à Rome. |

Le participe passé régulier se forme ainsi :
- verbes en **-are** → **-ato** : parlare → **parlato**
- verbes en **-ere** → **-uto** : credere → **creduto**
- verbes en **-ire** → **-ito** : dormire → **dormito**

## 2. Les verbes qui prennent *avere*

On utilise **avere** avec la grande majorité des verbes, en particulier les verbes **transitifs** (ceux qui peuvent avoir un complément d'objet direct).

| Exemple | Traduction |
|---|---|
| Ho **comprato** il pane. | J'ai acheté le pain. |
| Abbiamo **visto** un film. | Nous avons vu un film. |
| Hai **letto** il libro? | As-tu lu le livre ? |

Avec **avere**, le participe passé **ne s'accorde pas** avec le sujet : *Maria ha mangiato* (et non *mangiata*).

## 3. Les verbes qui prennent *essere*

On utilise **essere** avec :
- les verbes de **mouvement** et de déplacement : andare, venire, arrivare, partire, uscire, entrare, tornare, cadere ;
- les verbes de **changement d'état** : nascere (naître), morire (mourir), diventare, crescere ;
- les verbes **restare / rimanere / stare / essere** ;
- tous les verbes **pronominaux (réfléchis)** : alzarsi, svegliarsi, lavarsi…

**Attention : avec *essere*, le participe passé s'accorde en genre et en nombre avec le sujet** (‑o, ‑a, ‑i, ‑e).

| Sujet | Exemple | Traduction |
|---|---|---|
| Marco (m. sing.) | Marco è **partito**. | Marco est parti. |
| Anna (f. sing.) | Anna è **partita**. | Anna est partie. |
| I ragazzi (m. plur.) | I ragazzi sono **partiti**. | Les garçons sont partis. |
| Le ragazze (f. plur.) | Le ragazze sono **partite**. | Les filles sont parties. |

## 4. Les participes passés irréguliers à connaître

| Infinitif | Participe | Infinitif | Participe |
|---|---|---|---|
| fare | **fatto** | prendere | **preso** |
| dire | **detto** | mettere | **messo** |
| leggere | **letto** | scrivere | **scritto** |
| vedere | **visto** | chiedere | **chiesto** |
| venire | **venuto** | rimanere | **rimasto** |
| essere | **stato** | nascere | **nato** |
| aprire | **aperto** | chiudere | **chiuso** |

Remarque : le participe de **essere** est **stato**, identique à celui de *stare*.

## 5. Les erreurs à éviter

- Ne pas accorder le participe avec **essere** : on dit *Lei è andat**a***, jamais *è andato* pour une fille.
- Vouloir accorder le participe avec **avere** et le sujet : *Le ragazze hanno mangiat**o*** (et non *mangiate*).
- Traduire mot à mot le français : « j'ai été » se dit **sono stato**, avec *essere*, pas avec *avere*.
- Oublier que les verbes réfléchis prennent **essere** : *Mi sono lavat**o*** les mains.

## À retenir

- Passato prossimo = **avere** ou **essere** (au présent) + **participe passé**.
- **avere** : verbes transitifs → participe **invariable**.
- **essere** : mouvement, changement d'état, verbes réfléchis → participe **accordé** avec le sujet.
- Participes irréguliers fréquents : fatto, detto, visto, preso, scritto, stato.
