# Vocabulaire : l'ambiente (l'environnement)

> Protéger la planète, trier ses déchets, économiser l'énergie : l'environnement est un
> sujet clé en classe de 3e. Ce chapitre réunit le lexique de l'*ambiente* et de l'écologie.

## 1. La natura e il pianeta (la nature et la planète)

| Italien | Français |
|---|---|
| l'ambiente | l'environnement |
| il pianeta | la planète |
| la Terra | la Terre |
| la natura | la nature |
| l'aria | l'air |
| l'acqua | l'eau |
| il clima | le climat |
| le risorse naturali | les ressources naturelles |

Exemple : *Dobbiamo proteggere il nostro pianeta.* → Nous devons protéger notre planète.

## 2. I problemi ambientali (les problèmes environnementaux)

| Italien | Français |
|---|---|
| l'inquinamento | la pollution |
| i rifiuti | les déchets |
| il riscaldamento globale | le réchauffement climatique |
| lo spreco | le gaspillage |
| la deforestazione | la déforestation |
| lo smog | la pollution de l'air (smog) |

Exemple : *L'inquinamento danneggia l'ambiente.* → La pollution nuit à l'environnement.

## 3. Le soluzioni (les solutions)

| Italien | Français |
|---|---|
| riciclare | recycler |
| la raccolta differenziata | le tri sélectif |
| risparmiare (energia / acqua) | économiser (l'énergie / l'eau) |
| l'energia rinnovabile | l'énergie renouvelable |
| proteggere | protéger |
| inquinare | polluer |
| riutilizzare | réutiliser |

Exemple : *È importante riciclare la plastica e la carta.* → Il est important de recycler le plastique et le papier.

## 4. I materiali da riciclare (les matériaux à recycler)

| Italien | Français |
|---|---|
| la plastica | le plastique |
| il vetro | le verre |
| la carta | le papier |
| il metallo | le métal |
| l'organico | les déchets organiques |

## 5. Les erreurs à éviter

- *l'ambiente* signifie « l'environnement » (au sens écologique), à ne pas confondre avec « l'ambiance ».
- *inquinare* = polluer / *l'inquinamento* = la pollution : ne confonds pas le verbe et le nom.
- *la carta* = le papier (et non « la carte » au sens de plan, qui se dit *la cartina / la mappa*).
- *risparmiare* = économiser ; *sprecare / lo spreco* = gaspiller / le gaspillage (contraires).
- Attention aux doubles consonnes : *l'inquiname**nt**o*, *la ra**cc**olta*, *ri**cc**… non : ricicl**are** (un seul c), *ri**ff**iuti* → correct : *rifiuti* (un seul f).

## À retenir

- La planète : *l'ambiente*, *il pianeta*, *la Terra*, *il clima*, *le risorse naturali*.
- Les problèmes : *l'inquinamento*, *i rifiuti*, *il riscaldamento globale*, *lo spreco*.
- Les solutions : *riciclare*, *la raccolta differenziata*, *risparmiare*, *l'energia rinnovabile*.
- Les matériaux : *la plastica*, *il vetro*, *la carta*, *il metallo*.
- Verbe / nom : *inquinare* → *l'inquinamento* ; *risparmiare* est le contraire de *sprecare*.
