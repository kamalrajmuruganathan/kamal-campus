# Vocabulaire : la tecnologia e internet (la technologie et internet)

> Ordinateurs, téléphones, réseaux sociaux : la technologie fait partie du quotidien.
> Ce chapitre réunit le lexique de la *tecnologia* et d'*internet* pour en parler en italien.

## 1. Gli apparecchi (les appareils)

| Italien | Français |
|---|---|
| il computer | l'ordinateur |
| il portatile | l'ordinateur portable |
| il telefono / il cellulare | le téléphone / le portable |
| lo smartphone | le smartphone |
| il tablet | la tablette |
| lo schermo | l'écran |
| la tastiera | le clavier |
| il mouse | la souris |

Exemple : *Uso il portatile per fare i compiti.* → J'utilise le portable pour faire mes devoirs.

## 2. Internet e la rete (internet et le réseau)

| Italien | Français |
|---|---|
| internet / la rete | internet / le réseau |
| il sito (web) | le site (web) |
| la pagina | la page |
| il collegamento / il link | le lien |
| la password | le mot de passe |
| la connessione | la connexion |
| il motore di ricerca | le moteur de recherche |
| scaricare | télécharger |

Exemple : *Cerco un'informazione su internet.* → Je cherche une information sur internet.

## 3. La comunicazione digitale (la communication numérique)

| Italien | Français |
|---|---|
| il messaggio | le message |
| la mail / l'email | le courriel |
| il social (network) | le réseau social |
| l'account | le compte |
| chattare | tchatter |
| navigare | naviguer |
| condividere | partager |
| postare / pubblicare | poster / publier |

Exemple : *Condivido una foto con gli amici.* → Je partage une photo avec mes amis.

## 4. Verbi utili del digitale (verbes utiles du numérique)

| Italien | Français |
|---|---|
| accendere / spegnere | allumer / éteindre |
| cliccare | cliquer |
| digitare | taper (au clavier) |
| salvare | enregistrer, sauvegarder |
| cancellare | supprimer |
| inviare | envoyer |

## 5. Les erreurs à éviter

- Beaucoup de mots viennent de l'anglais mais restent invariables : *il computer / i computer*, *lo smartphone / gli smartphone*.
- *scaricare* = télécharger ; *caricare* = charger (une batterie) ou téléverser : ne les confonds pas.
- *salvare* = enregistrer / sauvegarder (un fichier), pas seulement « sauver ».
- *la rete* signifie « le réseau » (et aussi « le filet ») ; en informatique = internet.
- Attention aux doubles consonnes : *conne**ss**ione*, *me**ss**aggio*, *a**cc**ount*, *cli**cc**are*, *a**cc**endere*.

## À retenir

- Les appareils : *il computer*, *il portatile*, *lo smartphone*, *lo schermo*, *la tastiera*.
- Internet : *il sito*, *il link*, *la password*, *la connessione*, *il motore di ricerca*.
- La communication : *il messaggio*, *la mail*, *il social*, *condividere*, *postare*.
- Les verbes : *accendere / spegnere*, *cliccare*, *salvare*, *cancellare*, *scaricare*, *inviare*.
- Les mots venus de l'anglais sont souvent invariables : *i computer*, *gli smartphone*.
