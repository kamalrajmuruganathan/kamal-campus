# Wortschatz: Medien und Technik

> Ordinateur, smartphone, réseaux sociaux : ce chapitre réunit le vocabulaire
> allemand des médias et de la technique pour parler du numérique au quotidien.

## 1. Les appareils (die Geräte)

| Allemand | Traduction |
|---|---|
| **der Computer / der Rechner** | l'ordinateur |
| **das Handy / das Smartphone** | le téléphone portable |
| **der Bildschirm** | l'écran |
| **die Tastatur** | le clavier |
| **die Maus** | la souris |
| **der Drucker** | l'imprimante |
| **der Akku** | la batterie |

Attention : *das Handy* est un « faux anglicisme » — en allemand il désigne le
téléphone portable, pas ce qui est « pratique ».

## 2. Internet et les réseaux (das Internet, die sozialen Netzwerke)

| Allemand | Traduction |
|---|---|
| **die Website / die Seite** | le site web / la page |
| **die App / die Anwendung** | l'application |
| **die Suchmaschine** | le moteur de recherche |
| **der Browser** | le navigateur |
| **der Nutzer / die Nutzerin** | l'utilisateur / l'utilisatrice |
| **das Passwort** | le mot de passe |
| **der Datenschutz** | la protection des données |
| **die künstliche Intelligenz** | l'intelligence artificielle |

## 3. Les actions (die Verben)

| Allemand | Traduction |
|---|---|
| **surfen** | surfer |
| **posten / teilen** | poster / partager |
| **herunterladen** | télécharger (vers le bas) |
| **hochladen** | téléverser (mettre en ligne) |
| **speichern** | enregistrer / sauvegarder |
| **löschen** | supprimer / effacer |
| **streamen** | regarder en streaming |
| **ein-/ausschalten** | allumer / éteindre |

*herunterladen* et *hochladen* sont des verbes à particule séparable :
*Ich lade das Video **herunter**.* (Je télécharge la vidéo.)

## 4. Les erreurs à éviter

- **herunterladen** = télécharger (vers soi) ; **hochladen** = mettre en ligne. Ne
  les confonds pas.
- *das Handy* ne se traduit pas par « pratique » : c'est le téléphone portable.
- La particule séparable part à la fin : *Ich schalte den Computer **aus**.*
- Genre à mémoriser : **der** Bildschirm, **die** Tastatur, **die** Maus, **das** Passwort.

## À retenir

- Appareils : der Computer, das Handy, der Bildschirm, die Tastatur, die Maus.
- Internet : die Website, die App, die Suchmaschine, das Passwort, der Datenschutz.
- Verbes clés : herunterladen, hochladen, speichern, löschen, teilen, streamen.
- Beaucoup de ces verbes sont à particule séparable (elle part à la fin de la phrase).
