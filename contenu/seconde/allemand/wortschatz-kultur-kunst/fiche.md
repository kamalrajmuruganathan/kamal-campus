# Wortschatz: Kultur und Kunst

> Musée, théâtre, cinéma, littérature : ce chapitre rassemble le vocabulaire
> allemand de la culture et des arts pour parler de tes goûts et décrire une
> œuvre.

## 1. Les lieux et les arts (die Orte, die Künste)

| Allemand | Traduction |
|---|---|
| **das Museum** | le musée |
| **die Ausstellung** | l'exposition |
| **das Theater** | le théâtre |
| **das Kino** | le cinéma |
| **die Bibliothek** | la bibliothèque |
| **das Konzert** | le concert |
| **die Kunst** | l'art |
| **die Musik** | la musique |

## 2. Les œuvres et les artistes (die Werke, die Künstler)

| Allemand | Traduction |
|---|---|
| **das Kunstwerk** | l'œuvre d'art |
| **das Gemälde** | le tableau (peinture) |
| **der Roman** | le roman |
| **das Gedicht** | le poème |
| **der Film** | le film |
| **der Künstler / die Künstlerin** | l'artiste |
| **der Schriftsteller** | l'écrivain |
| **der Regisseur** | le réalisateur / le metteur en scène |

## 3. Décrire et apprécier (beschreiben und bewerten)

| Allemand | Traduction |
|---|---|
| **malen** | peindre |
| **zeichnen** | dessiner |
| **vorstellen** | présenter / imaginer |
| **beeindruckend** | impressionnant |
| **berühmt** | célèbre |
| **das gefällt mir** | ça me plaît |
| **spannend** | passionnant / captivant |
| **langweilig** | ennuyeux |

*Pour dire qu'on aime : « Das Gemälde **gefällt mir**. » (Ce tableau me plaît.)*

## 4. Les erreurs à éviter

- **gefallen** se construit avec le datif : *Der Film **gefällt mir*** (et non « ich gefalle »).
- Ne confonds pas **malen** (peindre) et **zeichnen** (dessiner au crayon).
- Genre à mémoriser : **das** Museum, **die** Ausstellung, **das** Gemälde, **der** Roman.
- *der Regisseur* désigne aussi bien le réalisateur de cinéma que le metteur en scène.

## À retenir

- Lieux : das Museum, die Ausstellung, das Theater, das Kino, die Bibliothek.
- Œuvres : das Gemälde, der Roman, das Gedicht, der Film, das Kunstwerk.
- Personnes : der Künstler, der Schriftsteller, der Regisseur.
- Apprécier : gefallen (+ datif), beeindruckend, spannend, langweilig.
