# Les verbes pronominaux (*se*)

> Beaucoup de verbes espagnols se conjuguent avec un pronom réfléchi : *levantarse*, *ducharse*, *llamarse*… Ce pronom change de forme selon la personne et peut se placer à deux endroits. Voici comment les maîtriser.

## 1. Reconnaître un verbe pronominal

À l'infinitif, le verbe se termine par **-se** : *llamar**se*** (s'appeler), *levantar**se*** (se lever), *ducharse* (se doucher). Le pronom *se* se transforme selon la personne.

## 2. Les pronoms réfléchis et la conjugaison

| Personne | Pronom | *levantarse* (se lever) |
|---|---|---|
| yo | **me** | me levanto |
| tú | **te** | te levantas |
| él / ella / usted | **se** | se levanta |
| nosotros | **nos** | nos levantamos |
| vosotros | **os** | os levantáis |
| ellos / ustedes | **se** | se levantan |

Le pronom **s'accorde** avec le sujet : *yo me ducho*, *nosotros nos duchamos*.

## 3. La place du pronom

| Cas | Place | Exemple |
|---|---|---|
| verbe conjugué | **avant** le verbe | **Me** levanto temprano. |
| infinitif | **collé** à la fin | Voy a levantar**me**. |
| gérondif | collé à la fin | Estoy duchándo**me**. |
| impératif affirmatif | collé à la fin | ¡Levánta**te**! |

Avec l'impératif négatif, le pronom revient devant : *No **te** levantes.*

## 4. Sens réfléchi, réciproque et changement de sens

- **Réfléchi** : l'action retombe sur le sujet : *Se lava.* (Il se lave.)
- **Réciproque** (pluriel) : « l'un l'autre » : *Se quieren.* (Ils s'aiment.)
- **Changement de sens** : le pronom modifie le sens : *ir* (aller) → *irse* (s'en aller) ; *dormir* (dormir) → *dormirse* (s'endormir).

## 5. Les erreurs à éviter

- Oublier d'accorder le pronom : *yo **me** levanto* (jamais *yo se levanto*).
- Placer le pronom après un verbe conjugué : *levanto me* ✗ → *me levanto*.
- Oublier l'accent écrit quand on colle le pronom : *duchándo**me***, *levánta**te***.

## À retenir
- Infinitif en **-se** = verbe pronominal ; le pronom s'accorde (me, te, se, nos, os, se).
- Verbe conjugué → pronom **devant** ; infinitif/gérondif/impératif affirmatif → pronom **collé**.
- *irse, dormirse, quedarse*… : le pronom peut changer le sens du verbe.
