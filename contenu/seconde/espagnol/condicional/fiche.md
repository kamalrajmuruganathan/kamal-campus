# El condicional

> Le conditionnel (*condicional*) sert à exprimer la politesse, le désir, l'hypothèse ou le conseil. Bonne nouvelle : il se forme presque comme le futur, avec les mêmes radicaux irréguliers.

## 1. La formation

On ajoute à l'**infinitif** les terminaisons de l'imperfecto des verbes en -er/-ir : **-ía, -ías, -ía, -íamos, -íais, -ían**. Ces terminaisons sont les mêmes pour tous les groupes.

| Personne | hablar | comer | vivir |
|---|---|---|---|
| yo | hablaría | comería | viviría |
| tú | hablarías | comerías | vivirías |
| él/ella | hablaría | comería | viviría |
| nosotros | hablaríamos | comeríamos | viviríamos |
| vosotros | hablaríais | comeríais | viviríais |
| ellos | hablarían | comerían | vivirían |

## 2. Les radicaux irréguliers

Ce sont exactement les mêmes qu'au futur. On ne modifie que le radical, jamais les terminaisons.

| Infinitif | Radical | Exemple |
|---|---|---|
| tener | tendr- | **tendría** |
| poder | podr- | **podría** |
| poner | pondr- | **pondría** |
| salir | saldr- | **saldría** |
| venir | vendr- | **vendría** |
| hacer | har- | **haría** |
| decir | dir- | **diría** |
| querer | querr- | **querría** |
| saber | sabr- | **sabría** |
| haber | habr- | **habría** |

## 3. Les emplois

| Emploi | Espagnol | Traduction |
|---|---|---|
| Politesse | **¿Podrías** ayudarme? | Pourrais-tu m'aider ? |
| Désir | Me **gustaría** viajar a Cuba. | J'aimerais voyager à Cuba. |
| Conseil | **Deberías** descansar más. | Tu devrais te reposer davantage. |
| Hypothèse | Yo en tu lugar **hablaría** con él. | À ta place, je lui parlerais. |
| Futur du passé | Dijo que **vendría**. | Il a dit qu'il viendrait. |

## 4. Le conditionnel de probabilité

Comme le futur exprime une supposition sur le présent, le conditionnel exprime une supposition sur le **passé**.

| Espagnol | Traduction |
|---|---|
| **Serían** las diez cuando llegó. | Il devait être dix heures quand il est arrivé. |
| ¿Cuántos años **tendría** entonces? | Quel âge pouvait-il bien avoir alors ? |

## 5. Les erreurs à éviter

- Ne pas séparer le radical de l'infinitif : *comería* s'écrit en un seul bloc (pas « comer ía »).
- Les radicaux irréguliers sont **identiques** au futur : si tu sais *tendré*, tu sais *tendría*.
- Pour un conseil, on emploie *deberías* (pas *debes*, trop direct).
- Ne pas confondre *querría* (conditionnel : j'aimerais) et *quería* (imperfecto : je voulais).

## À retenir

- Formation : **infinitif** + terminaisons -ía, -ías, -ía, -íamos, -íais, -ían.
- Radicaux irréguliers = ceux du futur (*tendr-, podr-, har-, dir-...*).
- Emplois : politesse, désir, conseil, hypothèse, futur du passé.
- Conditionnel de probabilité = supposition sur le passé.
