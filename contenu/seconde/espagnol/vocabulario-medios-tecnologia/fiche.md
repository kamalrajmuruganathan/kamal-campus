# Vocabulaire : los medios de comunicación y la tecnología

> Presse, télévision, réseaux sociaux, smartphone : la vie d'aujourd'hui se raconte
> en espagnol avec un vocabulaire précis. Cette fiche réunit les mots-clés des médias
> et des technologies, avec leur genre et des exemples traduits.

## 1. Los medios de comunicación (les médias)

| Espagnol | Français |
|---|---|
| el periódico / el diario | le journal |
| la prensa | la presse |
| la noticia | la nouvelle, l'information |
| el titular | le titre (d'un article) |
| la cadena (de televisión) | la chaîne (de télévision) |
| el/la periodista | le/la journaliste |
| la publicidad / el anuncio | la publicité / l'annonce |
| la emisora de radio | la station de radio |

Exemple : *Leo el periódico todos los días.* → Je lis le journal tous les jours.
Attention aux faux-amis : **la noticia** = la nouvelle (information), et non « la notice ».

## 2. La tecnología y las redes sociales

| Espagnol | Français |
|---|---|
| el ordenador | l'ordinateur |
| el móvil / el teléfono móvil | le téléphone portable |
| la pantalla | l'écran |
| el teclado | le clavier |
| la red social | le réseau social |
| la contraseña | le mot de passe |
| descargar | télécharger |
| navegar por internet | naviguer sur internet |
| la nube | le cloud (« le nuage ») |
| el usuario / la usuaria | l'utilisateur / l'utilisatrice |

Exemple : *Descargo una aplicación en el móvil.* → Je télécharge une application sur le portable.

## 3. Verbes et expressions utiles

- **conectarse a** = se connecter à : *Me conecto a internet.*
- **colgar una foto / subir una foto** = poster / mettre en ligne une photo.
- **estar en línea / estar conectado** = être en ligne.
- **enterarse de** = apprendre (une nouvelle) : *Me enteré de la noticia por la radio.*

## 4. Les erreurs à éviter

- **el ordenador** (Espagne) / **la computadora** (Amérique latine) : deux mots pour « ordinateur ».
- **el móvil** en Espagne, **el celular** en Amérique latine.
- Ne pas confondre **la red** (le réseau, le filet) et **la red social** (le réseau social).
- « télécharger » se dit **descargar**, pas *téléchargar* (mot inexistant).

## À retenir

- Médias : *el periódico, la noticia, la cadena, la prensa, el/la periodista*.
- Technologie : *el ordenador / la computadora, el móvil / el celular, la pantalla*.
- Verbes clés : *descargar, navegar, conectarse, colgar/subir una foto*.
- Le vocabulaire varie entre Espagne et Amérique latine (*ordenador/computadora*, *móvil/celular*).
