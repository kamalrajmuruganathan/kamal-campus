# Vocabulaire : la cultura y el arte

> Musées, peinture, musique, littérature : parler de culture en espagnol demande un
> lexique précis. Cette fiche réunit les mots-clés des arts et du patrimoine, avec leur
> genre et des exemples traduits.

## 1. Las artes plásticas (les arts plastiques)

| Espagnol | Français |
|---|---|
| el cuadro / la pintura | le tableau / la peinture |
| el/la pintor(a) | le/la peintre |
| la obra (de arte) | l'œuvre (d'art) |
| el museo | le musée |
| la exposición | l'exposition |
| la escultura | la sculpture |
| el/la artista | l'artiste |
| el lienzo | la toile |

Exemple : *Vamos a ver una exposición de pintura.* → Nous allons voir une exposition de peinture.
Attention au faux-ami : **el cuadro** = le tableau (peinture), et non « le cadre » au sens de contexte.

## 2. La música, el cine y la literatura

| Espagnol | Français |
|---|---|
| la canción | la chanson |
| el/la cantante | le/la chanteur(se) |
| la película | le film |
| el/la director(a) de cine | le/la réalisateur(rice) |
| la novela | le roman |
| el/la escritor(a) | l'écrivain(e) |
| el escenario | la scène |
| el papel | le rôle |

Exemple : *Esta novela ganó un premio importante.* → Ce roman a gagné un prix important.

## 3. Verbes et expressions utiles

- **pintar** = peindre : *Picasso pintó el Guernica.*
- **actuar / interpretar** = jouer (un rôle) : *La actriz interpreta a una reina.*
- **estrenar** = sortir (un film), donner une première : *La película se estrena mañana.*
- **exponer** = exposer : *El museo expone obras de Goya.*

## 4. Les erreurs à éviter

- **el papel** = le rôle (au théâtre / cinéma), mais aussi « le papier » : attention au contexte.
- Ne pas confondre **actuar** (jouer, agir) et **tocar** (jouer d'un instrument) : *Toca la guitarra.*
- « Réalisateur » se dit **director(a) de cine**, pas *realizador* (rare).
- **la novela** = le roman (faux-ami : ce n'est pas « la nouvelle », qui se dit *el cuento* ou *el relato*).

## À retenir

- Arts plastiques : *el cuadro, el/la pintor(a), la obra, el museo, la exposición*.
- Musique / cinéma / littérature : *la canción, la película, la novela, el/la escritor(a)*.
- Verbes clés : *pintar, actuar/interpretar, estrenar, exponer, tocar*.
- Faux-amis : *el cuadro* (le tableau), *la novela* (le roman), *el papel* (le rôle).
