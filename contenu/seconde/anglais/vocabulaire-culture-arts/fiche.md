# Vocabulaire : la culture et les arts

> Cinéma, peinture, musique, littérature : la culture est un terrain de discussion idéal au lycée. Cette fiche te donne le lexique anglais pour parler d'une œuvre, exprimer un avis nuancé et décrire une visite au musée ou une sortie au théâtre.

## 1. Les arts et les artistes

| Anglais | Français | Remarque |
|---|---|---|
| a painting | un tableau, une peinture | *an oil painting* = une peinture à l'huile |
| a portrait | un portrait | *a self-portrait* = un autoportrait |
| a sculpture | une sculpture | *a sculptor* = un sculpteur |
| an exhibition | une exposition | *to hold an exhibition* |
| an artwork / a piece | une œuvre d'art | *a work of art* |
| a masterpiece | un chef-d'œuvre | |
| the audience | le public, l'assistance | faux ami : pas « audience » = écoute |
| a playwright | un(e) dramaturge | attention à l'orthographe |

**Exemples :**
- *This painting is considered a masterpiece.* → Ce tableau est considéré comme un chef-d'œuvre.
- *The audience clapped for five minutes.* → Le public a applaudi pendant cinq minutes.

## 2. Cinéma, musique et littérature

| Anglais | Français |
|---|---|
| a movie / a film | un film |
| the plot | l'intrigue |
| the setting | le cadre, le décor |
| a character | un personnage |
| the soundtrack | la bande-son |
| a novel | un roman |
| a short story | une nouvelle |
| a lyric / lyrics | une parole / les paroles (de chanson) |
| a tune | un air, une mélodie |
| a review | une critique |

**Collocations utiles :**
- *to release a film / an album* → sortir un film / un album.
- *to be set in* → se dérouler à/dans. *The novel is set in London.*
- *based on a true story* → inspiré d'une histoire vraie.

## 3. Donner et nuancer son avis

Pour argumenter, va au-delà de *good* et *bad* :

| Anglais | Français |
|---|---|
| moving | émouvant |
| gripping | captivant, prenant |
| dull / boring | ennuyeux |
| overrated | surestimé |
| stunning | époustouflant |
| meaningful | riche de sens |
| I'm keen on | je suis passionné(e) par |
| it's not my cup of tea | ce n'est pas mon truc |

**Exemples :**
- *The plot was gripping from start to finish.* → L'intrigue était captivante du début à la fin.
- *Honestly, this film is a bit overrated.* → Franchement, ce film est un peu surestimé.

## 4. Registre : soutenu ou familier ?

| Familier | Neutre / soutenu |
|---|---|
| an awesome show | an impressive show |
| a flick | a film |
| the acting was great | the performance was remarkable |
| it's cool | it's enjoyable |

## 5. Les erreurs à éviter

- **« an artist »** ne se limite pas au peintre : c'est tout créateur (musicien, acteur…).
- **« a comedian »** = un humoriste, pas « un comédien » (= *an actor*).
- **« to attend a concert »** : assister à = *to attend*, pas *to assist*.
- **« a novel »** = un roman, pas « une nouvelle » (= *a short story*).
- **« a library »** = une bibliothèque, pas « une librairie » (= *a bookshop*).

## À retenir

- Décrire une œuvre : *a painting, a masterpiece, the plot, the setting, a character*.
- Sorties culturelles : *an exhibition, the audience, to release, to be set in*.
- Avis nuancé : *moving, gripping, overrated, stunning, not my cup of tea*.
- Faux amis à surveiller : *a comedian, a novel, a library, to attend*.
- Adapte ton **registre** à la situation (discussion entre amis vs écrit d'examen).
