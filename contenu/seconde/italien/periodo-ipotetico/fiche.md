# Les phrases hypothétiques (se)

> « Si tu étudies, tu réussiras » ; « Si j'avais le temps, je viendrais ». Le *periodo ipotetico* relie une condition (introduite par **se**) à sa conséquence. Selon que la condition est réelle, possible ou irréelle, les temps changent.

## 1. Type 1 — l'hypothèse réelle (la réalité)
La condition est vraie ou très probable. On emploie l'**indicatif** dans les deux parties.

| Condition (se + …) | Conséquence | Traduction |
|---|---|---|
| Se **piove**, | **resto** a casa. | S'il pleut, je reste à la maison. |
| Se **studierai**, | **passerai** l'esame. | Si tu étudies, tu réussiras l'examen. |
| Se **hai** fame, | **mangia**! | Si tu as faim, mange ! |

On peut mélanger présent, futur ou impératif dans la conséquence.

## 2. Type 2 — l'hypothèse possible ou irréelle (le présent)
La condition est peu probable ou contraire à la réalité présente. On emploie **se + congiuntivo imperfetto** et le **condizionale presente**.

| Condition | Conséquence | Traduction |
|---|---|---|
| Se **avessi** tempo, | **verrei** con te. | Si j'avais le temps, je viendrais avec toi. |
| Se **fossi** ricco, | **comprerei** una casa. | Si j'étais riche, j'achèterais une maison. |
| Se **potessi**, | ti **aiuterei**. | Si je pouvais, je t'aiderais. |

Le congiuntivo imperfetto utile ici : *essere* → **fossi**, *avere* → **avessi**, *potere* → **potessi**, *volere* → **volessi**, *fare* → **facessi**.

## 3. Type 3 — l'hypothèse irréelle (le passé)
La condition ne s'est pas réalisée dans le passé. On emploie **se + congiuntivo trapassato** et le **condizionale passato**.

| Condition | Conséquence | Traduction |
|---|---|---|
| Se **avessi studiato**, | **avrei passato** l'esame. | Si j'avais étudié, j'aurais réussi l'examen. |
| Se **fossi partito** prima, | non **avrei perso** il treno. | Si j'étais parti plus tôt, je n'aurais pas raté le train. |

## 4. Comment choisir ?
- La condition est **vraie/probable** → **Type 1** (indicatif + indicatif).
- La condition porte sur le **présent, mais est irréelle** → **Type 2** (congiuntivo imperfetto + condizionale presente).
- La condition porte sur le **passé et ne s'est pas produite** → **Type 3** (congiuntivo trapassato + condizionale passato).

## 5. Les erreurs à éviter
- Mettre le **conditionnel après « se »** : on ne dit pas *se avrei*, mais *se avessi* (le conditionnel va dans la conséquence, jamais après se).
- Confondre indicatif et congiuntivo : Type 1 = *se ho*, Type 2 = *se avessi*.
- Calquer le français : « si j'avais » = *se avessi* (congiuntivo), pas *se avevo*.
- Oublier que le **futur** est possible après « se » au Type 1 : *Se studierai, passerai*.

## À retenir
- **Type 1** (réel) : se + indicatif → indicatif/impératif. *Se piove, resto a casa.*
- **Type 2** (possible/irréel présent) : se + **congiuntivo imperfetto** → **condizionale presente**. *Se avessi tempo, verrei.*
- **Type 3** (irréel passé) : se + **congiuntivo trapassato** → **condizionale passato**. *Se avessi studiato, avrei passato.*
- **Jamais de conditionnel après « se »**.
- Le type dépend du **degré de réalité** de la condition.
