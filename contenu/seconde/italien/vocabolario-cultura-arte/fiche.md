# Vocabulaire : culture et art

> Peinture, musique, cinéma, patrimoine : l'Italie est un pays d'art par excellence. Cette fiche te donne le lexique pour décrire une œuvre, exprimer un goût artistique et parler de la vie culturelle.

## 1. Le arti (les arts)

| Italien | Français | Remarque |
|---|---|---|
| l'opera (f.) | l'œuvre ; l'opéra | *un'opera d'arte* = une œuvre d'art |
| il quadro / il dipinto | le tableau / la peinture | *un dipinto a olio* = à l'huile |
| il pittore / la pittrice | le peintre | *dipingere* = peindre |
| la scultura | la sculpture | *lo scultore* = le sculpteur |
| il capolavoro | le chef-d'œuvre | *un vero capolavoro* |
| la mostra | l'exposition | *una mostra di pittura* |
| il museo | le musée | *la galleria* = la galerie |

**Exemples :**
- *La Gioconda è un capolavoro di Leonardo.* → La Joconde est un chef-d'œuvre de Léonard.
- *Andiamo a vedere una mostra al museo.* → Allons voir une exposition au musée.

## 2. Musica, cinema e letteratura

| Italien | Français |
|---|---|
| il cantante | le chanteur |
| la canzone | la chanson |
| il regista | le réalisateur |
| il film | le film |
| lo spettacolo | le spectacle |
| lo scrittore / la scrittrice | l'écrivain |
| il romanzo | le roman |
| il patrimonio | le patrimoine |

**Exemples :**
- *Il regista ha vinto un premio importante.* → Le réalisateur a gagné un prix important.
- *Ho letto un romanzo di uno scrittore italiano.* → J'ai lu un roman d'un écrivain italien.

## 3. Les erreurs à éviter

- **il regista** = le réalisateur (faux ami : ce n'est pas un « registre »).
- **l'opera** peut signifier *l'œuvre* ou *l'opéra* selon le contexte.
- On dit **dipingere un quadro** (peindre un tableau), pas *« pittare »*.
- **lo spettacolo** = le spectacle : attention, *spettacoloso* n'existe pas, on dit *spettacolare*.

## À retenir

- Une œuvre d'art = **un'opera d'arte** ; un chef-d'œuvre = **un capolavoro**.
- Le peintre = **il pittore**, le réalisateur = **il regista**, l'écrivain = **lo scrittore**.
- Une exposition = **una mostra** ; le patrimoine = **il patrimonio**.
- **il regista** est un faux ami à connaître.
