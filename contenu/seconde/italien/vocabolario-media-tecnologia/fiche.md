# Vocabulaire : médias et technologie

> Journaux, télévision, réseaux sociaux, smartphones : les médias et le numérique sont partout. Cette fiche te donne le lexique italien pour parler de l'information, décrire tes usages en ligne et débattre des enjeux du numérique.

## 1. I mezzi di comunicazione (les médias)

En italien, **i mezzi di comunicazione** (littéralement « les moyens de communication ») désignent les médias. Attention aux collocations et aux faux amis.

| Italien | Français | Remarque |
|---|---|---|
| il giornale | le journal | *il quotidiano* = le quotidien |
| la stampa | la presse | *la stampa scandalistica* = la presse à scandale |
| il titolo | le titre, la manchette | *fare notizia* = faire la une |
| la notizia | la nouvelle, l'information | *le notizie* = les informations |
| il telegiornale (TG) | le journal télévisé | contraction courante : *il TG* |
| l'emittente (f.) | la chaîne (radio/TV) | *un'emittente televisiva* |
| la trasmissione | l'émission | *una trasmissione in diretta* = en direct |

**Exemples :**
- *La notizia è finita su tutti i giornali.* → La nouvelle a fini dans tous les journaux.
- *Guardo il telegiornale ogni sera.* → Je regarde le journal télévisé chaque soir.

## 2. Internet e i social (le numérique)

| Italien | Français |
|---|---|
| il dispositivo | l'appareil |
| lo schermo | l'écran |
| navigare (in rete) | naviguer (sur le net) |
| scaricare | télécharger |
| caricare | téléverser, mettre en ligne |
| pubblicare / un post | publier / une publication |
| condividere | partager |
| il seguace / il follower | l'abonné |
| la rete | le réseau, le net |

**Exemples :**
- *Ho condiviso il video con i miei amici.* → J'ai partagé la vidéo avec mes amis.
- *Passo troppo tempo davanti allo schermo.* → Je passe trop de temps devant l'écran.

## 3. Les erreurs à éviter

- **la stampa** = la presse (le média), à ne pas confondre avec *stampare* = imprimer.
- **la notizia** ≠ *la notice* : c'est une nouvelle, une information.
- Ne dis pas *« il giornale televisivo »* : on dit **il telegiornale**.
- **caricare** = mettre en ligne / charger, **scaricare** = télécharger : ne les inverse pas.

## À retenir

- Les médias = **i mezzi di comunicazione** ; la presse = **la stampa**.
- Le JT = **il telegiornale (TG)** ; une émission = **una trasmissione**.
- En ligne : **condividere** (partager), **pubblicare** (publier), **scaricare** (télécharger).
- **caricare** ≠ **scaricare** : ne pas inverser.
