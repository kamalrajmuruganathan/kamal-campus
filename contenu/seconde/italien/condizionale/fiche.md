# Le conditionnel

> Le *condizionale* sert à être poli, à exprimer un désir, un conseil ou une action soumise à condition. C'est le mode du « je voudrais », du « on pourrait » et du « ce serait bien ».

## 1. Le condizionale presente : formation
On part du **même radical que le futur**, auquel on ajoute les terminaisons **-ei, -esti, -ebbe, -emmo, -este, -ebbero**. Les verbes en **-are** transforment le -a- en **-e-** (comme au futur).

| Personne | parlare | prendere | dormire |
|---|---|---|---|
| io | parler**ei** | prender**ei** | dormir**ei** |
| tu | parler**esti** | prender**esti** | dormir**esti** |
| lui/lei | parler**ebbe** | prender**ebbe** | dormir**ebbe** |
| noi | parler**emmo** | prender**emmo** | dormir**emmo** |
| voi | parler**este** | prender**este** | dormir**este** |
| loro | parler**ebbero** | prender**ebbero** | dormir**ebbero** |

Attention à **noi** : *parleremmo* prend **deux m** (à ne pas confondre avec le futur *parleremo*, un seul m).

## 2. Les radicaux irréguliers (comme au futur)
| Verbe | Radical | Exemple (io) |
|---|---|---|
| essere | sar- | sarei |
| avere | avr- | avrei |
| fare | far- | farei |
| andare | andr- | andrei |
| potere | potr- | potrei |
| dovere | dovr- | dovrei |
| volere | vorr- | vorrei |
| venire | verr- | verrei |
| vedere | vedr- | vedrei |
| rimanere | rimarr- | rimarrei |

## 3. Les emplois
| Emploi | Exemple | Traduction |
|---|---|---|
| Politesse | **Vorrei** un caffè. | Je voudrais un café. |
| Désir | **Mi piacerebbe** viaggiare. | J'aimerais voyager. |
| Conseil | **Dovresti** studiare di più. | Tu devrais étudier davantage. |
| Possibilité | **Potremmo** uscire stasera. | On pourrait sortir ce soir. |
| Hypothèse | Con più tempo, **finirei** il lavoro. | Avec plus de temps, je finirais le travail. |

## 4. Le condizionale passato
Il se forme avec le **condizionale presente de avere/essere + participe passé**. Il exprime un désir non réalisé, ou le **futur dans le passé**.

| Exemple | Traduction |
|---|---|
| **Avrei voluto** venire, ma ero malato. | J'aurais voulu venir, mais j'étais malade. |
| Ha detto che **sarebbe arrivato** tardi. | Il a dit qu'il arriverait tard. |

Note : là où le français emploie le conditionnel présent (« il arriverait »), l'italien emploie le **condizionale passato** pour le futur dans le passé.

## 5. Les erreurs à éviter
- Confondre **-emmo** (conditionnel, noi) et **-eremo** (futur, noi) : *parleremmo* ≠ *parleremo*.
- Oublier le radical irrégulier : on dit *vorrei*, pas *volerei* ; *sarei*, pas *esserei*.
- Traduire « il a dit qu'il viendrait » par un conditionnel présent : il faut *ha detto che sarebbe venuto* (conditionnel passé).
- Employer *dovrei/vorrei* sans le radical futur : le conditionnel se construit toujours sur ce radical.

## À retenir
- Radical du **futur** + terminaisons **-ei, -esti, -ebbe, -emmo, -este, -ebbero**.
- Emplois : politesse, désir, conseil, possibilité, hypothèse.
- Irréguliers : **sarei, avrei, farei, andrei, potrei, dovrei, vorrei, verrei**.
- **Condizionale passato** = condizionale de avere/essere + participe.
- Le **futur dans le passé** se rend par le condizionale **passato**.
