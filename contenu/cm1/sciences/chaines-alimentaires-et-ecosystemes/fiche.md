# Chaînes alimentaires et écosystèmes

Dans la nature, les êtres vivants ne vivent pas seuls : ils dépendent les uns des
autres, surtout pour se nourrir. Étudier **qui mange quoi** permet de comprendre
comment fonctionne un milieu de vie.

## Une chaîne alimentaire

Une **chaîne alimentaire** montre **qui mange qui** dans un milieu. On la représente
avec des **flèches**. La flèche se lit **« est mangé par »** et pointe toujours vers
**celui qui mange**.

Exemple :

**herbe → sauterelle → grenouille → couleuvre**

- L'herbe **est mangée par** la sauterelle,
- qui **est mangée par** la grenouille,
- qui **est mangée par** la couleuvre.

> Attention au sens des flèches ! Elles montrent où va la nourriture, donc elles
> pointent vers celui qui se nourrit.

## Les trois rôles dans une chaîne

Chaque être vivant a un rôle :

- Les **producteurs** : ce sont les **végétaux verts**. Ils fabriquent leur propre
  matière grâce à la lumière. Ils sont **toujours au début** de la chaîne.
- Les **consommateurs** : ce sont les **animaux**. Ils doivent manger d'autres êtres
  vivants. Le premier animal qui mange le végétal est un consommateur, celui qui le
  mange ensuite en est un autre, et ainsi de suite.
- Les **décomposeurs** : ce sont les **champignons, les bactéries, les vers**… Ils
  se nourrissent des restes et des êtres morts, et les transforment en matière du sol.

## Le rôle des décomposeurs

Sans les décomposeurs, les feuilles mortes et les animaux morts s'accumuleraient sans
disparaître. Les décomposeurs **recyclent** la matière : ils la renvoient dans le sol
sous forme de sels minéraux, que les plantes utilisent à nouveau. La matière **tourne
en boucle** dans la nature.

## Un réseau alimentaire

Dans la vraie nature, un animal mange souvent **plusieurs sortes de proies**, et il
peut être mangé par **plusieurs prédateurs**. Quand on relie plusieurs chaînes
alimentaires entre elles, on obtient un **réseau alimentaire**.

## Un écosystème

Un **écosystème** est formé de tous les **êtres vivants** d'un milieu (animaux,
végétaux, champignons…) **et** de leur **milieu de vie** non-vivant (le sol, l'eau,
l'air, la lumière, la température).

Exemples d'écosystèmes : une **mare**, une **forêt**, une **prairie**, un **jardin**.
Dans un écosystème, tous les êtres vivants sont **reliés** : si l'un disparaît, cela
peut déranger tous les autres.

## Fragile équilibre

Si un maillon disparaît, toute la chaîne est touchée. Par exemple, si toutes les
grenouilles disparaissent :

- les sauterelles, moins mangées, deviennent **trop nombreuses** ;
- les couleuvres, qui mangeaient les grenouilles, manquent de nourriture.

C'est pourquoi il faut **protéger la biodiversité**, c'est-à-dire la variété des êtres
vivants.

## Ce qu'il faut retenir

- Une **chaîne alimentaire** montre qui mange qui ; la flèche se lit **« est mangé par »**.
- Une chaîne commence **toujours par un végétal** (le producteur).
- **Producteurs** = végétaux ; **consommateurs** = animaux ; **décomposeurs** =
  champignons, bactéries, vers.
- Les **décomposeurs recyclent** la matière dans le sol.
- Un **écosystème** = les êtres vivants d'un milieu **+** leur milieu non-vivant.

## Les erreurs à éviter

- **Se tromper de sens de flèche.** La flèche pointe vers celui qui **mange**.
- **Commencer une chaîne par un animal.** Une chaîne débute par un producteur (végétal).
- **Oublier les décomposeurs.** Sans eux, la matière ne serait pas recyclée.
- **Croire qu'un être vivant peut disparaître sans conséquence.** Tout est relié.
