# La casa

> Voici comment décrire ta maison en italien : les pièces, les meubles et où se trouvent les choses. Tu apprendras aussi à dire ce qu'il y a dans une pièce avec **c'è** et **ci sono**.

## 1. Les pièces de la maison

| Italien | Traduction |
|---|---|
| la **cucina** | la cuisine |
| il **bagno** | la salle de bains |
| la **camera (da letto)** | la chambre |
| il **salotto** | le salon |
| la **sala da pranzo** | la salle à manger |
| il **giardino** | le jardin |

- **La mia casa ha cinque stanze.** → Ma maison a cinq pièces.
- **In cucina c'è un tavolo.** → Dans la cuisine il y a une table.

## 2. Les meubles

| Italien | Traduction |
|---|---|
| il **letto** | le lit |
| il **tavolo** | la table |
| la **sedia** | la chaise |
| il **divano** | le canapé |
| l'**armadio** | l'armoire |
| la **lampada** | la lampe |

## 3. Dire où sont les choses : les prépositions

| Italien | Traduction |
|---|---|
| **su / sopra** | sur |
| **sotto** | sous |
| **in** | dans |
| **davanti a** | devant |
| **dietro** | derrière |
| **vicino a** | à côté de |

- **Il gatto è sotto il tavolo.** → Le chat est sous la table.
- **La lampada è sul comodino.** → La lampe est sur la table de nuit.

## 4. *C'è* et *ci sono*

Pour dire ce qu'il y a dans une pièce :

| Forme | Emploi | Exemple |
|---|---|---|
| **c'è** | une seule chose | In salotto **c'è** un divano. |
| **ci sono** | plusieurs choses | In cucina **ci sono** due sedie. |

## 5. Les erreurs à éviter

- Attention au genre : *la cucina* (féminin) mais *il bagno* (masculin).
- **c'è** pour le singulier, **ci sono** pour le pluriel : ne les confonds pas.
- « Dans la cuisine » se dit **in cucina** (sans article, avec *in*).

## À retenir

- Pièces : **la cucina, il bagno, la camera, il salotto, il giardino**.
- Meubles : **il letto, il tavolo, la sedia, il divano, l'armadio**.
- Prépositions : **su, sotto, in, davanti a, dietro, vicino a**.
- **c'è** (singulier) / **ci sono** (pluriel).
