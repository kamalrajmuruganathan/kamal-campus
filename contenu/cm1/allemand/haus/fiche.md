# Das Haus

> Combien de pièces y a-t-il chez toi ? Ce chapitre t'apprend à nommer les
> pièces de la maison et quelques meubles, avec leur bon article.

## 1. Les pièces de la maison

| Allemand | Traduction |
|---|---|
| das Haus / die Wohnung | la maison / l'appartement |
| **die Küche** | la cuisine |
| **das Wohnzimmer** | le salon |
| **das Schlafzimmer** | la chambre (à coucher) |
| **das Badezimmer** | la salle de bain |
| **der Garten** | le jardin |

Pour présenter une pièce, on dit **Das ist …** : *Das ist die Küche.* (C'est la cuisine.)

## 2. Les meubles (die Möbel)

| Allemand | Traduction |
|---|---|
| **der Tisch** | la table |
| **der Stuhl** | la chaise |
| **das Bett** | le lit |
| **das Sofa** | le canapé |
| **der Schrank** | l'armoire |
| **das Fenster / die Tür** | la fenêtre / la porte |

## 3. Dire où l'on se trouve : in + datif

Pour dire dans quelle pièce on est, on emploie **in** suivi de l'article au datif.

| Genre | Exemple | Traduction |
|---|---|---|
| masculin / neutre | Ich bin **im** Garten. (in dem → im) | Je suis dans le jardin. |
| neutre | Ich bin **im** Wohnzimmer. | Je suis dans le salon. |
| féminin | Ich bin **in der** Küche. | Je suis dans la cuisine. |

La question correspondante est **Wo bist du?** (Où es-tu ?).

## 4. Les erreurs à éviter

- Chaque pièce a son article : *die* Küche, *das* Haus, *der* Garten. Apprends le mot AVEC son article.
- **in dem** se contracte toujours en **im** : *im Garten*, *im Schlafzimmer*.
- Pour le féminin, on ne contracte pas : on dit **in der Küche** (et non *im Küche*).

## À retenir

- Pièces : die Küche, das Wohnzimmer, das Schlafzimmer, das Badezimmer, der Garten.
- Meubles : der Tisch, der Stuhl, das Bett, der Schrank.
- **Das ist …** pour présenter ; **Wo bist du?** pour demander où.
- Situer : **im** (masc./neutre) et **in der** (féminin).
