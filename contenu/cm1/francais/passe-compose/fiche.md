# Le passé composé

> Le passé composé raconte une action terminée dans le passé. « Hier, j'ai fini mes devoirs. » C'est un temps formé de deux mots : c'est pour cela qu'on l'appelle « composé ».

## 1. À quoi sert le passé composé ?

Le passé composé exprime une action **terminée** dans le passé. On l'utilise souvent pour raconter des événements qui se sont vraiment produits : « Nous **avons visité** un musée. »

## 2. Comment former le passé composé ?

Le passé composé se forme en deux parties :

**auxiliaire (avoir ou être au présent) + participe passé du verbe**

| Phrase | Auxiliaire | Participe passé |
|---|---|---|
| J'**ai mangé** une pomme. | ai (avoir) | mangé |
| Tu **as fini** ton travail. | as (avoir) | fini |
| Elle **est partie**. | est (être) | partie |
| Nous **sommes arrivés**. | sommes (être) | arrivés |

## 3. Choisir l'auxiliaire et le participe passé

La plupart des verbes se conjuguent avec **avoir**. Certains verbes de mouvement ou de changement d'état se conjuguent avec **être** : *aller, venir, partir, arriver, entrer, sortir, monter, descendre, tomber, naître, mourir, rester*.

Le participe passé se forme selon le groupe :
- 1er groupe (-er) → **-é** : chanter → chant**é**
- 2e groupe (-ir) → **-i** : finir → fin**i**
- 3e groupe → formes variées : prendre → pris, faire → fait, voir → vu, être → été, avoir → eu

**Attention à l'accord :** avec l'auxiliaire **être**, le participe passé s'accorde avec le sujet : « Elle est part**ie** », « Ils sont part**is** ».

## 4. Les erreurs à éviter

- Ne pas oublier l'auxiliaire : on écrit « j'ai chanté », jamais « j'chanté ».
- Ne pas confondre *-é* (participe passé : *j'ai mangé*) et *-er* (infinitif : *je vais manger*).
- Avec l'auxiliaire **avoir**, le participe passé ne s'accorde pas avec le sujet : « Elles ont chanté » (et non *chantées*).
- Avec l'auxiliaire **être**, ne pas oublier d'accorder : « Marie est venu**e** ».

## À retenir

- Le passé composé raconte une action terminée du passé.
- Il se forme avec **avoir ou être au présent + participe passé**.
- On accorde le participe passé avec le sujet quand l'auxiliaire est **être**.
- Attention à ne pas confondre le participe passé en *-é* et l'infinitif en *-er*.
