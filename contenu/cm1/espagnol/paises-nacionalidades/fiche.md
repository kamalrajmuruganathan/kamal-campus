# Países y nacionalidades

> D'où viens-tu ? En espagnol, on répond avec **Soy de...** (Je viens de...) ou avec une nationalité : **Soy francés / francesa**. Découvre les pays et les nationalités !

## 1. Les pays (los países)

| Espagnol | Traduction |
|---|---|
| **España** | l'Espagne |
| **Francia** | la France |
| **Inglaterra** | l'Angleterre |
| **Alemania** | l'Allemagne |
| **Italia** | l'Italie |
| **México** | le Mexique |

## 2. Les nationalités

La nationalité s'accorde : **-o** au masculin, **-a** au féminin. Elle s'écrit avec une **minuscule** !

| Pays | Masculin | Féminin |
|---|---|---|
| España | **español** | **española** |
| Francia | **francés** | **francesa** |
| Inglaterra | **inglés** | **inglesa** |
| Alemania | **alemán** | **alemana** |
| Italia | **italiano** | **italiana** |
| México | **mexicano** | **mexicana** |

## 3. Demander et dire l'origine

| Espagnol | Traduction |
|---|---|
| **¿De dónde eres?** | D'où viens-tu ? |
| **Soy de España.** | Je viens d'Espagne. |
| **Soy español.** / **Soy española.** | Je suis espagnol. / espagnole. |

On utilise le verbe **ser** (être) : *soy* (je suis), *eres* (tu es), *es* (il/elle est).

## 4. Les erreurs à éviter

- Les nationalités s'écrivent en **minuscule** en espagnol : *español*, pas *Español*.
- Mais les **pays** gardent la majuscule : *España*, *Francia*.
- Accorde au féminin : une fille dit *Soy francesa*, un garçon dit *Soy francés*.
- On utilise **ser** (soy), pas *estar* : *Soy español*.

## À retenir

- Pays : *España, Francia, Inglaterra, Alemania, Italia, México* (majuscule).
- Nationalités en minuscule, accordées : *español / española*, *francés / francesa*.
- **¿De dónde eres?** → **Soy de...** / **Soy + nationalité**.
- Verbe **ser** : soy, eres, es.
