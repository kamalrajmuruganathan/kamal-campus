# La casa

> Bienvenue à la maison ! En espagnol, on découvre les pièces (*las habitaciones*), les meubles (*los muebles*) et le petit mot magique **hay** (il y a). Apprends aussi à dire où se trouvent les choses !

## 1. Les pièces de la maison

| Espagnol | Traduction |
|---|---|
| **la cocina** | la cuisine |
| **el salón** | le salon |
| **el dormitorio** | la chambre |
| **el baño** | la salle de bain |
| **el jardín** | le jardin |

## 2. Les meubles (los muebles)

| Espagnol | Traduction |
|---|---|
| **la mesa** | la table |
| **la silla** | la chaise |
| **la cama** | le lit |
| **el sofá** | le canapé |
| **el armario** | l'armoire |

## 3. Dire ce qu'il y a : *hay*

Le mot **hay** signifie « il y a » (au singulier comme au pluriel) :

| Espagnol | Traduction |
|---|---|
| **En la cocina hay una mesa.** | Dans la cuisine, il y a une table. |
| **En el salón hay dos sofás.** | Dans le salon, il y a deux canapés. |

Pour situer, on utilise : **en** (dans), **encima de** (sur), **debajo de** (sous), **al lado de** (à côté de).

| Espagnol | Traduction |
|---|---|
| **El libro está encima de la mesa.** | Le livre est sur la table. |
| **El gato está debajo de la cama.** | Le chat est sous le lit. |

## 4. Les erreurs à éviter

- **hay** ne change jamais : *hay una mesa*, *hay dos mesas* (jamais « hayn »).
- Attention au genre : on dit *la mesa* (féminin) mais *el sofá* (masculin).
- Pour situer un objet précis, on utilise **está** (est) : *El gato está debajo de la cama.*

## À retenir

- Pièces : *la cocina, el salón, el dormitorio, el baño, el jardín*.
- Meubles : *la mesa, la silla, la cama, el sofá, el armario*.
- **hay** = il y a (invariable).
- Situer : *en, encima de, debajo de, al lado de*.
