# La comida

> On apprend les mots espagnols pour parler de la nourriture : *el pan*, *la leche*, *la manzana*... Tu vas pouvoir dire ce que tu aimes manger !

## 1. Les aliments et les boissons

| Espagnol | Français |
|---|---|
| el pan | le pain |
| el agua | l'eau |
| la leche | le lait |
| la manzana | la pomme |
| el plátano | la banane |
| la naranja | l'orange |
| el queso | le fromage |
| el huevo | l'œuf |
| el pollo | le poulet |
| el pescado | le poisson |
| el arroz | le riz |
| el tomate | la tomate |
| la fruta | le fruit |
| el chocolate | le chocolat |

## 2. Dire ce que j'aime

Pour dire « j'aime », on utilise **me gusta** :

| Espagnol | Français |
|---|---|
| Me gusta el pan. | J'aime le pain. |
| Me gusta la leche. | J'aime le lait. |
| No me gusta el pescado. | Je n'aime pas le poisson. |

Pour dire « je veux », on utilise **quiero** : *Quiero agua.* (Je veux de l'eau.)

## 3. À table !

Quelques phrases utiles pour manger :

- *Tengo hambre.* → J'ai faim.
- *Tengo sed.* → J'ai soif.
- *¡Qué rico!* → C'est délicieux !

## 4. Les erreurs à éviter

- *la naranja* veut dire « l'orange » (le fruit) mais aussi la couleur orange.
- Ne confonds pas *el pan* (le pain) et *el plátano* (la banane).
- On dit *el agua* même si c'est un mot féminin (c'est un cas spécial).

## À retenir

- La nourriture se dit **la comida**.
- *pan* = pain, *leche* = lait, *manzana* = pomme, *agua* = eau.
- Pour dire « j'aime », on utilise **me gusta**.
- Pour dire « je veux », on utilise **quiero**.
