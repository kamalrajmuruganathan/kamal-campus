# Los días de la semana

> On apprend les jours de la semaine en espagnol : *lunes*, *martes*, *miércoles*... Tu vas pouvoir dire quel jour on est !

## 1. Les sept jours

| Espagnol | Français |
|---|---|
| lunes | lundi |
| martes | mardi |
| miércoles | mercredi |
| jueves | jeudi |
| viernes | vendredi |
| sábado | samedi |
| domingo | dimanche |

Attention : en espagnol, les jours de la semaine s'écrivent avec une **petite lettre** (pas de majuscule) !

## 2. Des mots utiles

| Espagnol | Français |
|---|---|
| la semana | la semaine |
| el fin de semana | le week-end |
| hoy | aujourd'hui |
| mañana | demain |
| ayer | hier |

## 3. Dire quel jour on est

Pour dire quel jour on est, on utilise **es** ou **hoy es** :

- *Hoy es lunes.* → Aujourd'hui, c'est lundi.
- *Mañana es martes.* → Demain, c'est mardi.
- *Ayer fue domingo.* → Hier, c'était dimanche.

## 4. Les erreurs à éviter

- On n'écrit **pas** de majuscule aux jours : on écrit *lunes*, pas *Lunes*.
- Ne confonds pas *jueves* (jeudi) et *viernes* (vendredi).
- *mañana* veut dire « demain », mais aussi « le matin » selon la phrase.

## À retenir

- La semaine se dit **la semana** et compte sept jours.
- Les jours : *lunes, martes, miércoles, jueves, viernes, sábado, domingo*.
- Les jours s'écrivent avec une petite lettre.
- *hoy* = aujourd'hui, *mañana* = demain, *ayer* = hier.
