# La familia

> On apprend les mots espagnols pour parler des personnes de sa famille : *padre*, *madre*, *hermano*, *hermana*... Tu vas pouvoir présenter les gens que tu aimes !

## 1. Les mots de la famille

Voici les mots les plus importants.

| Espagnol | Français |
|---|---|
| el padre / papá | le père / papa |
| la madre / mamá | la mère / maman |
| el hermano | le frère |
| la hermana | la sœur |
| el abuelo | le grand-père |
| la abuela | la grand-mère |
| el tío | l'oncle |
| la tía | la tante |
| el primo | le cousin |
| la prima | la cousine |
| el hijo | le fils |
| la hija | la fille |
| el bebé | le bébé |
| la familia | la famille |

## 2. Garçon ou fille ?

En espagnol, beaucoup de mots changent la fin selon qu'on parle d'un garçon ou d'une fille :
le garçon se termine souvent par **-o** et la fille par **-a**.

| Garçon (-o) | Fille (-a) |
|---|---|
| herman**o** (le frère) | herman**a** (la sœur) |
| abuel**o** (le grand-père) | abuel**a** (la grand-mère) |
| tí**o** (l'oncle) | tí**a** (la tante) |
| prim**o** (le cousin) | prim**a** (la cousine) |

On dit **el** devant un garçon (*el hermano*) et **la** devant une fille (*la hermana*).

## 3. Dire à qui appartient la famille

Pour dire « mon » ou « ma », on utilise **mi** : *mi padre* (mon père), *mi hermana* (ma sœur).
Pour dire « c'est... », on utilise **es** : *Es mi madre.* (C'est ma mère.)

- *Es mi hermano.* → C'est mon frère.
- *Mi abuela es simpática.* → Ma grand-mère est gentille.

## 4. Les erreurs à éviter

- Ne confonds pas **-o** (garçon) et **-a** (fille) : on dit *el hermano* pour un frère, *la hermana* pour une sœur.
- *madre* veut dire « mère » (et pas « maire ») ; *padre* veut dire « père ».
- En espagnol, la lettre **ñ** existe : *niño* (garçon) se lit « niño ».

## À retenir

- La famille se dit **la familia**.
- *padre* = père, *madre* = mère, *hermano* = frère, *hermana* = sœur.
- Les mots en **-o** sont souvent des garçons, ceux en **-a** des filles.
- Pour dire « mon / ma », on utilise **mi**.
