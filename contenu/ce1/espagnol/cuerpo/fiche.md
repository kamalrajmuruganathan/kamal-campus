# El cuerpo

> On apprend les mots espagnols pour nommer les parties du corps : *la cabeza*, *la mano*, *el pie*... Tu vas pouvoir montrer et nommer chaque partie de ton corps !

## 1. Les parties du corps

| Espagnol | Français |
|---|---|
| la cabeza | la tête |
| el pelo | les cheveux |
| la cara | le visage |
| el ojo (los ojos) | l'œil (les yeux) |
| la nariz | le nez |
| la boca | la bouche |
| la oreja | l'oreille |
| el diente | la dent |
| el brazo | le bras |
| la mano | la main |
| el dedo | le doigt |
| la pierna | la jambe |
| el pie (los pies) | le pied (les pieds) |
| el cuerpo | le corps |

## 2. Un ou plusieurs ? (le pluriel)

Pour dire qu'il y en a plusieurs, on ajoute souvent un **-s** à la fin du mot,
et l'article devient **los** (garçons) ou **las** (filles).

| Un seul | Plusieurs |
|---|---|
| el ojo (un œil) | los ojo**s** (les yeux) |
| la mano (une main) | las mano**s** (les mains) |
| el pie (un pied) | los pie**s** (les pieds) |
| la oreja (une oreille) | las oreja**s** (les oreilles) |

## 3. Dire ce que j'ai

Pour dire « j'ai », on utilise **tengo** :

- *Tengo dos ojos.* → J'ai deux yeux.
- *Tengo una nariz.* → J'ai un nez.
- *Me duele la cabeza.* → J'ai mal à la tête.

## 4. Les erreurs à éviter

- *la mano* finit par **-o** mais c'est bien un mot féminin : on dit **la** mano (pas *el mano*).
- Ne confonds pas *oreja* (l'oreille) et *ojo* (l'œil).
- *el pelo* (au singulier) veut dire « les cheveux » en français.

## À retenir

- Le corps se dit **el cuerpo**.
- *cabeza* = tête, *mano* = main, *pie* = pied, *ojo* = œil.
- Au pluriel, on ajoute **-s** : *los ojos*, *las manos*.
- Pour dire « j'ai », on utilise **tengo**.
