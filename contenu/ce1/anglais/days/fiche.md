# Days of the week: les jours de la semaine

> Apprends les sept jours de la semaine en anglais, de *Monday* à *Sunday*. En anglais, les jours prennent toujours une majuscule !

## 1. Les sept jours

| Anglais | Français |
|---|---|
| Monday | lundi |
| Tuesday | mardi |
| Wednesday | mercredi |
| Thursday | jeudi |
| Friday | vendredi |
| Saturday | samedi |
| Sunday | dimanche |

En anglais, les jours de la semaine commencent **toujours par une majuscule**.

## 2. Avant et après

Pour ranger les jours dans l'ordre :

| Exemple | Traduction |
|---|---|
| After **Monday** is **Tuesday**. | Après lundi, c'est mardi. |
| Before **Sunday** is **Saturday**. | Avant dimanche, c'est samedi. |

## 3. Les mots du temps

| Anglais | Français |
|---|---|
| day | le jour |
| week | la semaine |
| weekend | le week-end |
| today | aujourd'hui |
| tomorrow | demain |
| yesterday | hier |

| Exemple | Traduction |
|---|---|
| Today is **Monday**. | Aujourd'hui, c'est lundi. |
| Tomorrow is **Tuesday**. | Demain, c'est mardi. |

## 4. Les erreurs à éviter
- On écrit *Monday*, *Friday*... avec une **majuscule**, même au milieu d'une phrase.
- *today* (aujourd'hui), *tomorrow* (demain) et *yesterday* (hier) : ne les mélange pas.

## À retenir
- Les 7 jours : Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.
- Les jours prennent toujours une majuscule.
- week = semaine, weekend = week-end, day = jour.
- today = aujourd'hui, tomorrow = demain, yesterday = hier.
