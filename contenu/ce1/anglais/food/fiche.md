# Food: la nourriture

> Découvre les mots anglais pour la nourriture : *apple*, *bread*, *milk*, *cake*... De quoi parler de ce que tu aimes manger !

## 1. Les aliments

| Anglais | Français |
|---|---|
| apple | la pomme |
| banana | la banane |
| orange | l'orange |
| tomato | la tomate |
| bread | le pain |
| cheese | le fromage |
| egg | l'œuf |
| rice | le riz |

## 2. La viande, le poisson et les gourmandises

| Anglais | Français |
|---|---|
| meat | la viande |
| fish | le poisson |
| chicken | le poulet |
| cake | le gâteau |
| chocolate | le chocolat |
| candy | le bonbon |

## 3. Les boissons et manger

| Anglais | Français |
|---|---|
| water | l'eau |
| milk | le lait |
| juice | le jus |
| breakfast | le petit-déjeuner |

Pour dire ce qu'on fait, on utilise **eat** (manger) et **drink** (boire).

| Exemple | Traduction |
|---|---|
| I **eat** an apple. | Je mange une pomme. |
| I **drink** water. | Je bois de l'eau. |

## 4. Les erreurs à éviter
- Devant *apple*, *egg*, *orange* (qui commencent par un son voyelle) on dit **an** : *an apple*.
- *eat* (manger) et *drink* (boire) : on **mange** un gâteau mais on **boit** du lait.

## À retenir
- apple = pomme, bread = pain, cheese = fromage.
- water = eau, milk = lait, juice = jus.
- eat = manger, drink = boire.
- breakfast = le petit-déjeuner.
