# Family: la famille

> On apprend les mots anglais pour parler des personnes de sa famille : *mum*, *dad*, *brother*, *sister*... Tu vas pouvoir présenter les gens que tu aimes !

## 1. Les mots de la famille

Voici les mots les plus importants.

| Anglais | Français |
|---|---|
| mother / mum | la mère / maman |
| father / dad | le père / papa |
| sister | la sœur |
| brother | le frère |
| baby | le bébé |
| family | la famille |

*mum* et *dad* sont les mots que l'on utilise à la maison, comme « maman » et « papa ».

## 2. Les grands-parents et le reste de la famille

| Anglais | Français |
|---|---|
| grandmother / grandma | la grand-mère / mamie |
| grandfather / grandpa | le grand-père / papy |
| aunt | la tante |
| uncle | l'oncle |
| cousin | le cousin / la cousine |
| parents | les parents |

## 3. Présenter quelqu'un

Pour montrer une personne, on dit **This is...** (« Voici... »).

| Exemple | Traduction |
|---|---|
| This is my **mum**. | Voici ma maman. |
| This is my **brother**. | Voici mon frère. |
| I love my **family**. | J'aime ma famille. |

## 4. Les erreurs à éviter
- On ne dit pas *mother* de son frère : un garçon est **brother**, une fille est **sister**.
- *aunt* (tante) et *uncle* (oncle) : ne les confonds pas.

## À retenir
- mum = maman, dad = papa.
- brother = frère (garçon), sister = sœur (fille).
- grandmother = grand-mère, grandfather = grand-père.
- Pour présenter : **This is my...**
