# My body: le corps

> Apprends à nommer les parties de ton corps en anglais : *head*, *hand*, *eyes*, *nose*... Tu pourras montrer et dire chaque partie !

## 1. La tête et le visage

| Anglais | Français |
|---|---|
| head | la tête |
| hair | les cheveux |
| face | le visage |
| eye / eyes | l'œil / les yeux |
| ear / ears | l'oreille / les oreilles |
| nose | le nez |
| mouth | la bouche |
| tooth / teeth | la dent / les dents |

## 2. Le corps, les bras et les jambes

| Anglais | Français |
|---|---|
| body | le corps |
| arm | le bras |
| hand | la main |
| finger / fingers | le doigt / les doigts |
| leg | la jambe |
| knee | le genou |
| foot / feet | le pied / les pieds |

## 3. J'utilise mon corps

| Exemple | Traduction |
|---|---|
| I see with my **eyes**. | Je vois avec mes yeux. |
| I hear with my **ears**. | J'entends avec mes oreilles. |
| I walk with my **feet**. | Je marche avec mes pieds. |

## 4. Les erreurs à éviter
- *eye* (un œil) → *eyes* (les yeux) : on ajoute **-s** au pluriel.
- *foot* (un pied) devient *feet* (les pieds) ; *tooth* devient *teeth*. Ces pluriels sont spéciaux.
- Ne confonds pas *hair* (cheveux) et *head* (tête).

## À retenir
- head = tête, hair = cheveux, face = visage.
- eyes = yeux, ears = oreilles, nose = nez, mouth = bouche.
- hand = main, foot = pied (pluriel : feet).
- body = le corps.
