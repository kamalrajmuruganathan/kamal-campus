# Les figures planes

Une **figure plane**, c'est une forme dessinée à plat, sur une feuille.
En CE1, on apprend à reconnaître et à décrire le **carré**, le **rectangle**,
le **triangle** et le **cercle**.

## Le vocabulaire

Pour décrire une figure, on regarde :

- les **côtés** : les bords droits de la figure ;
- les **sommets** : les coins, là où deux côtés se rencontrent ;
- les **angles droits** : les coins « bien carrés », comme le coin d'une feuille.

On vérifie un angle droit avec l'**équerre** ou le coin d'une feuille.

## Le carré

Le carré a :

- **4 côtés** de la **même longueur** ;
- **4 sommets** (4 coins) ;
- **4 angles droits**.

Toutes ses côtés sont égaux : c'est ce qui le rend « bien carré ».

## Le rectangle

Le rectangle a :

- **4 côtés** et **4 angles droits**, comme le carré ;
- mais les côtés ne sont pas tous égaux : les côtés en face sont égaux **deux à
  deux** (deux longs et deux courts).

Un carré est un rectangle un peu spécial dont tous les côtés sont égaux.

## Le triangle

Le triangle a :

- **3 côtés** ;
- **3 sommets**.

Il n'a pas toujours d'angle droit.

## Le cercle

Le cercle est **tout rond** : il n'a **pas de côté** ni de **sommet**.
On le trace avec un **compas**. Le **centre** est le point du milieu.

## Les erreurs à éviter

- Ne confonds pas carré et rectangle : le carré a **tous** ses côtés égaux.
- Le cercle n'a pas de coin : ne dis pas qu'il a des côtés.
- Compte bien : un triangle a 3 côtés et 3 sommets, pas 4.
- Un angle droit se vérifie, on ne le devine pas seulement à l'œil.
