# Le calendrier et la frise du temps

> Le temps passe toujours dans le même sens : hier, aujourd'hui, demain. Le calendrier et la frise nous aident à ranger les jours, les mois et les événements dans l'ordre.

## 1. Les jours et la semaine
Une **semaine** compte **7 jours**, toujours dans le même ordre :
lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche.

- La journée d'**avant** aujourd'hui s'appelle **hier**.
- La journée d'**après** aujourd'hui s'appelle **demain**.

## 2. Les mois et l'année
Une **année** compte **12 mois**, toujours dans le même ordre :

| Rang | Mois |
|---|---|
| 1 | janvier |
| 2 | février |
| 3 | mars |
| 4 | avril |
| 5 | mai |
| 6 | juin |
| 7 | juillet |
| 8 | août |
| 9 | septembre |
| 10 | octobre |
| 11 | novembre |
| 12 | décembre |

Le premier mois de l'année est **janvier**, le dernier est **décembre**.

## 3. Les quatre saisons
L'année a **4 saisons** : le **printemps**, l'**été**, l'**automne** et l'**hiver**.
Elles reviennent toujours dans le même ordre.

## 4. La frise du temps
Une **frise** est une ligne qui va de gauche (le passé) vers la droite (le futur).
On y place les événements dans l'**ordre** où ils se sont passés.
- Le **passé** : ce qui est déjà arrivé.
- Le **présent** : maintenant.
- Le **futur** : ce qui n'est pas encore arrivé.

## 5. Les erreurs à éviter
- Ne pas confondre **jour** (7 par semaine) et **mois** (12 par an).
- « Hier » est dans le passé, « demain » est dans le futur : ne pas les inverser.
- Sur une frise, on va toujours du passé (gauche) vers le futur (droite).

## À retenir
- La semaine a **7 jours**, l'année a **12 mois** et **4 saisons**.
- Le premier mois est **janvier**, le dernier est **décembre**.
- La frise du temps va du **passé** (gauche) vers le **futur** (droite).
- Hier = passé, aujourd'hui = présent, demain = futur.
