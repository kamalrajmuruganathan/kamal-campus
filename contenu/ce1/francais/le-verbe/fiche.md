# Le verbe et son infinitif

> Dans une phrase, il y a très souvent un mot qui dit ce qu'on **fait** : courir, manger, dormir, chanter… Ce mot magique, c'est le **verbe**. Sans lui, la phrase ne veut rien dire !

## 1. Qu'est-ce qu'un verbe ?

Le **verbe** est le mot qui dit une **action** (ce qu'on fait) ou un **état** (comment on est).

| Ce que dit le verbe | Exemple | Le verbe |
|---|---|---|
| une action | Le chien **court** dans le jardin. | court |
| une action | Nous **mangeons** une pomme. | mangeons |
| un état | Léa **est** contente. | est |

Pour trouver le verbe, on peut se demander : **« Qu'est-ce qu'on fait ? »**
Dans *Papa lave la voiture*, on fait l'action de **laver** : le verbe est **lave**.

## 2. Le verbe change, l'infinitif ne change pas

Dans une phrase, le verbe **change** selon la personne et le moment.

| Phrase | Verbe dans la phrase | Infinitif |
|---|---|---|
| Je **mange** une pomme. | mange | manger |
| Tu **manges** une pomme. | manges | manger |
| Hier, nous **mangions**. | mangions | manger |

L'**infinitif**, c'est le nom du verbe, celui qu'on trouve dans le dictionnaire : *manger, finir, prendre, être*. Il ne change jamais.
Pour trouver l'infinitif, on dit : **« il faut… »** → *il faut manger* → l'infinitif est **manger**.

## 3. Les erreurs à éviter

- Ne pas confondre le **nom** et le **verbe** : *le dessin* (nom) et *je dessine* (verbe).
- L'infinitif se termine souvent par **-er** (manger), **-ir** (finir), **-re** (prendre) ou **-oir** (voir).
- Le verbe **change** dans la phrase, mais son infinitif reste toujours pareil.
- Il y a toujours un verbe dans une phrase, même s'il est petit : *Elle **est** là.*

## À retenir

- Le **verbe** dit une action ou un état.
- Pour le trouver, on demande **« Qu'est-ce qu'on fait ? »**
- Le verbe **change** dans la phrase (je mange, tu manges).
- L'**infinitif** est le nom du verbe ; on le trouve avec **« il faut… »** (il faut manger → manger).
