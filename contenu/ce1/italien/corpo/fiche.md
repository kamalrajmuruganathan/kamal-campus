# Il corpo

> La tête, les yeux, les mains... Apprends à nommer les parties du corps en italien pour parler de toi et jouer à « Jacques a dit » : « Toccati il naso ! » (Touche ton nez !).

## 1. Les parties du corps

| Italien | Français |
|---|---|
| la testa | la tête |
| i capelli | les cheveux |
| l'occhio / gli occhi | l'œil / les yeux |
| il naso | le nez |
| la bocca | la bouche |
| l'orecchio / le orecchie | l'oreille / les oreilles |
| la mano | la main |
| il braccio | le bras |
| la gamba | la jambe |
| il piede | le pied |
| la pancia | le ventre |
| il dito | le doigt |

## 2. Un ou plusieurs ?

En italien, le pluriel change souvent la fin du mot.

| Singulier | Pluriel | Français |
|---|---|---|
| l'occhi**o** | gli occh**i** | l'œil → les yeux |
| la gamb**a** | le gamb**e** | la jambe → les jambes |
| il pied**e** | i pied**i** | le pied → les pieds |

Les mots en **-o** font leur pluriel en **-i**, les mots en **-a** font leur pluriel en **-e**.

## 3. Parler de son corps

- **Ho due occhi.** = J'ai deux yeux.
- **Mi fa male la testa.** = J'ai mal à la tête.
- **Tocca il naso!** = Touche le nez !

## 4. Les erreurs à éviter

- **la mano** est féminin, même s'il finit par -o : on dit **la** mano.
- **la bocca** s'écrit avec deux « c » : attention aux doubles consonnes.
- « les cheveux » se dit **i capelli** (au pluriel), pas « il capello ».

## À retenir

- **la testa** = la tête, **i capelli** = les cheveux.
- **gli occhi / il naso / la bocca** = les yeux / le nez / la bouche.
- **la mano / il piede** = la main / le pied.
- Les mots en -o font leur pluriel en **-i**, ceux en -a en **-e**.
- **la mano** est féminin même s'il finit par -o.
