# I giorni della settimana

> Lundi, mardi, mercredi... En italien, les jours de la semaine ressemblent beaucoup au français ! Apprends-les pour dire quel jour on est.

## 1. Les sept jours

Attention : en italien, les jours de la semaine s'écrivent avec une **petite lettre** (pas de majuscule).

| Italien | Français |
|---|---|
| lunedì | lundi |
| martedì | mardi |
| mercoledì | mercredi |
| giovedì | jeudi |
| venerdì | vendredi |
| sabato | samedi |
| domenica | dimanche |

Beaucoup de jours finissent par **-dì** avec un accent (lunedì, martedì...). Cet accent se prononce et se voit à l'écrit.

## 2. Aujourd'hui, demain, hier

| Italien | Français |
|---|---|
| oggi | aujourd'hui |
| domani | demain |
| ieri | hier |
| la settimana | la semaine |

## 3. Dire quel jour on est

- **Oggi è lunedì.** = Aujourd'hui, c'est lundi.
- **Domani è martedì.** = Demain, c'est mardi.
- **Che giorno è oggi?** = Quel jour sommes-nous aujourd'hui ?

## 4. Les erreurs à éviter

- N'écris pas de majuscule aux jours : on écrit **lunedì**, pas « Lunedì ».
- N'oublie pas l'accent sur **-dì** (lunedì, martedì, mercoledì, giovedì, venerdì).
- **sabato** et **domenica** ne prennent pas d'accent final.

## À retenir

- Les jours : **lunedì, martedì, mercoledì, giovedì, venerdì, sabato, domenica**.
- Les jours s'écrivent en minuscule en italien.
- **oggi / domani / ieri** = aujourd'hui / demain / hier.
- **Oggi è...** = Aujourd'hui, c'est...
- Cinq jours finissent par **-dì** avec un accent.
