# Il cibo

> Pizza, pasta, gelato... L'Italie est le pays de la bonne cuisine ! Apprends à nommer les aliments pour dire ce que tu aimes manger.

## 1. Les aliments

| Italien | Français |
|---|---|
| il pane | le pain |
| la pasta | les pâtes |
| la pizza | la pizza |
| il formaggio | le fromage |
| il latte | le lait |
| l'acqua | l'eau |
| la mela | la pomme |
| la banana | la banane |
| il pomodoro | la tomate |
| il gelato | la glace |
| la frutta | les fruits |
| la verdura | les légumes |

## 2. Dire ce qu'on aime

Pour dire qu'on aime, on utilise **mi piace** (au singulier) et **mi piacciono** (au pluriel).

| Italien | Français |
|---|---|
| Mi piace la pizza. | J'aime la pizza. |
| Mi piace il gelato. | J'aime la glace. |
| Mi piacciono le mele. | J'aime les pommes. |

## 3. À table !

- **Ho fame.** = J'ai faim.
- **Ho sete.** = J'ai soif.
- **Buon appetito!** = Bon appétit !
- **Vorrei una pizza.** = Je voudrais une pizza.

## 4. Les erreurs à éviter

- **la pasta** en italien = les pâtes (le plat), pas la « pâte » à modeler.
- **il formaggio** s'écrit avec deux « g » : attention à la double consonne.
- **l'acqua** s'écrit avec « cq » : c'est un mot un peu piège.

## À retenir

- **il pane / la pasta / la pizza** = le pain / les pâtes / la pizza.
- **il latte / l'acqua** = le lait / l'eau.
- **la frutta / la verdura** = les fruits / les légumes.
- **Mi piace...** = J'aime... (au singulier).
- **Ho fame / Ho sete** = J'ai faim / J'ai soif.
