# Das Essen

> À table ! On va apprendre les mots de la nourriture et des boissons en allemand. Comme toujours, chaque nom prend une **majuscule**.

## 1. Ce qu'on mange (das Essen)

| Allemand | Français |
|---|---|
| das Essen | la nourriture / le repas |
| das Brot | le pain |
| der Käse | le fromage |
| die Butter | le beurre |
| das Ei | l'œuf |
| die Wurst | la saucisse |
| der Apfel | la pomme |
| die Banane | la banane |
| der Kuchen | le gâteau |

Exemple : **Ich esse ein Brot.** (Je mange un pain.)

## 2. Ce qu'on boit (die Getränke)

| Allemand | Français |
|---|---|
| das Wasser | l'eau |
| die Milch | le lait |
| der Saft | le jus |
| der Tee | le thé |

Exemple : **Ich trinke Milch.** (Je bois du lait.)

## 3. Dire « j'aime » avec les aliments

Pour dire qu'on aime manger quelque chose, on utilise le petit mot **gern** (volontiers).

| Phrase | Traduction |
|---|---|
| Ich esse **gern** Käse. | J'aime manger du fromage. |
| Ich trinke **gern** Saft. | J'aime boire du jus. |

- **essen** = manger
- **trinken** = boire

## 4. Les erreurs à éviter
- **das Brot** (le pain) : c'est un mot neutre, on dit *das*, pas *der*.
- Ne confonds pas **essen** (manger) et **trinken** (boire).
- Majuscule partout : der Apfel, die Milch, das Ei.

## À retenir
- Manger = **essen** ; boire = **trinken**.
- Aliments : **das Brot, der Käse, das Ei, der Apfel, die Banane**.
- Boissons : **das Wasser, die Milch, der Saft**.
- **gern** sert à dire qu'on aime : Ich esse gern Kuchen.
