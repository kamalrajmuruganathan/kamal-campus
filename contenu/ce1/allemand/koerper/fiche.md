# Der Körper

> Le corps, c'est **der Körper**. On va apprendre à nommer la tête, les yeux, les mains... N'oublie pas la majuscule et les Umlauts (les deux petits points sur ä, ö, ü) !

## 1. La tête (der Kopf)

| Allemand | Français |
|---|---|
| der Kopf | la tête |
| das Auge | l'œil |
| die Augen | les yeux |
| die Nase | le nez |
| der Mund | la bouche |
| das Ohr | l'oreille |
| die Ohren | les oreilles |
| das Haar / die Haare | le cheveu / les cheveux |

Exemple : **Meine Augen sind blau.** (Mes yeux sont bleus.)

## 2. Le corps (der Körper)

| Allemand | Français |
|---|---|
| der Arm | le bras |
| die Hand | la main |
| das Bein | la jambe |
| der Fuß | le pied |
| der Bauch | le ventre |
| der Rücken | le dos |

Attention : **der Fuß** s'écrit avec un **ß** (le « s » spécial allemand).

## 3. Le singulier et le pluriel

Souvent, on a deux parties du corps : le mot change au pluriel.

| Un seul | Plusieurs |
|---|---|
| das Auge (un œil) | die Augen (les yeux) |
| das Ohr (une oreille) | die Ohren (les oreilles) |
| die Hand (une main) | die Hände (les mains) |
| der Fuß (un pied) | die Füße (les pieds) |

Remarque : au pluriel, le petit mot devient toujours **die**.

## 4. Les erreurs à éviter
- On écrit **der Fuß** avec ß, pas « Fuss ».
- Les Umlauts sont importants : die **Hände** (les mains), die **Füße** (les pieds).
- Tous les noms prennent une **majuscule** : der Kopf, die Nase.

## À retenir
- Le corps = **der Körper** ; la tête = **der Kopf**.
- Sur le visage : **das Auge, die Nase, der Mund, das Ohr**.
- Le corps : **der Arm, die Hand, das Bein, der Fuß**.
- Au pluriel, l'article devient **die** : die Augen, die Hände, die Füße.
