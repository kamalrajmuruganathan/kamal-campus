# Die Wochentage

> Lundi, mardi, mercredi... En allemand, les jours de la semaine s'appellent **die Wochentage**. Ils prennent tous une **majuscule** et beaucoup finissent par *-tag* (jour) !

## 1. Les sept jours

| Allemand | Français |
|---|---|
| der Montag | lundi |
| der Dienstag | mardi |
| der Mittwoch | mercredi |
| der Donnerstag | jeudi |
| der Freitag | vendredi |
| der Samstag | samedi |
| der Sonntag | dimanche |

Astuce : presque tous finissent par **-tag** (= jour). Seul **Mittwoch** (le « milieu de la semaine ») est différent.

## 2. La semaine et le week-end

| Allemand | Français |
|---|---|
| die Woche | la semaine |
| das Wochenende | le week-end |
| heute | aujourd'hui |
| morgen | demain |
| gestern | hier |

Exemple : **Heute ist Montag.** (Aujourd'hui, c'est lundi.)

## 3. Dire quel jour on est

On utilise le petit mot **am** pour dire « le » + un jour.

| Phrase | Traduction |
|---|---|
| **Am Montag** gehe ich zur Schule. | Le lundi, je vais à l'école. |
| Heute ist **Freitag**. | Aujourd'hui, c'est vendredi. |
| **Am Wochenende** spiele ich. | Le week-end, je joue. |

## 4. Les erreurs à éviter
- Tous les jours prennent une **majuscule** : der Montag, der Sonntag.
- Attention à **Mittwoch** : il ne finit pas par -tag.
- « aujourd'hui » = **heute** (avec un h au début).

## À retenir
- Les 7 jours : **Montag, Dienstag, Mittwoch, Donnerstag, Freitag, Samstag, Sonntag**.
- La plupart finissent par **-tag**.
- La semaine = **die Woche** ; le week-end = **das Wochenende**.
- **heute** = aujourd'hui, **morgen** = demain, **gestern** = hier.
