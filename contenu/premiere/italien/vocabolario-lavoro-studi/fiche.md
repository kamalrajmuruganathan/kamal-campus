# Vocabulaire : travail et études

> Choisir une orientation, chercher un emploi, décrire un métier : ce lexique te permet de parler de ton parcours scolaire et du monde du travail en italien, avec les nuances utiles à l'oral comme à l'écrit.

## 1. Gli studi (les études)

| Italien | Français | Remarque |
|---|---|---|
| il liceo | le lycée | *il liceo classico/scientifico* |
| l'università (f.) | l'université | *iscriversi* = s'inscrire |
| la laurea | le diplôme universitaire | *laurearsi* = obtenir sa licence |
| la materia | la matière | *la materia preferita* |
| il voto | la note | *un bel voto* = une bonne note |
| l'esame (m.) | l'examen | *superare un esame* = réussir un examen |
| la borsa di studio | la bourse d'études | |

**Exemples :**
- *Mi sono iscritto all'università di Bologna.* → Je me suis inscrit à l'université de Bologne.
- *Ha superato tutti gli esami.* → Il a réussi tous ses examens.

## 2. Il mondo del lavoro (le monde du travail)

| Italien | Français |
|---|---|
| il lavoro / l'impiego | le travail / l'emploi |
| l'azienda / la ditta | l'entreprise |
| il colloquio (di lavoro) | l'entretien (d'embauche) |
| il contratto | le contrat |
| lo stipendio | le salaire |
| il/la dipendente | le/la salarié(e) |
| il datore di lavoro | l'employeur |
| la disoccupazione | le chômage |
| il tirocinio | le stage |

**Exemples :**
- *Ho un colloquio di lavoro domani.* → J'ai un entretien d'embauche demain.
- *La disoccupazione giovanile è un problema serio.* → Le chômage des jeunes est un problème sérieux.

## 3. Les erreurs à éviter

- **il colloquio** = l'entretien d'embauche (faux ami : ce n'est pas un « colloque »).
- **lo stipendio** = le salaire (mensuel) ; ne pas confondre avec *il salario* (plus technique).
- **la laurea** = le diplôme universitaire, pas *« le laurier »*.
- **superare un esame** = réussir un examen (pas *« passare »*, qui signifie seulement le passer).

## À retenir

- L'université = **l'università** ; s'inscrire = **iscriversi** ; le diplôme = **la laurea**.
- L'entretien d'embauche = **il colloquio** (faux ami).
- Le salaire = **lo stipendio** ; le chômage = **la disoccupazione**.
- Réussir un examen = **superare un esame**.
