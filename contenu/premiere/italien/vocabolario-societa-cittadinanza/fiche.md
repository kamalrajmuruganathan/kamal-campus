# Vocabulaire : société et citoyenneté

> Droits, devoirs, démocratie, vie en société : ce lexique te donne les mots pour parler de la citoyenneté, débattre de questions de société et exprimer une opinion argumentée en italien.

## 1. La cittadinanza e le istituzioni

| Italien | Français | Remarque |
|---|---|---|
| il cittadino / la cittadina | le citoyen / la citoyenne | |
| il diritto | le droit | *i diritti umani* = les droits de l'homme |
| il dovere | le devoir | |
| la legge | la loi | *rispettare la legge* |
| lo Stato | l'État | |
| il governo | le gouvernement | |
| la democrazia | la démocratie | |
| il voto / votare | le vote / voter | *le elezioni* = les élections |

**Exemples :**
- *Ogni cittadino ha diritti e doveri.* → Chaque citoyen a des droits et des devoirs.
- *È importante andare a votare.* → Il est important d'aller voter.

## 2. La vita in società

| Italien | Français |
|---|---|
| l'uguaglianza (f.) | l'égalité |
| la libertà | la liberté |
| la giustizia | la justice |
| il rispetto | le respect |
| la solidarietà | la solidarité |
| l'impegno (m.) | l'engagement |
| il volontariato | le bénévolat |
| la manifestazione | la manifestation |

**Exemples :**
- *I giovani si impegnano nel volontariato.* → Les jeunes s'engagent dans le bénévolat.
- *Hanno partecipato a una manifestazione pacifica.* → Ils ont participé à une manifestation pacifique.

## 3. Les erreurs à éviter

- **la manifestazione** = la manifestation (dans la rue).
- **il diritto** = le droit ; ne pas confondre avec *diretto* (direct).
- **la legge** (double g) = la loi : soigne la double consonne.
- On dit **andare a votare** ou **votare**, pas *« fare il voto »* dans ce sens.

## À retenir

- Le citoyen = **il cittadino** ; les droits de l'homme = **i diritti umani**.
- La démocratie = **la democrazia** ; voter = **votare** ; les élections = **le elezioni**.
- Valeurs clés : **l'uguaglianza**, **la libertà**, **la solidarietà**.
- L'engagement = **l'impegno** ; le bénévolat = **il volontariato**.
