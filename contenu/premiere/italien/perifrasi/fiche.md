# Les périphrases : stare per, stare + gerundio…

> Pour dire qu'une action est *en train de se faire*, sur le point de commencer ou qu'elle continue, l'italien emploie des *perifrasi verbali* : des tournures faites d'un verbe support + gérondif ou + infinitif.

## 1. stare + gerundio : l'action en cours
Elle exprime une action **en train de se dérouler** au moment où l'on parle (équivalent de l'anglais *be + -ing*). Formation : **stare** (au présent ou à l'imperfetto) + **gérondif**.

Le gérondif se forme ainsi : -are → **-ando** (parlare → parl**ando**), -ere/-ire → **-endo** (leggere → legg**endo**, dormire → dorm**endo**).

| Exemple | Traduction |
|---|---|
| **Sto studiando** italiano. | Je suis en train d'étudier l'italien. |
| Che cosa **stai facendo**? | Qu'est-ce que tu es en train de faire ? |
| **Stavamo mangiando** quando è arrivato. | Nous étions en train de manger quand il est arrivé. |

## 2. stare per + infinitif : l'action imminente
Elle indique une action **sur le point de se produire** (= « être sur le point de », « aller »).

| Exemple | Traduction |
|---|---|
| Il treno **sta per** partire. | Le train est sur le point de partir. |
| **Stavo per** uscire quando ha telefonato. | J'étais sur le point de sortir quand il a appelé. |

## 3. Autres périphrases utiles
| Périphrase | Sens | Exemple |
|---|---|---|
| **continuare a** + inf. | continuer à | Continua a piovere. |
| **cominciare a / iniziare a** + inf. | commencer à | Ha cominciato a nevicare. |
| **finire di / smettere di** + inf. | finir de / arrêter de | Ho finito di studiare. / Smetti di parlare! |
| **andare / venire a** + inf. | aller / venir faire | Vado a comprare il pane. |
| **essere sul punto di** + inf. | être sur le point de | Ero sul punto di rinunciare. |

Le gérondif peut aussi s'employer seul pour exprimer la manière ou la simultanéité : *Cammina **cantando*** (Il marche en chantant).

## 4. Choisir la bonne préposition
Beaucoup de ces périphrases exigent une préposition fixe (**a** ou **di**) qu'il faut mémoriser :
- avec **a** : cominciare a, iniziare a, continuare a, andare a, venire a, imparare a.
- avec **di** : finire di, smettere di, cercare di, decidere di.

## 5. Les erreurs à éviter
- Employer *stare* + infinitif pour l'action en cours : ❌ *Sto studiare* → ✅ *Sto **studiando***.
- Confondre *stare per* (imminence) et *stare* + gérondif (action en cours).
- Se tromper de préposition : ❌ *comincio di studiare* → ✅ *comincio **a** studiare*.
- Employer le gérondif là où le français mettrait un infinitif : ❌ *Ho finito studiando* → ✅ *Ho finito **di studiare***.

## À retenir
- **stare + gérondif** = action en cours : *sto mangiando* (je suis en train de manger).
- **stare per + infinitif** = action imminente : *sto per partire* (je suis sur le point de partir).
- Gérondif : -are → **-ando**, -ere/-ire → **-endo**.
- Périphrases fréquentes : cominciare **a**, continuare **a**, finire **di**, smettere **di**.
- La préposition (a / di) est fixe : elle se mémorise avec le verbe.
