# Mythologie gréco-romaine : dieux et héros

> Les Romains ont largement repris les dieux grecs en leur donnant des noms latins. Connaître ces
> correspondances et les grands héros permet de comprendre l'art, la littérature et la culture antiques.

## 1. Les grands dieux et leurs correspondances
| Grec | Latin | Domaine |
|---|---|---|
| Zeus | Jupiter | roi des dieux, le ciel |
| Héra | Junon | mariage, épouse de Zeus |
| Poséidon | Neptune | la mer |
| Hadès | Pluton | les Enfers |
| Athéna | Minerve | sagesse, guerre juste |
| Arès | Mars | la guerre |
| Aphrodite | Vénus | l'amour, la beauté |
| Héphaïstos | Vulcain | le feu, la forge |
| Apollon | Apollon | la lumière, les arts, la divination |
| Artémis | Diane | la chasse, la lune |
| Hermès | Mercure | messager, commerce |
| Déméter | Cérès | les moissons |
| Dionysos | Bacchus | le vin, la fête |
| Hestia | Vesta | le foyer |

Les douze dieux de l'Olympe sont ceux du tableau, sauf **Hadès**, qui règne sur les Enfers et non sur l'Olympe. (Selon les listes, Dionysos remplace parfois Hestia.)

Les dieux résident sur le mont **Olympe**.

## 2. Les grands héros
- **Héraclès** (Hercule) : accomplit les douze travaux.
- **Thésée** : tue le Minotaure dans le labyrinthe, grâce au fil d'Ariane.
- **Persée** : tranche la tête de la Gorgone Méduse.
- **Ulysse** (Odysseus) : héros de l'Odyssée, rentre à Ithaque après dix ans.
- **Achille** : héros grec de l'Iliade, vulnérable au talon.

## 3. Les erreurs à éviter
- Ne pas confondre Arès/Mars (guerre) et Athéna/Minerve (sagesse et guerre stratégique).
- Vénus est la déesse de l'amour, pas Junon (le mariage).
- Ulysse est un héros grec, distinct d'Énée, le héros troyen de l'Énéide.

## À retenir
- Zeus=Jupiter, Héra=Junon, Poséidon=Neptune, Athéna=Minerve, Aphrodite=Vénus.
- Arès=Mars, Hermès=Mercure, Artémis=Diane, Héphaïstos=Vulcain, Dionysos=Bacchus.
- Héros : Héraclès (12 travaux), Thésée (Minotaure), Persée (Méduse), Ulysse (Odyssée), Achille (Iliade).
