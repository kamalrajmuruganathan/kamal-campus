# Vocabulaire : el trabajo y los estudios

> Choisir un métier, passer un entretien, réussir ses examens : le monde du travail
> et des études a son vocabulaire propre. Cette fiche rassemble les mots utiles pour
> parler de son parcours et de son avenir professionnel en espagnol.

## 1. Los estudios (les études)

| Espagnol | Français |
|---|---|
| el instituto | le lycée |
| la universidad | l'université |
| la carrera | les études supérieures / la filière |
| la asignatura | la matière |
| el examen / la prueba | l'examen / l'épreuve |
| aprobar | réussir (un examen) |
| suspender | rater / échouer (à un examen) |
| la nota | la note |
| la beca | la bourse |
| matricularse | s'inscrire |

Exemple : *Aprobé todas las asignaturas.* → J'ai réussi toutes les matières.
Attention : **aprobar** = réussir (un examen), et non « approuver » au sens courant.

## 2. El trabajo (le travail)

| Espagnol | Français |
|---|---|
| el empleo | l'emploi |
| el trabajo | le travail |
| la empresa | l'entreprise |
| el sueldo / el salario | le salaire |
| el/la jefe/jefa | le chef / la cheffe |
| la entrevista (de trabajo) | l'entretien (d'embauche) |
| el currículum | le CV |
| el paro / el desempleo | le chômage |
| contratar | embaucher |
| despedir | licencier |

Exemple : *Tengo una entrevista de trabajo el lunes.* → J'ai un entretien d'embauche lundi.
Faux-ami : **el paro** = le chômage (« estar en paro » = être au chômage).

## 3. Verbes et expressions du parcours

- **buscar trabajo** = chercher du travail.
- **ganarse la vida** = gagner sa vie.
- **hacer prácticas** = faire un stage ; **un becario / una becaria** = un(e) stagiaire.
- **jubilarse** = partir à la retraite ; **la jubilación** = la retraite.
- **estar en paro** = être au chômage.

## 4. Les erreurs à éviter

- Ne pas confondre **suspender** (rater un examen) et **aprobar** (le réussir).
- **la carrera** = les études supérieures (aussi « la course ») ; la carrière se dit *la trayectoria profesional*.
- **el sueldo** est masculin : *un buen sueldo*.
- « Postuler » se dit **presentarse a / solicitar (un puesto)**.

## À retenir

- Études : *el instituto, la universidad, la carrera, la asignatura, aprobar / suspender*.
- Travail : *el empleo, la empresa, el sueldo, la entrevista, el paro*.
- Verbes clés : *aprobar, suspender, contratar, despedir, jubilarse*.
- Faux-amis à surveiller : *el paro* (chômage), *la carrera* (études supérieures).
