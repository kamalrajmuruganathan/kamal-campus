# L'expression du patrimoine génétique

> Toutes les cellules d'un organisme possèdent le **même ADN**. Pourtant un neurone
> ne ressemble pas à un globule rouge. La différence ne tient pas au programme, mais
> à la partie du programme que chaque cellule **utilise**. Ce chapitre explique
> comment l'information d'un gène devient une **protéine** — et comment une même
> cellule choisit les gènes qu'elle exprime.

---

## 1. Du gène à la protéine : le problème à résoudre

L'ADN porte l'information dans le **noyau**. Mais les protéines, qui réalisent les
fonctions de la cellule, sont fabriquées dans le **cytoplasme**, sur les
**ribosomes**. L'information doit donc **sortir** du noyau, alors que l'ADN, lui, y
reste.

La cellule résout ce problème avec une **molécule intermédiaire**, mobile et
provisoire : l'**ARN messager (ARNm)**.

$$\text{ADN (noyau)} \xrightarrow{\text{transcription}} \text{ARNm} \xrightarrow{\text{traduction}} \text{protéine (cytoplasme)}$$

Cet enchaînement porte un nom : **l'expression du gène**.

---

## 2. L'ARN, une molécule cousine de l'ADN

L'ARN ressemble à l'ADN, mais **trois différences** le distinguent.

| | ADN | ARN |
|---|---|---|
| Nombre de brins | **deux** (double hélice) | **un seul** |
| Sucre | désoxyribose | ribose |
| Bases | A, T, G, C | A, **U**, G, C |

> ⚠️ **La base T de l'ADN est remplacée par U (uracile) dans l'ARN.** Il n'y a
> **jamais** de thymine dans un ARN, ni d'uracile dans l'ADN. C'est l'erreur la plus
> fréquente.

L'ARN messager est une **copie**, simple brin, d'un gène. Il est **provisoire** : il
est fabriqué quand la cellule en a besoin, puis dégradé.

---

## 3. La transcription : copier le gène en ARNm

La transcription a lieu dans le **noyau**. Une enzyme, l'**ARN polymérase**,
parcourt le gène et synthétise un ARNm en respectant la **complémentarité des
bases** :

| Base lue sur l'ADN (brin transcrit) | Base ajoutée sur l'ARNm |
|---|---|
| A | U |
| T | A |
| G | C |
| C | G |

> **Un seul des deux brins de l'ADN est copié** : c'est le **brin transcrit** (ou
> brin matrice). L'ARNm obtenu a donc la même séquence que l'autre brin (dit brin
> non transcrit ou codant), à ceci près que les T sont remplacés par des U.

> **Exemple.** Brin transcrit : `A T G C` → ARNm : `U A C G`.

L'ARNm ainsi formé quitte le noyau par un **pore nucléaire** et gagne le cytoplasme.

---

## 4. Le code génétique : la clé de traduction

Comment une séquence de **4 bases** peut-elle coder les **20 acides aminés** des
protéines ? En lisant les bases **par groupes de trois**. Un groupe de trois bases
successives de l'ARNm s'appelle un **codon**. Chaque codon désigne **un** acide
aminé (ou un signal d'arrêt).

La correspondance codon → acide aminé est le **code génétique**. Ses propriétés :

- **Universel** : le même code fonctionne chez la bactérie, la plante et l'humain
  (à de très rares exceptions près). C'est un argument fort de la **parenté** de
  tous les êtres vivants.
- **Redondant** (on dit *dégénéré*) : plusieurs codons peuvent coder le **même**
  acide aminé. Il y a 64 codons pour 20 acides aminés.
- **Non ambigu** : un codon donné code **toujours** le même acide aminé.
- Il comporte un **codon-start** (AUG, début de lecture) et trois **codons-stop**
  (UAA, UAG, UGA) qui **arrêtent** la traduction sans coder d'acide aminé.

> ⚠️ **Le code n'est pas « un gène = un acide aminé » ni « une base = un acide
> aminé »** : c'est **un codon (trois bases) = un acide aminé**. Se tromper d'unité
> fausse tout le raisonnement.

> ⚠️ **Redondant ne veut pas dire ambigu.** Redondant : *plusieurs codons* pour un
> même acide aminé. Ambigu voudrait dire *un codon pour plusieurs* acides aminés —
> ce qui n'existe pas.

---

## 5. La traduction : fabriquer la protéine

La traduction a lieu dans le **cytoplasme**, sur les **ribosomes**. Le ribosome se
fixe sur l'ARNm et le lit **codon par codon**, du codon-start au codon-stop. À
chaque codon, il ajoute l'acide aminé correspondant à la chaîne en construction.

Le résultat est une **protéine** : une suite d'acides aminés reliés dans un ordre
précis. Cet ordre — la **séquence** de la protéine — découle directement de la
séquence de l'ARNm, donc du gène.

$$\text{séquence du gène} \Rightarrow \text{séquence de l'ARNm} \Rightarrow \text{séquence de la protéine} \Rightarrow \text{forme et fonction}$$

> **Pourquoi la séquence fait tout.** La suite d'acides aminés détermine le
> **repliement** de la protéine dans l'espace, donc sa **forme**, donc sa
> **fonction** (enzyme, protéine de structure, récepteur…). Changer un acide aminé
> peut changer la forme, donc l'activité.

---

## 6. Un même génome, des cellules différentes

Toutes les cellules d'un organisme ont le **même ADN**. Ce qui les distingue, c'est
l'**ensemble des gènes qu'elles expriment**. Une cellule n'utilise à un instant
donné qu'une **fraction** de ses gènes : les autres restent inexprimés.

- Un gène **exprimé** est transcrit puis traduit → sa protéine est présente.
- Un gène **non exprimé** ne l'est pas → sa protéine est absente.

> **Exemple.** Le gène de l'insuline est présent dans **toutes** les cellules, mais
> il n'est exprimé que dans certaines cellules du pancréas. Ailleurs il est là, mais
> silencieux.

C'est cette **expression sélective** des gènes qui explique la **spécialisation** des
cellules (différenciation) : même patrimoine, usages différents.

> **L'environnement influence l'expression.** Des facteurs comme la température, la
> lumière ou des molécules-signal peuvent modifier quels gènes sont exprimés, sans
> changer l'ADN lui-même. Le phénotype dépend donc du génome **et** de son
> expression, elle-même sensible au milieu.

---

## 7. À retenir absolument

| | |
|---|---|
| Expression d'un gène | ADN → (transcription) ARNm → (traduction) protéine |
| ARN vs ADN | 1 brin, ribose, base **U** au lieu de T |
| Transcription | dans le **noyau**, par l'ARN polymérase, un seul brin copié |
| Codon | **3 bases** de l'ARNm = 1 acide aminé |
| Code génétique | universel, redondant, non ambigu ; start AUG, 3 stop |
| Traduction | dans le **cytoplasme**, sur le **ribosome**, codon par codon |
| Séquence | gène → ARNm → protéine → forme → fonction |
| Cellules différentes | même ADN, gènes **exprimés** différents |

---

## 8. Les erreurs qui coûtent des points

1. **Mettre de la thymine dans un ARN** : l'ARN contient de l'**uracile (U)**, jamais
   de T.
2. **Croire qu'une base code un acide aminé** : c'est un **codon**, trois bases.
3. **Confondre transcription et traduction** : transcription = ADN → ARN (noyau) ;
   traduction = ARN → protéine (cytoplasme).
4. **Dire que le code est ambigu parce qu'il est redondant** : redondant ≠ ambigu.
5. **Oublier que les deux brins d'ADN ne sont pas copiés** : un seul, le brin
   transcrit.
6. **Penser que les cellules d'un organisme ont des ADN différents** : elles ont le
   **même** ADN, elles n'en expriment pas les mêmes gènes.
7. **Confondre codon-start et codon-stop** : AUG lance la lecture, UAA/UAG/UGA
   l'arrêtent.
8. **Faire fabriquer la protéine dans le noyau** : la traduction se fait dans le
   cytoplasme, sur les ribosomes.
