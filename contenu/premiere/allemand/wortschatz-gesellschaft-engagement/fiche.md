# Wortschatz: Gesellschaft und Engagement

> Bénévolat, manifestations, égalité, solidarité : ce chapitre réunit le
> vocabulaire allemand de la société et de l'engagement citoyen pour débattre et
> défendre une opinion.

## 1. La société (die Gesellschaft)

| Allemand | Traduction |
|---|---|
| **die Gesellschaft** | la société |
| **der Bürger / die Bürgerin** | le citoyen / la citoyenne |
| **die Gemeinschaft** | la communauté |
| **die Gleichberechtigung** | l'égalité des droits |
| **die Solidarität** | la solidarité |
| **die Vielfalt** | la diversité |
| **die Ungerechtigkeit** | l'injustice |
| **die Meinung** | l'opinion |

## 2. L'engagement (das Engagement)

| Allemand | Traduction |
|---|---|
| **sich engagieren** | s'engager |
| **das Ehrenamt** | le bénévolat |
| **die Freiwilligenarbeit** | le travail bénévole |
| **die Demonstration** | la manifestation |
| **der Verein** | l'association |
| **die Spende** | le don |
| **unterstützen** | soutenir |
| **sich einsetzen für** | s'engager en faveur de |

## 3. Débattre et défendre une opinion (diskutieren)

| Allemand | Traduction |
|---|---|
| **die Debatte** | le débat |
| **das Argument** | l'argument |
| **überzeugen** | convaincre |
| **fordern** | exiger / réclamer |
| **verteidigen** | défendre |
| **kritisieren** | critiquer |
| **verantwortlich** | responsable |
| **gerecht / ungerecht** | juste / injuste |

*S'engager pour une cause : « Sie **setzt sich für** die Umwelt **ein**. » (Elle
s'engage pour l'environnement.)*

## 4. Les erreurs à éviter

- **sich engagieren** est pronominal : *Ich **engagiere mich** in einem Verein.*
- **sich einsetzen für** est à particule séparable : *Er setzt sich **für** die Gleichheit **ein**.*
- Ne confonds pas **die Meinung** (l'opinion) et **die Menge** (la quantité, la foule).
- Genre à mémoriser : **die** Gesellschaft, **das** Ehrenamt, **der** Verein, **die** Spende.

## À retenir

- Société : die Gesellschaft, der Bürger, die Gleichberechtigung, die Solidarität, die Vielfalt.
- Engagement : sich engagieren, das Ehrenamt, die Demonstration, der Verein, die Spende.
- Débattre : die Debatte, das Argument, überzeugen, fordern, verteidigen.
- Verbes pronominaux/séparables : sich engagieren, sich einsetzen für.
