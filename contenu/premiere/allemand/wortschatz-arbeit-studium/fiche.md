# Wortschatz: Arbeit und Studium

> Métier, entreprise, université, candidature : voici le vocabulaire allemand
> pour parler du monde du travail et des études.

## 1. Le travail (die Arbeit)

| Allemand | Traduction |
|---|---|
| **der Beruf** | le métier / la profession |
| **die Stelle / der Job** | le poste / l'emploi |
| **der Arbeitgeber** | l'employeur |
| **der Arbeitnehmer** | le salarié |
| **das Unternehmen / die Firma** | l'entreprise |
| **der Kollege / die Kollegin** | le / la collègue |
| **das Gehalt** | le salaire (mensuel) |
| **die Arbeitslosigkeit** | le chômage |

## 2. Les études et la formation (Studium und Ausbildung)

| Allemand | Traduction |
|---|---|
| **das Studium** | les études (supérieures) |
| **die Universität (die Uni)** | l'université |
| **die Ausbildung / die Lehre** | la formation (en alternance) |
| **das Praktikum** | le stage |
| **die Prüfung** | l'examen |
| **der Abschluss / das Diplom** | le diplôme |
| **das Fach** | la matière / la discipline |
| **das Semester** | le semestre |

En Allemagne, l'*Ausbildung* (apprentissage en alternance) est une voie très
valorisée, à côté des études universitaires.

## 3. Chercher et trouver un emploi (die Bewerbung)

| Allemand | Traduction |
|---|---|
| **sich bewerben (um)** | postuler (à) |
| **die Bewerbung** | la candidature |
| **der Lebenslauf** | le CV |
| **das Vorstellungsgespräch** | l'entretien d'embauche |
| **einstellen** | embaucher |
| **kündigen** | démissionner / licencier |
| **verdienen** | gagner (de l'argent) |
| **arbeitslos** | au chômage |

Exemple : *Ich bewerbe mich um eine Stelle als Ingenieur.* (Je postule à un poste
d'ingénieur.)

## 4. Les erreurs à éviter

- **das Gehalt** (salaire des employés) et **der Lohn** (salaire ouvrier, souvent
  horaire) : deux mots, un même thème.
- **sich bewerben** est pronominal et se construit avec **um** + accusatif.
- **studieren** = faire des études supérieures ; **lernen** = apprendre / réviser.
  Ne dis pas *Ich lerne an der Uni* pour « je suis à la fac ».
- **kündigen** signifie aussi bien démissionner que licencier selon le contexte.

## À retenir

- Travail : der Beruf, die Stelle, das Unternehmen, das Gehalt, der Arbeitgeber.
- Études : das Studium, die Universität, die Ausbildung, das Praktikum, der Abschluss.
- Candidature : sich bewerben um, die Bewerbung, der Lebenslauf, das Vorstellungsgespräch.
- Distingue **studieren** (études sup.) et **lernen** (apprendre).
