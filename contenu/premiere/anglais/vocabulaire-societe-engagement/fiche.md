# Vocabulaire : société, engagement et citoyenneté

> Manifestations, droits, solidarité, vote : les questions de société sont au cœur des épreuves de première. Cette fiche te donne le lexique anglais pour parler d'engagement citoyen, décrire un débat démocratique et défendre une cause avec précision.

## 1. Citoyenneté et démocratie

| Anglais | Français | Remarque |
|---|---|---|
| a citizen | un(e) citoyen(ne) | *citizenship* = la citoyenneté |
| rights | les droits | *human rights* = les droits humains |
| to vote / an election | voter / une élection | *to run for office* = se présenter |
| a law | une loi | *to pass a law* = adopter une loi |
| freedom of speech | la liberté d'expression | |
| equality | l'égalité | *gender equality* = égalité des genres |
| a policy | une politique (mesure) | faux ami : ≠ police |
| welfare | la protection sociale | *the welfare state* = l'État-providence |

**Exemples :**
- *Every citizen has the right to vote.* → Tout citoyen a le droit de voter.
- *Parliament passed a new law on equality.* → Le Parlement a adopté une nouvelle loi sur l'égalité.

## 2. S'engager et défendre une cause

| Anglais | Français |
|---|---|
| to volunteer | faire du bénévolat |
| a charity | une association caritative |
| to raise awareness | sensibiliser |
| to fundraise / to donate | collecter des fonds / faire un don |
| a protest / to protest | une manifestation / manifester |
| a demonstration | une manifestation |
| to campaign for | faire campagne pour |
| to stand up for | défendre, prendre position pour |
| a petition | une pétition |
| a cause | une cause |

**Collocations utiles :**
- *to raise awareness of an issue* → sensibiliser à un problème.
- *to take action* → agir, passer à l'action.
- *to make a difference* → changer les choses.

## 3. Problèmes de société et débat

| Anglais | Français |
|---|---|
| inequality | l'inégalité |
| poverty | la pauvreté |
| discrimination | la discrimination |
| homelessness | le sans-abrisme |
| an issue | un problème, une question |
| a right / a duty | un droit / un devoir |
| to tackle | s'attaquer à (un problème) |
| to be committed to | être engagé dans |
| grassroots | de terrain, citoyen (mouvement) |

**Exemples :**
- *This charity tackles homelessness in big cities.* → Cette association s'attaque au sans-abrisme dans les grandes villes.
- *She is deeply committed to gender equality.* → Elle est profondément engagée pour l'égalité des genres.

## 4. Registre : soutenu ou familier ?

| Familier | Neutre / soutenu |
|---|---|
| to help out | to volunteer / to contribute |
| a big deal | a major issue |
| lots of people | many citizens |
| to fight for stuff | to campaign for a cause |

## 5. Les erreurs à éviter

- **« a policy »** = une mesure politique, pas « la police » (= *the police*).
- **« to demand »** = exiger, pas « demander » (= *to ask*).
- **« sensible »** = raisonnable, pas « sensible » (= *sensitive*).
- **« the police »** est suivi d'un verbe au **pluriel** : *the police are…*.
- **« engaged »** signifie souvent « fiancé » : pour « engagé », dis *committed / involved*.

## À retenir

- Démocratie : *a citizen, rights, to vote, a law, freedom of speech, equality*.
- Engagement : *to volunteer, a charity, to raise awareness, to protest, a petition*.
- Débat : *inequality, poverty, discrimination, to tackle, to be committed to*.
- Faux amis à surveiller : *a policy, to demand, sensible, engaged*.
- Adapte ton **registre** à la situation (oral entre amis vs dissertation).
