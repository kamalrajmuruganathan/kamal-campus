# Vocabulaire : le monde du travail et les études

> Orientation, candidatures, stages, premier emploi : à la fin du lycée, ces sujets deviennent concrets. Cette fiche te donne le lexique anglais pour parler de tes études, décrire un parcours professionnel et réussir un entretien ou une lettre de motivation.

## 1. Les études et l'orientation

| Anglais | Français | Remarque |
|---|---|---|
| a degree | un diplôme (universitaire) | *a Bachelor's / Master's degree* |
| a major | une spécialité (universitaire) | *to major in biology* |
| tuition (fees) | les frais de scolarité | indénombrable |
| a scholarship | une bourse | *to win a scholarship* |
| to graduate | obtenir son diplôme | *to graduate from university* |
| a gap year | une année de césure | |
| coursework | le travail en contrôle continu | indénombrable |
| a lecture | un cours magistral | faux ami : ≠ lecture |

**Exemples :**
- *She graduated from university with a degree in law.* → Elle a obtenu son diplôme de droit à l'université.
- *He decided to take a gap year before applying.* → Il a décidé de prendre une année de césure avant de postuler.

## 2. Chercher et décrocher un emploi

| Anglais | Français |
|---|---|
| a job / a position | un emploi / un poste |
| to apply for a job | postuler à un emploi |
| an application | une candidature |
| a cover letter | une lettre de motivation |
| a résumé / a CV | un CV |
| a job interview | un entretien d'embauche |
| an applicant / a candidate | un(e) candidat(e) |
| an opening / a vacancy | un poste à pourvoir |
| to hire / to recruit | embaucher / recruter |
| to be hired | être embauché |

**Collocations clés :**
- *to apply **for** a job* → postuler **à** un emploi (préposition *for*).
- *to fill **in** an application form* → remplir un formulaire.
- *to be shortlisted* → être présélectionné.

## 3. Le monde du travail

| Anglais | Français |
|---|---|
| an employer / an employee | un employeur / un(e) salarié(e) |
| a colleague / a co-worker | un(e) collègue |
| a salary / wages | un salaire / une paie |
| a raise | une augmentation |
| a promotion | une promotion |
| a deadline | une échéance, un délai |
| a workload | une charge de travail |
| to commute | faire le trajet domicile-travail |
| a trainee / an intern | un(e) stagiaire |
| an internship / a work placement | un stage |
| to be self-employed | être à son compte |
| to be made redundant | être licencié (économique) |

**Exemples :**
- *After a six-month internship, she was offered a permanent position.* → Après un stage de six mois, on lui a proposé un poste permanent.
- *He got a raise because he met every deadline.* → Il a eu une augmentation parce qu'il a respecté chaque échéance.

## 4. Registre : la lettre et l'entretien

Dans une candidature, le registre est **formel**.

| Familier | Formel |
|---|---|
| I want this job. | I would be delighted to join your team. |
| I'm good at… | I am highly skilled in… |
| Thanks! | Thank you for your consideration. |
| a boss | a manager / a supervisor |

## 5. Les erreurs à éviter

- **« to apply to a job »** → dis **to apply *for* a job** (mais *to apply **to** a university*).
- **« a formation »** n'existe pas au sens de cursus : dis **training** ou **a course**.
- **« to pass an exam »** = **réussir** un examen (pas simplement le passer, qui est *to take/sit an exam*).
- **« a stage »** = une scène, pas un stage ! Un stage = **an internship / a work placement**.
- **« a patron »** = un client régulier ou un mécène, pas un patron (= *a boss/manager*).
- **« actually »** = en fait ; **« eventually »** = finalement (pas « éventuellement »).

## À retenir

- Études : *a degree, to graduate, tuition fees, a scholarship, a gap year*.
- Candidature : *to apply for a job, a cover letter, a résumé, a job interview*.
- Travail : *an employee, a salary, a deadline, an internship, a promotion*.
- Faux amis : *to pass an exam, an internship (≠ stage), a boss (≠ patron), eventually*.
- Adopte un **registre formel** dans une lettre de motivation ou un entretien.
