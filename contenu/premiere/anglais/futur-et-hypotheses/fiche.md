# Exprimer le futur et les hypothèses

> L'anglais n'a pas de « temps futur » unique : il choisit entre plusieurs formes selon qu'il s'agit d'une prédiction, d'une décision, d'un projet ou d'un programme. Les hypothèses en *if* prolongent cette logique vers l'irréel.

## 1. Les formes du futur

| Forme | Emploi | Exemple |
|---|---|---|
| **will** + BV | prédiction, décision spontanée, promesse | I think it **will rain**. / I**'ll help** you. |
| **be going to** + BV | intention, prédiction fondée sur des indices | I**'m going to study** law. / Look, it**'s going to rain**! |
| présent **continu** | arrangement fixé, avec date/personne | I**'m meeting** Sam at 6. |
| présent **simple** | horaires, programmes officiels | The train **leaves** at 8. |
| **will be + -ing** (futur continu) | action en cours à un moment futur | This time tomorrow, I**'ll be flying** to Rome. |

**Nuance clé** : *will* = décision prise **au moment de parler** ; *be going to* = intention **déjà décidée** avant.

## 2. Le futur après les conjonctions de temps

Après **when, as soon as, before, after, until, once**, on **n'emploie pas will** : on met le **présent simple**.

| Forme | Exemple | Traduction |
|---|---|---|
| when + présent | I'll call you **when I arrive**. | Je t'appellerai quand j'arriverai. |
| as soon as | We'll leave **as soon as she's ready**. | Nous partirons dès qu'elle sera prête. |

## 3. Les hypothèses en *if* : les trois types de base

| Type | Structure | Valeur | Exemple |
|---|---|---|---|
| **0** | if + présent, présent | vérité générale | If you **heat** ice, it **melts**. |
| **1** | if + présent, will + BV | futur probable | If it **rains**, we **will stay** home. |
| **2** | if + prétérit, would + BV | irréel du présent, peu probable | If I **won** the lottery, I **would travel**. |

Au type 2, on emploie **were** pour toutes les personnes de be : *If I **were** you, I would apologize.* (À ta place...)

## 4. Le type 3 et les regrets (irréel du passé)

Le **type 3** exprime une hypothèse sur le passé, donc irréalisable :

| Structure | Exemple | Traduction |
|---|---|---|
| if + past perfect, would have + V-en | If I **had studied**, I **would have passed**. | Si j'avais révisé, j'aurais réussi. |

On l'emploie souvent pour exprimer un **regret** : *If she **had left** earlier, she **wouldn't have missed** the train.*

## 5. Les erreurs à éviter

- **Jamais will après if** (hypothèse) ni après when/as soon as : *If it will rain* → *If it **rains***.
- Au type 2, ne pas mettre would dans la subordonnée : *If I would have money* → *If I **had** money*.
- **would have + participe passé** au type 3, pas *would had* : *I **would have** gone*.
- Ne pas confondre **will** (prédiction) et **be going to** (intention déjà prise).
- Après *when* futur, présent simple : *when I **will** be older* → *when I **am** older*.

## À retenir

- Plusieurs futurs : **will** (prédiction/décision), **be going to** (intention), continu (arrangement), simple (horaire).
- Après **when, as soon as, if**... on met le **présent**, jamais will.
- Type 1 : if + présent → will (futur probable). Type 2 : if + prétérit → would (irréel présent).
- Type 3 : if + past perfect → would have + V-en (irréel/regret du passé).
- *If I **were** you* pour un conseil.
