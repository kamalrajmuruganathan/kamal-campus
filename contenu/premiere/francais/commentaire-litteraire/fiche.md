# Méthode : le commentaire littéraire

> Le commentaire littéraire est l'un des deux sujets possibles à l'écrit du bac de français (l'autre étant la dissertation). Il s'agit d'expliquer, de façon organisée et rédigée, comment un texte produit du sens et des effets.

## 1. Ce qu'est (et n'est pas) le commentaire

Commenter un texte, c'est **analyser** : relier un procédé d'écriture à un effet de sens ou à une émotion. Ce n'est **pas** :

- **paraphraser** (redire le texte avec d'autres mots) ;
- réciter des connaissances sur l'auteur ;
- juger (« j'ai aimé »).

À l'écrit du bac (épreuve de 4 heures, notée sur 20), le candidat choisit **au choix** le commentaire **ou** la dissertation.

## 2. Les étapes du brouillon

1. **Lire** le texte plusieurs fois et repérer le genre, le registre, la situation.
2. **Relever les procédés** (lexique, figures, syntaxe, sonorités, temps verbaux…) et noter leurs **effets**.
3. Formuler une **problématique** : la question centrale à laquelle le commentaire répond.
4. **Regrouper** les remarques en **axes de lecture** (les grandes parties, souvent 2 ou 3).
5. Ordonner les sous-parties, chacune appuyée sur des **citations** analysées.

## 3. La structure rédigée

| Partie | Contenu |
|---|---|
| Introduction | situer (auteur/œuvre/mouvement), présenter le texte, poser la problématique, annoncer le plan |
| Développement | 2 ou 3 axes ; chaque axe = plusieurs sous-parties (procédé → citation → interprétation) |
| Conclusion | bilan répondant à la problématique + ouverture |

Chaque paragraphe suit la logique : **affirmation → citation → analyse**. Les axes sont reliés par des **transitions**.

## 4. Exigences de rédaction

- Le commentaire est **entièrement rédigé** (pas de plan apparent, pas de liste).
- Chaque analyse s'appuie sur une **citation** entre guillemets.
- On emploie un **vocabulaire d'analyse précis** (métaphore, champ lexical, focalisation, allitération…).
- On évite la paraphrase et le jugement personnel non argumenté.

## 5. Les erreurs à éviter

- **Paraphraser** au lieu d'analyser (raconter le texte sans expliquer les procédés).
- **Faire un axe = une strophe** : les axes sont des idées, pas un simple découpage linéaire.
- **Citer sans analyser** : une citation doit toujours être commentée.
- **Oublier la problématique** : elle guide tout le devoir.
- **Réciter la biographie de l'auteur** au lieu d'étudier le texte.

## À retenir

- Commenter = analyser (procédé → effet), pas paraphraser ni juger.
- Étapes : lire, relever les procédés, problématiser, bâtir des axes.
- Structure : introduction (situer, problématique, plan) / développement (2-3 axes) / conclusion (bilan + ouverture).
- Chaque paragraphe : affirmation → citation → interprétation.
- Devoir entièrement rédigé, appuyé sur des citations.
