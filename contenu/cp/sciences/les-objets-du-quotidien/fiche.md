# Les objets du quotidien

## Qu'est-ce qu'un objet ?

Un **objet**, c'est une chose **fabriquée** par les humains pour **servir à
quelque chose**. Un objet n'est **pas vivant**.

Exemples : un **crayon**, une **cuillère**, un **ballon**, un **parapluie**, une
**chaise**, un **vélo**.

Chaque objet a une **utilité** : le parapluie sert à se **protéger de la
pluie**, la cuillère sert à **manger**.

## Les matières

Les objets sont faits avec des **matières** (des matériaux) :

- le **bois** (une chaise, un crayon),
- le **métal** (une cuillère, une clé),
- le **plastique** (un seau, une bouteille),
- le **verre** (un verre, une vitre),
- le **papier** ou le **carton** (un livre, une boîte),
- le **tissu** (un vêtement).

On choisit la matière selon l'usage : une **casserole en métal** pour la
chaleur, une **fenêtre en verre** pour voir à travers.

## À quoi servent les objets

Un objet est fait pour **rendre un service** :

- Pour **écrire** : le crayon, le stylo.
- Pour **couper** : les ciseaux (attention, c'est dangereux, on demande à un
  adulte).
- Pour **s'éclairer** : la lampe.
- Pour **se déplacer** : le vélo, la trottinette.

## Bien utiliser les objets

Il faut utiliser chaque objet **comme il faut** et faire **attention** :

- Les **ciseaux**, le **couteau** coupent : on fait attention aux doigts.
- Les **prises** et l'**électricité** sont **dangereuses** : on ne touche pas.
- On **range** les objets et on en **prend soin** pour qu'ils durent.

## Ce qu'il faut retenir

- Un **objet** est **fabriqué** par l'humain et sert à quelque chose ; il n'est
  **pas vivant**.
- Les objets sont faits de **matières** : bois, métal, plastique, verre, papier,
  tissu.
- On choisit la **matière** selon l'**usage** de l'objet.

## Les erreurs à éviter

- Un **objet n'est pas vivant** : il ne grandit pas et ne se nourrit pas.
- Le **verre** et le **plastique** ne sont pas la même matière : le verre se
  **casse** et est **transparent**, le plastique **plie** souvent.
- Certains objets sont **dangereux** (ciseaux, prises) : on demande de l'aide à
  un adulte.
