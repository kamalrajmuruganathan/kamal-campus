# Die Farben

> Le monde est plein de couleurs ! En allemand, le ciel est *blau*, l'herbe est *grün* et le soleil est *gelb*. Apprends à nommer les couleurs pour décrire tout ce qui t'entoure.

## 1. Les couleurs
Voici les couleurs (die Farben). Cherche autour de toi un objet de chaque couleur.

| Français | Allemand | Français | Allemand |
|---|---|---|---|
| rouge | **rot** | blanc | **weiß** |
| bleu | **blau** | marron | **braun** |
| jaune | **gelb** | gris | **grau** |
| vert | **grün** | rose | **rosa** |
| noir | **schwarz** | orange | **orange** |
| violet | **lila** | | |

## 2. Dire la couleur d'une chose
On utilise le petit verbe **ist** (« est »). Le nom prend une majuscule.

| Allemand | Français |
|---|---|
| Der Himmel **ist blau**. | Le ciel est bleu. |
| Das Gras **ist grün**. | L'herbe est verte. |
| Die Banane **ist gelb**. | La banane est jaune. |
| Der Schnee **ist weiß**. | La neige est blanche. |

## 3. Les erreurs à éviter
- **weiß** (blanc) s'écrit avec **ß**, pas avec un simple s.
- **grün** (vert) prend un tréma : ü.
- Ne confonds pas **grün** (vert) et **grau** (gris) : ils commencent pareil mais ne finissent pas pareil.

## À retenir
- Les couleurs de base : **rot, blau, gelb, grün**.
- Puis : **schwarz, weiß, braun, grau, rosa, orange, lila**.
- Pour dire la couleur : Der Himmel **ist blau**.
- Attention au **ß** de **weiß** et au **ü** de **grün**.
