# Le nom et son petit mot (le, la, un, une)

> Chaque chose a un nom : le chat, la table, un ballon. Et devant le nom, il y a souvent un petit mot qui lui donne la main : le, la, un, une. Apprends à les reconnaître !

## 1. Le nom

Un **nom** sert à **nommer** une personne, un animal ou une chose.

| Nom | Il nomme… |
|---|---|
| chat | un animal |
| table | une chose |
| maman | une personne |
| ballon | une chose |

## 2. Le petit mot devant le nom

Devant le nom, on met souvent un **petit mot** : **le, la, un, une**. On l'appelle un **déterminant**.

| Petit mot | Exemple | Masculin ou féminin ? |
|---|---|---|
| le | **le** chat | masculin |
| un | **un** ballon | masculin |
| la | **la** table | féminin |
| une | **une** pomme | féminin |

- **le** et **un** vont avec les noms **masculins**.
- **la** et **une** vont avec les noms **féminins**.

## 3. Les erreurs à éviter

- Ne pas se tromper de genre : on dit **la** table, pas « le table ».
- Ne pas oublier le petit mot : on dit **le** chien, pas « chien » tout seul dans la phrase.
- Attention : « le » et « la » servent pour une chose que l'on connaît déjà ; « un » et « une » pour une chose parmi d'autres.

## À retenir

- Un **nom** nomme une personne, un animal ou une chose.
- Devant le nom, il y a un petit mot : **le, la, un, une** (un déterminant).
- **le / un** → masculin ; **la / une** → féminin.
- Je choisis le bon petit mot pour aller avec le nom.
