# Colours: les couleurs

> Le monde est plein de couleurs ! Apprends leurs noms en anglais pour décrire
> tout ce que tu vois.

## 1. Les couleurs de base

| Anglais | Se dit | Traduction |
|---|---|---|
| red | *rèd* | rouge |
| blue | *blou* | bleu |
| green | *grîne* | vert |
| yellow | *yè-lo* | jaune |
| orange | *o-rinnj* | orange |

## 2. Encore des couleurs

| Anglais | Se dit | Traduction |
|---|---|---|
| purple | *peu-peul* | violet |
| pink | *pinnk* | rose |
| brown | *braoune* | marron |
| black | *blak* | noir |
| white | *ouaït* | blanc |
| grey | *gréï* | gris |

## 3. Dire une couleur

On peut dire : **The sky is blue.** (Le ciel est bleu.)
**The grass is green.** (L'herbe est verte.) **The snow is white.** (La neige est blanche.)

## Les erreurs à éviter
- **red** (rouge) ne se dit pas comme *read* : attention à bien dire *rèd*.
- **white** (blanc) commence par le son *w* : *ouaït*.
- **green** (vert) et **grey** (gris) commencent pareil mais sont différents.

## À retenir
- **red** = rouge, **blue** = bleu, **green** = vert, **yellow** = jaune.
- **black** = noir, **white** = blanc.
- The sky is **blue**, the grass is **green**.
