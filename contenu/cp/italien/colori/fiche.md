# I colori

> Découvre les couleurs en italien pour décrire tout ce qui t'entoure : le ciel, les fruits, tes crayons !

## 1. Les couleurs en italien
Apprends les couleurs (i colori) pour décrire le monde autour de toi.

| Italien | Couleur | Italien | Couleur |
|---|---|---|---|
| **rosso** | rouge | **viola** | violet |
| **blu** | bleu | **rosa** | rose |
| **giallo** | jaune | **nero** | noir |
| **verde** | vert | **bianco** | blanc |
| **arancione** | orange | **marrone** | marron |
| **grigio** | gris | **azzurro** | bleu ciel |

## 2. Dire la couleur d'une chose
On place souvent la couleur **après** le nom :
- **Il limone è giallo.** → Le citron est jaune.
- **L'erba è verde.** → L'herbe est verte.
- **Il pomodoro è rosso.** → La tomate est rouge.

## 3. Les erreurs à éviter
- **blu** et **azzurro** sont deux bleus : *azzurro* = bleu ciel, plus clair.
- Attention : en italien, la couleur se met souvent **après** le nom (« la macchina rossa » = la voiture rouge).
- **bianco** = blanc (le « ch » n'existe pas ici, on écrit *bianco*).

## À retenir
- Les couleurs de base : **rosso, blu, giallo, verde, nero, bianco**.
- **arancione** (orange), **viola** (violet), **rosa** (rose), **grigio** (gris), **marrone** (marron), **azzurro** (bleu ciel).
- La couleur se place souvent après le nom.
