# Le temps qui passe : jour, semaine, mois, saisons

> Le temps passe toujours dans le même ordre. En apprenant les jours, les mois
> et les saisons, tu sais te repérer et dire quand les choses arrivent.

## 1. La journée : le jour et la nuit

La Terre tourne sur elle-même en un jour. Quand il fait clair, c'est le **jour** ;
quand il fait sombre, c'est la **nuit**.

Dans une journée, on distingue plusieurs moments qui se suivent toujours dans le
même ordre :

| Moment | Quand |
|---|---|
| le matin | au début du jour |
| le midi | au milieu du jour |
| l'après-midi | après le repas de midi |
| le soir | à la fin du jour |
| la nuit | quand il fait noir |

## 2. La semaine : 7 jours

Une **semaine** dure **7 jours**. Ils reviennent toujours dans le même ordre :

**lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche.**

- Le jour **avant** aujourd'hui s'appelle **hier**.
- Le jour **après** aujourd'hui s'appelle **demain**.

## 3. Les mois et l'année

Une **année** compte **12 mois**. Ils se suivent dans cet ordre :

janvier, février, mars, avril, mai, juin, juillet, août, septembre, octobre,
novembre, décembre.

Janvier est le **premier** mois de l'année, décembre est le **dernier**.

## 4. Les quatre saisons

L'année a **4 saisons** qui reviennent toujours dans le même ordre :

| Saison | Souvent... |
|---|---|
| le printemps | les fleurs poussent |
| l'été | il fait chaud |
| l'automne | les feuilles tombent |
| l'hiver | il fait froid |

## À retenir

- Une semaine dure **7 jours** ; le premier est lundi, le dernier est dimanche.
- Une année compte **12 mois** ; le premier est janvier, le dernier est décembre.
- Il y a **4 saisons** : printemps, été, automne, hiver.
- **Hier** = le jour d'avant ; **demain** = le jour d'après.
