# Los colores

> Rouge, bleu, jaune… En espagnol, les couleurs ont de jolis noms ! On les apprend ici pour décrire le monde autour de nous : *el sol es amarillo* (le soleil est jaune).

## 1. Les couleurs principales

| Couleur | Espagnol | Exemple |
|---|---|---|
| rouge | **rojo** | el tomate es rojo |
| bleu | **azul** | el cielo es azul |
| jaune | **amarillo** | el sol es amarillo |
| vert | **verde** | la hierba es verde |
| noir | **negro** | el gato es negro |
| blanc | **blanco** | la nieve es blanca |

## 2. D'autres couleurs

| Couleur | Espagnol |
|---|---|
| orange | **naranja** |
| rose | **rosa** |
| marron | **marrón** |
| gris | **gris** |
| violet | **morado** |

Pour dire de quelle couleur est une chose, on utilise **es** (« est ») :
*La flor es roja.* (« La fleur est rouge. »)

## 3. Les erreurs à éviter
- **azul** = bleu, à ne pas confondre avec le français.
- **verde** (vert) finit par « -e ».
- Beaucoup de couleurs changent au féminin : *rojo* → *roja*, *blanco* → *blanca*.

## À retenir
- rojo (rouge), azul (bleu), amarillo (jaune), verde (vert).
- negro (noir), blanco (blanc).
- Pour décrire : **… es …** (La flor **es** roja).
