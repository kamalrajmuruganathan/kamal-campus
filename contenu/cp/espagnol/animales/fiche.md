# Los animales

> Chien, chat, oiseau… Les animaux sont partout ! En espagnol, on apprend leurs noms pour parler de nos amis à quatre pattes : *el perro* (le chien), *el gato* (le chat).

## 1. Les animaux de la maison et de la ferme

| Français | Espagnol |
|---|---|
| le chien | **el perro** |
| le chat | **el gato** |
| l'oiseau | **el pájaro** |
| le poisson | **el pez** |
| le cheval | **el caballo** |
| la vache | **la vaca** |

## 2. D'autres animaux

| Français | Espagnol |
|---|---|
| le lapin | **el conejo** |
| la poule | **la gallina** |
| le mouton | **la oveja** |
| le cochon | **el cerdo** |
| le lion | **el león** |

Devant le nom, on met **el** (le) ou **la** (la) :
*el perro* (le chien), *la vaca* (la vache).

## 3. Les erreurs à éviter
- On dit **el gato** pour « le chat » (et non « le cat »).
- **el pez** = le poisson vivant ; attention au « z ».
- Le « j » de **pájaro** se prononce comme un « r » raclé.

## À retenir
- el perro (chien), el gato (chat), el pájaro (oiseau).
- el pez (poisson), el caballo (cheval), la vaca (vache).
- On met **el** ou **la** devant le nom de l'animal.
