# Descrivere le persone

> Comment dire qu'une personne est grande, a les cheveux bruns ou est sympathique ? Tu vas apprendre à **décrire** les gens en italien avec les adjectifs et le verbe *essere*.

## 1. Le verbe essere (être)
Pour décrire, on utilise souvent **essere** :

| Pronom | Forme | Traduction |
|---|---|---|
| io | sono | je suis |
| tu | sei | tu es |
| lui / lei | è | il / elle est |
| loro | sono | ils / elles sont |

Exemple : *Marco è alto.* → Marco est grand.

## 2. Gli aggettivi (les adjectifs)
Voici des adjectifs utiles :

| Italien | Français |
|---|---|
| alto / basso | grand / petit |
| bello / brutto | beau / laid |
| simpatico | sympathique |
| gentile | gentil |
| giovane / vecchio | jeune / vieux |

**Important :** l'adjectif s'accorde. Au masculin on dit *alto*, au féminin *alta* :
- *Marco è alt**o**.* (masculin) / *Anna è alt**a**.* (féminin)

## 3. Descrivere il fisico (décrire le physique)
Pour les cheveux et les yeux, on utilise **avere** (avoir) :
- *Ho i capelli bruni.* → J'ai les cheveux bruns.
- *Ha gli occhi azzurri.* → Il/elle a les yeux bleus.

| Italien | Français |
|---|---|
| i capelli | les cheveux |
| gli occhi | les yeux |
| biondo | blond |
| bruno | brun |

## 4. Les erreurs à éviter
- L'adjectif s'accorde au féminin : *alta*, *bella*, *vecchia* (et non *alto* pour une fille).
- On décrit le physique avec **avere** (avoir), comme en français : *ho i capelli…* (j'ai les cheveux…).
- « è » (il est) prend un accent : ne pas confondre avec « e » (et).

## À retenir
- Essere : **sono, sei, è, sono**.
- L'adjectif s'accorde : *alto* (m.) / *alta* (f.).
- Physique avec **avere** : *ho i capelli bruni*, *ha gli occhi azzurri*.
- Adjectifs : **alto, basso, simpatico, gentile, giovane**.
