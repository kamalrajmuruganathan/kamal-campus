# L'accord du participe passé (être / avoir)

> Faut-il écrire « elle est venue » ou « elle est venu » ? « les fleurs qu'il a
> cueillies » ou « cueilli » ? Tout dépend de l'auxiliaire. Voici les deux règles
> à ne plus jamais confondre.

## 1. Avec l'auxiliaire *être* : accord avec le sujet

Quand le verbe est conjugué avec **être**, le participe passé **s'accorde en genre
et en nombre avec le sujet**.

| Sujet | Exemple | Accord |
|---|---|---|
| il | Il est **parti**. | masculin singulier |
| elle | Elle est **partie**. | + e (féminin) |
| ils | Ils sont **partis**. | + s (pluriel) |
| elles | Elles sont **parties**. | + es (féminin pluriel) |

## 2. Avec l'auxiliaire *avoir* : pas d'accord avec le sujet

Quand le verbe est conjugué avec **avoir**, le participe passé **ne s'accorde pas
avec le sujet**.

| Sujet | Exemple | Remarque |
|---|---|---|
| elle | Elle a **mangé**. | pas de « e » |
| ils | Ils ont **chanté**. | pas de « s » |
| elles | Elles ont **fini**. | invariable ici |

**Cas particulier (à connaître) :** avec *avoir*, le participe s'accorde avec le
**COD** seulement si celui-ci est placé **avant** le verbe.

> Les pommes qu'elle a **mangées** sont bonnes.
> (Le COD « les pommes » est placé avant → accord au féminin pluriel : mangées.)

## 3. Tableau récapitulatif

| Auxiliaire | Accord avec… | Exemple |
|---|---|---|
| être | le **sujet** | Elles sont **arrivées**. |
| avoir | le **COD** placé **avant** | La lettre qu'il a **écrite**. |
| avoir | rien si pas de COD avant | Elles ont **couru**. |

## 4. Les erreurs à éviter

- **Ne pas accorder avec avoir + sujet.** On écrit « elles ont chanté », jamais
  « elles ont chantées » à cause du sujet.
- **Ne pas oublier l'accord avec être.** « Elle est venu » est faux : il faut « venue ».
- **Repérer le bon auxiliaire.** « Elle a » → avoir ; « elle est » → être.
- Le cas du COD avant avec *avoir* est plus difficile : cherche d'abord « qu'a-t-elle… ? ».

## À retenir

- Avec **être** : le participe passé s'accorde avec le **sujet**.
- Avec **avoir** : pas d'accord avec le sujet ; accord avec le **COD** seulement s'il est **placé avant**.
- Toujours commencer par repérer l'auxiliaire (être ou avoir).
- « Elles ont mangé » (avoir, pas d'accord) ≠ « Elles sont venues » (être, accord).
