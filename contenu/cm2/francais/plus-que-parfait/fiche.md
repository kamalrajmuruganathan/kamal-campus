# Le plus-que-parfait

> Quand on raconte au passé, il arrive qu'une action se soit produite **avant** une
> autre action passée. Pour l'exprimer, on utilise le plus-que-parfait. C'est le
> « passé du passé ».

## 1. À quoi sert le plus-que-parfait ?

Le plus-que-parfait exprime une action passée qui a eu lieu **avant** une autre
action passée.

> Quand nous sommes arrivés, le film **avait** déjà **commencé**.

Ici, le film a commencé *avant* notre arrivée : on emploie le plus-que-parfait
(« avait commencé ») pour l'action la plus ancienne.

## 2. Comment le former ?

Plus-que-parfait = **auxiliaire *être* ou *avoir* à l'imparfait** + **participe passé** du verbe.

| Auxiliaire | Exemple | Verbe |
|---|---|---|
| avoir (imparfait) | j'**avais mangé** | manger |
| avoir (imparfait) | tu **avais fini** | finir |
| être (imparfait) | il **était parti** | partir |
| être (imparfait) | elle **était venue** | venir |

Rappel de l'imparfait des auxiliaires :

| Personne | avoir | être |
|---|---|---|
| je / j' | avais | étais |
| tu | avais | étais |
| il/elle | avait | était |
| nous | avions | étions |
| vous | aviez | étiez |
| ils/elles | avaient | étaient |

## 3. L'accord du participe passé

- Avec **être**, le participe passé **s'accorde** avec le sujet :
  elle était **partie**, ils étaient **venus**.
- Avec **avoir**, le participe passé **ne s'accorde pas** avec le sujet :
  elles avaient **mangé** (et non « mangées »).

## 4. Les erreurs à éviter

- **Ne pas oublier l'auxiliaire.** On ne dit pas « je mangé » mais « j'avais mangé ».
- **Choisir le bon auxiliaire.** Les verbes de déplacement et d'état (aller, venir,
  partir, arriver, rester, tomber…) se conjuguent avec *être*.
- **Ne pas confondre imparfait et plus-que-parfait.** « Je jouais » (imparfait, une seule
  action) ≠ « J'avais joué » (plus-que-parfait, action antérieure).
- Avec *avoir*, ne fais pas accorder le participe avec le sujet : « ils avaient chanté ».

## À retenir

- Le plus-que-parfait = **le passé du passé** (une action avant une autre action passée).
- Formation : **auxiliaire à l'imparfait + participe passé**.
- Avec *être*, le participe **s'accorde** avec le sujet ; avec *avoir*, il **ne s'accorde pas** avec le sujet.
- N'oublie jamais l'auxiliaire.
