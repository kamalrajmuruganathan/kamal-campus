# Mahlzeiten und im Restaurant bestellen

> En allemand, on parle beaucoup de nourriture ! Dans ce chapitre, tu apprends à nommer les repas, les aliments et à commander poliment au restaurant.

## 1. Die Mahlzeiten (les repas)
En Allemagne, il y a trois repas principaux. Chaque repas a son nom.

| Allemand | Traduction |
|---|---|
| das Frühstück | le petit-déjeuner |
| das Mittagessen | le déjeuner |
| das Abendessen | le dîner |

Deux verbes très utiles : **essen** (manger) et **trinken** (boire).
Exemple : *Ich esse ein Brot.* (Je mange un pain.) — *Ich trinke Wasser.* (Je bois de l'eau.)

## 2. Die Lebensmittel (les aliments)
Attention à l'article de chaque mot : il faut l'apprendre avec le mot.

| Allemand | Traduction |
|---|---|
| das Brot | le pain |
| der Käse | le fromage |
| der Apfel | la pomme |
| das Ei | l'œuf |
| die Milch | le lait |
| das Wasser | l'eau |
| der Saft | le jus |
| der Kuchen | le gâteau |

## 3. Im Restaurant bestellen (commander au restaurant)
Pour commander poliment, on utilise **Ich möchte …** (je voudrais) ou **Ich hätte gern …** (j'aimerais bien).

| Phrase | Traduction |
|---|---|
| Ich möchte einen Saft, bitte. | Je voudrais un jus, s'il vous plaît. |
| Ich hätte gern die Suppe. | J'aimerais bien la soupe. |
| Die Rechnung, bitte. | L'addition, s'il vous plaît. |
| Guten Appetit! | Bon appétit ! |

On appelle **die Speisekarte** la carte / le menu.

## 4. Les erreurs à éviter
- Ne pas oublier **bitte** (s'il vous plaît) : sans lui, la phrase paraît impolie.
- **Essen** est irrégulier : *ich esse*, mais *du isst*, *er isst* (le e devient i).
- Ne pas confondre les articles : on dit *das* Brot, mais *der* Käse.

## À retenir
- Trois repas : das Frühstück, das Mittagessen, das Abendessen.
- **essen** = manger, **trinken** = boire.
- Pour commander : **Ich möchte …** ou **Ich hätte gern …** + **bitte**.
- L'addition : **Die Rechnung, bitte.**
