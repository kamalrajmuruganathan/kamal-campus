# Describir a las personas

> Comment est ton meilleur ami ? Grand, brun, sympathique ?
> En espagnol, tu vas apprendre à décrire le physique et le caractère
> avec **ser**, **tener** et des adjectifs bien accordés.

## 1. Décrire le physique avec « ser »

On utilise **ser** (être) pour décrire quelqu'un.

| Personne | ser |
|---|---|
| yo | soy |
| tú | eres |
| él / ella | es |
| nosotros | somos |
| ellos | son |

| Adjectif | Français | Contraire |
|---|---|---|
| alto | grand | bajo (petit) |
| delgado | mince | gordo (gros) |
| joven | jeune | viejo (vieux) |
| guapo | beau | feo (laid) |
| moreno | brun | rubio (blond) |

Exemple : *Ana **es** alta y morena.*

## 2. Décrire avec « tener »

On utilise **tener** (avoir) pour les cheveux et les yeux.

| Personne | tener |
|---|---|
| yo | tengo |
| tú | tienes |
| él / ella | tiene |

| Phrase espagnole | Traduction |
|---|---|
| **Tiene el pelo** rubio. | Il/elle a les cheveux blonds. |
| **Tiene los ojos** azules. | Il/elle a les yeux bleus. |
| **Tengo el pelo** moreno. | J'ai les cheveux bruns. |

## 3. L'accord de l'adjectif

L'adjectif s'accorde en **genre** (masculin/féminin) et en **nombre** (singulier/pluriel).

| | Singulier | Pluriel |
|---|---|---|
| Masculin | alt**o** | alt**os** |
| Féminin | alt**a** | alt**as** |

Exemples : *El niño es alt**o**.* / *La niña es alt**a**.* / *Los niños son alt**os**.*

Les adjectifs qui finissent par **-e** ou consonne ne changent pas au féminin :
*Él es inteligent**e** / Ella es inteligent**e**.*

## 4. Le caractère

| Espagnol | Français | Contraire |
|---|---|---|
| simpático | sympathique | antipático (antipathique) |
| alegre | joyeux | triste (triste) |
| tímido | timide | hablador (bavard) |
| trabajador | travailleur | perezoso (paresseux) |

Exemple : *Mi amigo **es** simpático y trabajador.*

## 5. Les erreurs à éviter

- L'adjectif s'accorde : *Ana es alt**a*** (pas *Ana es alto*).
- On décrit avec **ser** (es alta), pas avec *estar* pour une caractéristique.
- Les cheveux et les yeux se disent avec **tener** : *tiene el pelo*, pas *es el pelo*.
- En espagnol, on dit *tiene **el** pelo rubio* (avec l'article el).

## À retenir

- Physique et caractère → **ser** : *es alta, es simpático*.
- Cheveux et yeux → **tener** : *tiene el pelo moreno, tiene los ojos verdes*.
- L'adjectif s'accorde : **-o** masculin, **-a** féminin, **-s** pluriel.
- Contraires utiles : alto/bajo, guapo/feo, simpático/antipático.
