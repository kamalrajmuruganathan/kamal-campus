# Vocabulaire : la nature et les animaux

> Décrire un paysage, nommer les animaux d'une forêt ou d'une ferme : ce lexique
> est essentiel pour parler de l'environnement, raconter une promenade ou comprendre
> un documentaire animalier en anglais.

## 1. Les paysages et la nature

| Anglais | Français |
|---|---|
| a forest | une forêt |
| a mountain | une montagne |
| a river | une rivière, un fleuve |
| a lake | un lac |
| the sea | la mer |
| a beach | une plage |
| a field | un champ |
| an island | une île |
| the sky | le ciel |
| a tree | un arbre |
| a flower | une fleur |

Exemple : *There is a river in the forest.* → Il y a une rivière dans la forêt.

## 2. Les animaux sauvages

| Anglais | Français |
|---|---|
| a lion | un lion |
| a bear | un ours |
| a wolf | un loup |
| a fox | un renard |
| an eagle | un aigle |
| a snake | un serpent |
| a frog | une grenouille |
| a deer | un cerf, une biche |
| an owl | un hibou, une chouette |

Exemple : *The wolf lives in the forest.* → Le loup vit dans la forêt.

## 3. Les animaux de la ferme et de la mer

| Anglais | Français |
|---|---|
| a cow | une vache |
| a horse | un cheval |
| a sheep | un mouton |
| a pig | un cochon |
| a goat | une chèvre |
| a hen | une poule |
| a whale | une baleine |
| a dolphin | un dauphin |
| a shark | un requin |
| a turtle | une tortue |

## 4. Les petits animaux et les verbes utiles

| Anglais | Français |
|---|---|
| a bee | une abeille |
| a butterfly | un papillon |
| an ant | une fourmi |
| a spider | une araignée |
| to fly | voler |
| to swim | nager |
| to grow | pousser, grandir |

## 5. Les erreurs à éviter

- Certains pluriels sont irréguliers : **a sheep → two sheep** (invariable),
  **a wolf → wolves**, **a fox → foxes**, **a mouse → mice**.
- « a deer » est invariable au pluriel : *two deer*.
- Ne confonds pas *a hen* (une poule) et *a chicken* (un poulet).
- Attention à l'orthographe de *mountain*, *butterfly*, *island* (le « s » ne se prononce pas).

## À retenir

- Paysages : *forest*, *mountain*, *river*, *lake*, *sea*, *beach*, *island*.
- Sauvages : *lion*, *bear*, *wolf*, *fox*, *eagle*, *snake*, *owl*.
- Ferme : *cow*, *horse*, *sheep*, *pig*, *hen*.
- Mer : *whale*, *dolphin*, *shark*, *turtle*.
- Pluriels irréguliers : *sheep → sheep*, *wolf → wolves*, *fox → foxes*.
