# Vocabulaire : die Stadt und Reisen

> Décrire une ville (**die Stadt**), se déplacer et voyager (**reisen**) : voici le
> vocabulaire pour s'orienter, prendre les transports et parler de ses vacances.

## 1. La ville et les lieux

| Allemand | Français |
|---|---|
| die Stadt | la ville |
| das Dorf | le village |
| die Straße | la rue |
| der Platz | la place |
| das Museum | le musée |
| die Kirche | l'église |
| das Schloss | le château |
| der Markt | le marché |
| die Brücke | le pont |

## 2. Les transports et le voyage

| Allemand | Français |
|---|---|
| der Bahnhof | la gare |
| der Zug | le train |
| das Flugzeug | l'avion |
| der Flughafen | l'aéroport |
| der Bus | le bus |
| das Fahrrad | le vélo |
| die U-Bahn | le métro |
| die Fahrkarte | le billet |
| der Koffer | la valise |
| die Reise | le voyage |
| der Urlaub | les vacances |

Exemple : *Wir machen eine Reise nach Berlin.* (Nous faisons un voyage à Berlin.)

## 3. S'orienter

| Allemand | Français |
|---|---|
| links | à gauche |
| rechts | à droite |
| geradeaus | tout droit |
| die Ampel | le feu (tricolore) |
| der Stadtplan | le plan de la ville |

## 4. Les erreurs à éviter

- « fahren » (aller en véhicule) ≠ « gehen » (aller à pied).
- On dit **mit dem** Bus / Zug / Fahrrad (avec le, au datif).
- « die Reise » = le voyage ; « der Urlaub » = les vacances ; à ne pas confondre.
- Tous les noms prennent une majuscule : die Stadt, der Bahnhof, das Museum.

## À retenir

- La ville : die Stadt, die Straße, der Platz, das Museum, die Kirche.
- Transports : der Zug, der Bus, das Flugzeug, das Fahrrad, die U-Bahn.
- S'orienter : links, rechts, geradeaus.
- Voyager : reisen, die Reise, der Koffer, die Fahrkarte, der Urlaub.
