# Die Possessivartikel

> Les possessifs (mein, dein, sein...) expriment l'appartenance. Ils se placent devant le nom et se déclinent exactement comme *ein* et *kein*.

## 1. Les possessifs de base
À chaque pronom personnel correspond un possessif :

| Pronom | Possessif | Pronom | Possessif |
|---|---|---|---|
| ich | mein | wir | unser |
| du | dein | ihr | euer |
| er | sein | sie (pl) | ihr |
| sie (elle) | ihr | Sie | Ihr |
| es | sein | | |

## 2. La déclinaison (comme ein/kein)
Les possessifs prennent les terminaisons de *ein/kein*. Comme pour l'accusatif, **seul le masculin change**.

| Genre | Nominatif | Accusatif | Exemple |
|---|---|---|---|
| Masculin | mein | **meinen** | Ich liebe **meinen** Hund. |
| Féminin | meine | meine | Meine Mutter / Ich sehe **meine** Mutter. |
| Neutre | mein | mein | Das ist **mein** Auto. |
| Pluriel | meine | meine | **Meine** Eltern wohnen hier. |

Attention à **euer** : devant une terminaison, il perd son 2e e → *eure Bücher*, *eure Mutter*.

## 3. sein ou ihr ?
Le possessif s'accorde avec **le possesseur** pour le choix (sein/ihr), puis avec **le nom possédé** pour la terminaison.
- er → **sein** : *Er sucht **seinen** Schlüssel.*
- sie / leur → **ihr** : *Anna liebt **ihre** Katze.*

## 4. Les erreurs à éviter
- Ne pas oublier le -en au masculin accusatif : *Ich liebe **meinen** Hund*.
- Ne pas confondre le possesseur et le nom possédé : *Anna liebt **ihren** Vater* (der Vater masc → ihren).
- euer devient **eure** devant une terminaison.

## À retenir
- mein, dein, sein, ihr, sein / unser, euer, ihr, Ihr.
- Déclinaison comme ein/kein : seul le masculin change (mein → meinen).
- euer → eure devant une terminaison.
- sein = à lui, ihr = à elle ou à eux.
