# Vocabulaire : Natur und Tiere

> La nature (**die Natur**) et les animaux (**die Tiere**) permettent de décrire
> un paysage, une promenade ou son animal préféré. Comme toujours en allemand,
> on retient chaque nom **avec son article** et sa majuscule.

## 1. Le paysage

| Allemand | Français |
|---|---|
| die Natur | la nature |
| der Baum | l'arbre |
| die Blume | la fleur |
| der Wald | la forêt |
| der Berg | la montagne |
| der See | le lac |
| der Fluss | la rivière, le fleuve |
| das Meer | la mer |

## 2. Le ciel et le temps

| Allemand | Français |
|---|---|
| die Sonne | le soleil |
| der Mond | la lune |
| der Himmel | le ciel |
| der Stern | l'étoile |
| die Wolke | le nuage |
| der Regen | la pluie |
| der Schnee | la neige |
| der Wind | le vent |

## 3. Les animaux

On apprend chaque nom **avec son article**.

| Allemand | Français |
|---|---|
| das Tier | l'animal |
| der Hund | le chien |
| die Katze | le chat |
| das Pferd | le cheval |
| die Kuh | la vache |
| der Vogel | l'oiseau |
| der Fisch | le poisson |
| der Löwe | le lion |
| der Bär | l'ours |
| der Fuchs | le renard |
| die Maus | la souris |
| der Schmetterling | le papillon |

## 4. Les verbes utiles

| Allemand | Français |
|---|---|
| leben | vivre |
| laufen | courir |
| fliegen | voler |
| schwimmen | nager |
| springen | sauter |

Exemple : *Der Vogel kann fliegen.* (L'oiseau peut voler.)

## 5. Les erreurs à éviter

- Ne jamais apprendre un animal sans son article : **der** Hund, **die** Katze, **das** Pferd.
- « der See » = le lac ; « die See » = la mer : attention au genre, il change le sens.
- « der Vogel » fait « die Vögel » au pluriel (Umlaut) ; « der Baum » → « die Bäume ».
- Tous les noms prennent une **majuscule** : der Baum, die Sonne, das Tier.

## À retenir

- On retient chaque nom **avec son article** : der Baum, die Blume, das Tier.
- Le paysage : der Wald, der Berg, der See, das Meer.
- Le ciel : die Sonne, der Mond, die Wolke, der Regen.
- Verbes clés : leben, laufen, fliegen, schwimmen, springen.
