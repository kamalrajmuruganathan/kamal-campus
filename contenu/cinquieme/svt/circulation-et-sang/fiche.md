# Circulation sanguine et sang

Les organes ont besoin de **nutriments** (venus de la digestion) et de
**dioxygène** (venu de la respiration). Comment leur parviennent-ils ? Grâce au
**sang**, mis en mouvement par le **cœur** dans un réseau de **vaisseaux
sanguins**. C'est l'**appareil circulatoire**.

## 1. Le cœur, une pompe

Le **cœur** est un **muscle creux** qui se contracte sans arrêt : il joue le
rôle d'une **pompe**. À chaque battement, il pousse le sang dans les vaisseaux.
Chez l'humain, il bat environ 60 à 80 fois par minute au repos, plus vite pendant
l'effort. C'est ce qui donne le **pouls** que l'on sent au poignet.

## 2. Les vaisseaux sanguins

Le sang circule dans trois types de vaisseaux :

- Les **artères** : elles **partent du cœur** et conduisent le sang vers les
  organes.
- Les **veines** : elles **ramènent le sang** des organes vers le cœur.
- Les **capillaires** : ce sont des vaisseaux **minuscules et très fins** qui
  traversent les organes. C'est là que se font les **échanges** entre le sang et
  les organes.

Le sang tourne toujours dans le même sens : il fait une **boucle** (circulation
en circuit fermé).

## 3. Les échanges avec les organes

Au niveau des **capillaires**, le sang **cède** aux organes ce dont ils ont
besoin et **récupère** leurs déchets :

- le sang **apporte** aux organes du **dioxygène** et des **nutriments** ;
- le sang **emporte** les **déchets** produits par les organes, en particulier le
  **dioxyde de carbone**.

Les organes qui travaillent beaucoup (comme un muscle pendant l'effort)
consomment davantage : ils sont alors **plus irrigués** par le sang.

## 4. La composition du sang

Le sang est un liquide rouge composé de :

- le **plasma** : liquide dans lequel baignent les cellules et qui transporte les
  nutriments et les déchets ;
- les **globules rouges** (hématies) : ils transportent le **dioxygène** ; ce
  sont eux qui donnent au sang sa couleur rouge ;
- les **globules blancs** (leucocytes) : ils **défendent** le corps contre les
  microbes ;
- les **plaquettes** : elles participent à la **coagulation** (formation d'un
  caillot qui arrête le saignement).

## Ce qu'il faut retenir

- Le **cœur** est un muscle qui **pompe** le sang dans les vaisseaux.
- **Artères** : du cœur vers les organes ; **veines** : des organes vers le cœur ;
  **capillaires** : échanges dans les organes.
- Le sang **apporte** dioxygène et nutriments et **emporte** les déchets.
- Le sang contient : **plasma**, **globules rouges**, **globules blancs**,
  **plaquettes**.

## Les erreurs à éviter

- Le cœur ne « respire » pas et ne « digère » pas : c'est une **pompe** qui fait
  circuler le sang.
- Les **artères** ne contiennent pas toujours du sang riche en dioxygène : ce qui
  les définit, c'est qu'elles **partent du cœur**.
- Les **globules blancs** ne transportent pas le dioxygène : ce sont les
  **globules rouges** qui le font.
- Le sang ne fabrique pas les nutriments : il les **transporte** après la
  digestion.
