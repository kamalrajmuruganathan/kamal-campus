# Le futur simple et le conditionnel présent

> Le futur dit ce qui **va arriver** ; le conditionnel dit ce qui **pourrait arriver**. Leurs formes se ressemblent beaucoup : attention à ne pas les confondre !

## 1. Le futur simple

Le **futur simple** exprime une action à venir, considérée comme certaine.
On le forme souvent sur l'**infinitif** + les terminaisons **-ai, -as, -a, -ons, -ez, -ont**.

| Personne | chanter | finir |
|---|---|---|
| je | chanterai | finirai |
| tu | chanteras | finiras |
| il/elle | chantera | finira |
| nous | chanterons | finirons |
| vous | chanterez | finirez |
| ils/elles | chanteront | finiront |

*Demain, nous partirons à l'aube.*

## 2. Le conditionnel présent

Le **conditionnel présent** exprime une action possible, soumise à une condition, un souhait ou la politesse.
On le forme sur le **même radical** que le futur + les terminaisons de l'imparfait **-ais, -ais, -ait, -ions, -iez, -aient**.

| Personne | chanter | finir |
|---|---|---|
| je | chanterais | finirais |
| tu | chanterais | finirais |
| il/elle | chanterait | finirait |
| nous | chanterions | finirions |
| vous | chanteriez | finiriez |
| ils/elles | chanteraient | finiraient |

*Je voudrais un peu d'eau, s'il vous plaît.* (politesse)
*Si j'avais le temps, je lirais davantage.* (condition)

## 3. Les erreurs à éviter

- **je chanterai** (futur, -ai) / **je chanterais** (conditionnel, -ais) : le -s change tout ! Astuce : remplace par « nous » → *nous chanterons* (futur) / *nous chanterions* (conditionnel).
- Après « si » de condition, on n'emploie **pas** le conditionnel : on écrit *Si j'avais…* (imparfait), pas « si j'aurais ».
- Ne pas oublier le radical irrégulier de certains verbes : *aller → j'irai / j'irais*, *être → je serai / je serais*, *avoir → j'aurai / j'aurais*, *faire → je ferai / je ferais*, *venir → je viendrai / je viendrais*.

## À retenir

- **Futur simple** : action certaine à venir ; terminaisons **-ai, -as, -a, -ons, -ez, -ont**.
- **Conditionnel présent** : action possible, souhait, politesse ; terminaisons **-ais, -ais, -ait, -ions, -iez, -aient**.
- Même **radical** pour les deux (souvent l'infinitif).
- Astuce « nous » : *nous chanterons* (futur) ≠ *nous chanterions* (conditionnel).
- Jamais de conditionnel après « si » de condition : *si j'avais* (et non « si j'aurais »).
