# Les expansions du nom : épithète, complément du nom, relative

> Un nom seul dit peu de chose : « une maison ». Mais « une **vieille** maison **de pierre** **qui domine la mer** », voilà une image précise ! Les mots qui viennent enrichir le nom s'appellent les **expansions du nom**.

## 1. Le groupe nominal et son noyau

Le **groupe nominal** (GN) est organisé autour d'un mot principal, le **nom noyau**. Autour de ce noyau, on peut ajouter des mots qui le précisent : ce sont les **expansions du nom**.

| Groupe nominal | Noyau | Expansion |
|---|---|---|
| une grande forêt | forêt | grande |
| le chien du voisin | chien | du voisin |
| l'homme qui rit | homme | qui rit |

On peut toujours supprimer une expansion : la phrase reste correcte, mais moins précise.

## 2. Les trois grandes expansions

**a) L'adjectif épithète** est un adjectif qualificatif placé directement à côté du nom, sans mot de liaison.

| Exemple | Adjectif épithète |
|---|---|
| une **belle** histoire | belle |
| un ciel **étoilé** | étoilé |

**b) Le complément du nom** est un groupe introduit par une **préposition** (de, à, en, pour…).

| Exemple | Complément du nom |
|---|---|
| un verre **de lait** | de lait |
| une machine **à laver** | à laver |

**c) La proposition subordonnée relative** est introduite par un **pronom relatif** (qui, que, dont, où…) et contient un verbe conjugué.

| Exemple | Relative |
|---|---|
| le livre **que je lis** | que je lis |
| la ville **où je suis né** | où je suis né |

## 3. Les erreurs à éviter

- Ne pas confondre l'épithète (collée au nom : *un chat noir*) et l'attribut du sujet (après le verbe être : *le chat est noir*).
- Le complément du nom commence par une **préposition** ; sans préposition, ce n'est pas un complément du nom.
- Une relative contient toujours un **verbe conjugué** : *le train qui arrive*. « Le train de Paris » n'est pas une relative, c'est un complément du nom.
- L'adjectif épithète s'**accorde** avec le nom : *des fleurs blanches* (et non « des fleurs blanc »).

## À retenir

- Le **noyau** du groupe nominal est le nom principal.
- Les **expansions** enrichissent le nom : on peut les supprimer.
- Trois expansions à connaître : **adjectif épithète**, **complément du nom** (avec préposition), **proposition subordonnée relative** (avec pronom relatif + verbe conjugué).
- L'épithète s'accorde avec le nom ; le complément du nom et la relative se placent après le nom.
