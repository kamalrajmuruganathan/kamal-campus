# Vocabulaire : la città e i viaggi (la ville et les voyages)

> Savoir décrire une ville, demander son chemin et parler de ses déplacements est
> essentiel pour voyager en Italie. Ce chapitre réunit le lexique de la *città* et des *viaggi*.

## 1. In città (dans la ville)

| Italien | Français |
|---|---|
| la piazza | la place |
| la via / la strada | la rue / la route |
| il centro | le centre-ville |
| il museo | le musée |
| la chiesa | l'église |
| il negozio | le magasin |
| il mercato | le marché |
| la stazione | la gare |
| l'ospedale | l'hôpital |

Exemple : *La stazione è in centro.* → La gare est dans le centre.

## 2. I mezzi di trasporto (les moyens de transport)

| Italien | Français |
|---|---|
| il treno | le train |
| l'autobus | le bus |
| la macchina | la voiture |
| la bicicletta | le vélo |
| l'aereo | l'avion |
| la metropolitana | le métro |
| a piedi | à pied |

Exemple : *Vado a scuola in autobus.* → Je vais à l'école en bus.

## 3. Chiedere e dare indicazioni (demander et donner son chemin)

| Italien | Français |
|---|---|
| Dov'è…? | Où est… ? |
| a destra | à droite |
| a sinistra | à gauche |
| sempre dritto | tout droit |
| vicino | près |
| lontano | loin |
| girare | tourner |
| attraversare | traverser |

Exemple : *Gira a destra e poi sempre dritto.* → Tourne à droite puis tout droit.

## 4. Il viaggio (le voyage)

| Italien | Français |
|---|---|
| il biglietto | le billet |
| la valigia | la valise |
| l'albergo / l'hotel | l'hôtel |
| la vacanza | les vacances |
| la partenza | le départ |
| l'arrivo | l'arrivée |
| il turista | le touriste |

Exemple : *Compro il biglietto del treno.* → J'achète le billet de train.

## 5. Les erreurs à éviter

- On voyage **in** + moyen de transport : *in treno, in macchina, in aereo*, MAIS **a piedi** (à pied).
- *la macchina* signifie « la voiture » (et aussi « la machine ») ; le contexte tranche.
- Ne confonds pas *la via / la strada* (la rue) et *il viaggio* (le voyage).
- *sempre dritto* = tout droit ; ne pas confondre *dritto* (droit devant) et *a destra* (à droite).
- Attention aux doubles consonnes : *la pia**zz**a*, *la ma**cch**ina*, *la va**l**i**g**ia*, *l'albe**rg**o*.

## À retenir

- La ville : *la piazza*, *la via*, *il museo*, *la stazione*, *il negozio*.
- Les transports : *il treno*, *l'autobus*, *la macchina*, *la bicicletta*, *l'aereo*.
- On dit *in treno*, *in macchina*, mais *a piedi*.
- S'orienter : *a destra*, *a sinistra*, *sempre dritto*, *vicino*, *lontano*.
- Le voyage : *il biglietto*, *la valigia*, *l'albergo*, *la vacanza*.
