# Vocabulaire : la natura e gli animali (la nature et les animaux)

> Parler de la nature, du paysage, du temps qu'il fait et des animaux permet de décrire
> le monde qui t'entoure. Ce chapitre réunit le lexique de la *natura* et des *animali*.

## 1. Il paesaggio (le paysage)

| Italien | Français |
|---|---|
| la montagna | la montagne |
| il mare | la mer |
| il fiume | le fleuve, la rivière |
| il lago | le lac |
| il bosco / la foresta | le bois / la forêt |
| la campagna | la campagne |
| il prato | le pré |
| la spiaggia | la plage |
| l'albero | l'arbre |

Exemple : *In estate vado al mare.* → En été je vais à la mer.

## 2. Il tempo e le stagioni (le temps et les saisons)

| Italien | Français |
|---|---|
| il sole | le soleil |
| la pioggia | la pluie |
| il vento | le vent |
| la neve | la neige |
| il cielo | le ciel |
| la primavera | le printemps |
| l'estate | l'été |
| l'autunno | l'automne |
| l'inverno | l'hiver |

Exemple : *Oggi c'è il sole e fa caldo.* → Aujourd'hui il y a du soleil et il fait chaud.

## 3. Gli animali (les animaux)

| Italien | Français |
|---|---|
| il cane | le chien |
| il gatto | le chat |
| il cavallo | le cheval |
| la mucca | la vache |
| l'uccello | l'oiseau |
| il pesce | le poisson |
| la farfalla | le papillon |
| il topo | la souris |
| il leone | le lion |

Exemple : *Il cane corre nel prato.* → Le chien court dans le pré.

## 4. Les erreurs à éviter

- Pour la météo, on emploie souvent *fare* : *fa caldo* (il fait chaud), *fa freddo* (il fait froid).
- *c'è il sole* = il y a du soleil ; *piove* = il pleut ; *nevica* = il neige (verbes impersonnels).
- *il mare* (la mer) est masculin en italien, alors que « la mer » est féminin en français.
- Ne confonds pas *il bosco* (le petit bois) et *la foresta* (la grande forêt).
- Attention aux doubles consonnes : *la fa**rf**alla*, *la mu**cc**a*, *il ga**tt**o*, *la spia**gg**ia*.

## À retenir

- Le paysage : *la montagna*, *il mare*, *il fiume*, *il lago*, *il bosco*, *la campagna*.
- Le temps : *il sole*, *la pioggia*, *il vento*, *la neve* ; *fa caldo*, *fa freddo*.
- Les saisons : *la primavera*, *l'estate*, *l'autunno*, *l'inverno*.
- Les animaux : *il cane*, *il gatto*, *il cavallo*, *la mucca*, *l'uccello*.
- Météo impersonnelle : *piove* (il pleut), *nevica* (il neige).
