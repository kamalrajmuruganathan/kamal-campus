# Reconnaître les classes de mots (nom, verbe, adjectif, déterminant)

> Chaque mot d'une phrase a un rôle : c'est sa **classe de mots** (on dit aussi
> sa « nature »). Savoir reconnaître ces classes t'aide à mieux écrire et à ne
> plus faire d'erreurs.

## 1. Le nom

Le **nom** désigne une personne, un animal, une chose ou une idée.

| Ce qu'il désigne | Exemple |
|---|---|
| une personne | la **maîtresse**, un **garçon** |
| un animal | le **chat**, une **girafe** |
| une chose | la **table**, un **ballon** |
| une ville, un prénom | **Paris**, **Léa** (noms propres, avec une majuscule) |

Astuce : devant un nom, on peut souvent mettre **le, la, un, une** (un chat, une table).

## 2. Le déterminant

Le **déterminant** est le petit mot placé **devant le nom**. Il montre le genre
(masculin/féminin) et le nombre (singulier/pluriel).

| Déterminants | Exemple |
|---|---|
| le, la, l', les | **le** livre, **les** livres |
| un, une, des | **une** fleur, **des** fleurs |
| mon, ton, son, ma, ta, sa, mes, tes, ses | **mon** cartable |
| ce, cette, ces | **cette** voiture |

## 3. Le verbe

Le **verbe** dit ce que l'on **fait** ou ce que l'on **est**. Il change quand
on change le temps (hier, aujourd'hui, demain).

| Exemple | Le verbe |
|---|---|
| Léa **mange** une pomme. | manger |
| Nous **jouons** dans la cour. | jouer |
| Le chien **court**. | courir |

Astuce : le verbe change si tu dis « Hier, je… » / « Demain, je… ».

## 4. L'adjectif

L'**adjectif** donne une précision sur le nom : il dit **comment** est la
personne, l'animal ou la chose.

| Nom seul | Nom + adjectif |
|---|---|
| une voiture | une **grande** voiture |
| un chat | un chat **noir** |
| des fleurs | des **jolies** fleurs |

L'adjectif s'accorde avec le nom : un chat noir → des chats **noirs**.

## 5. Les erreurs à éviter
- Ne confonds pas le **nom** et le **verbe** : « la **danse** » (nom) / « je
  **danse** » (verbe).
- Le **déterminant** ne s'emploie jamais tout seul : il est toujours devant un nom.
- L'**adjectif** n'est pas un nom : « **rouge** » est un adjectif dans « une pomme rouge ».
- N'oublie pas la **majuscule** aux noms propres (Léa, Paris).

## À retenir
- Le **nom** désigne une personne, un animal, une chose (le, la, un, une devant).
- Le **déterminant** est le petit mot devant le nom.
- Le **verbe** dit ce que l'on fait ; il change avec le temps.
- L'**adjectif** précise comment est le nom et s'accorde avec lui.
