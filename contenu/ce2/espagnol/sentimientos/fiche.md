# Los sentimientos

> Es-tu content, triste ou fatigué aujourd'hui ? En espagnol, on dit comment
> on se sent avec le verbe **estar** (être, dans le sens d'un état passager).
> Tu vas apprendre à répondre à **¿Cómo estás?** (Comment vas-tu ?).

## 1. ¿Cómo estás? Dire comment on va
On répond avec le verbe **estar**.

| Espagnol | Traduction |
|---|---|
| Estoy bien. | Je vais bien. |
| Estoy mal. | Je vais mal. |
| Estoy regular. | Je vais comme ci comme ça. |

## 2. Los sentimientos : les sentiments
Les adjectifs changent selon qu'on est un garçon (**-o**) ou une fille (**-a**).

| Espagnol (garçon / fille) | Traduction |
|---|---|
| contento / contenta | content(e) |
| triste | triste |
| cansado / cansada | fatigué(e) |
| enfadado / enfadada | fâché(e) |
| nervioso / nerviosa | nerveux(se) |
| asustado / asustada | effrayé(e) |
| aburrido / aburrida | ennuyé(e) |

Exemples : **Estoy contento.** (Je suis content — garçon.) ·
**Estoy contenta.** (Je suis contente — fille.) ·
**Estoy triste.** (« triste » ne change pas.)

## 3. Poser la question à quelqu'un
- **¿Cómo estás?** → Comment vas-tu ?
- **¿Cómo está tu hermana?** → Comment va ta sœur ?
- **Está cansada.** → Elle est fatiguée.

## 4. Les erreurs à éviter
- Pour un état/sentiment, on utilise **estar**, pas **ser** : on dit **estoy cansado**.
- On accorde l'adjectif : une fille dit **contenta**, un garçon dit **contento**.
- **triste** est pareil au masculin et au féminin : **estoy triste** pour tout le monde.

## À retenir
- On dit comment on se sent avec **estar** : **Estoy bien / mal / regular.**
- Les sentiments : **contento, triste, cansado, enfadado, nervioso…**
- On accorde en **-o** (garçon) ou **-a** (fille).
- La question : **¿Cómo estás?**
