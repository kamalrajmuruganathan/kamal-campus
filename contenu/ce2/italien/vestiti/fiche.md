# I vestiti

> Comment s'appellent les vêtements en italien ? Apprends à nommer ce que tu portes chaque jour : la maglietta, i pantaloni, le scarpe… et à dire « Porto una giacca ! »

## 1. Les vêtements de tous les jours

| Français | Italien |
|---|---|
| le tee-shirt | **la maglietta** |
| le pantalon | **i pantaloni** |
| la jupe | **la gonna** |
| la robe | **il vestito** |
| la chemise | **la camicia** |
| le pull | **il maglione** |

Remarque : « i pantaloni » est toujours au pluriel, comme en français « les pantalons ».

## 2. Pour se couvrir

| Français | Italien |
|---|---|
| le manteau | **il cappotto** |
| la veste | **la giacca** |
| les chaussures | **le scarpe** |
| les chaussettes | **i calzini** |
| l'écharpe | **la sciarpa** |
| le chapeau | **il cappello** |

Attention aux doubles consonnes : ca**pp**otto, ca**pp**ello, gia**cc**a.

## 3. Dire ce qu'on porte

On utilise le verbe **portare** (porter).

| Français | Italien |
|---|---|
| Je porte un tee-shirt. | **Porto** una maglietta. |
| Je porte des chaussures. | **Porto** le scarpe. |
| Tu portes une veste. | **Porti** una giacca. |

## 4. Les erreurs à éviter
- Ne confonds pas **il cappotto** (le manteau) et **il cappello** (le chapeau) !
- « il vestito » veut dire « la robe » (ou un costume), pas seulement « le vêtement ».
- « le scarpe » et « i calzini » vont par paire : on les emploie au pluriel.

## À retenir
- Vêtements : la maglietta, i pantaloni, la gonna, il vestito, la camicia, il maglione.
- Pour sortir : il cappotto, la giacca, le scarpe, i calzini, la sciarpa, il cappello.
- Le verbe **portare** : Porto / Porti… un vêtement.
- Attention : cappotto (manteau) ≠ cappello (chapeau).
