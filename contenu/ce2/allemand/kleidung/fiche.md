# Die Kleidung

> Que portes-tu aujourd'hui ? En allemand, les vêtements se disent
> **die Kleidung**. Tu vas apprendre les mots comme **der Pullover**, **die Hose**,
> **die Schuhe**, et la phrase **« Ich trage… »** (je porte…).

## 1. Les vêtements (die Kleidung)

Chaque vêtement a son article (der, die ou das).

| Français | Allemand |
|---|---|
| le pull | **der Pullover** |
| le pantalon | **die Hose** |
| la robe | **das Kleid** |
| le t-shirt | **das T-Shirt** |
| la veste | **die Jacke** |
| les chaussures | **die Schuhe** |

Attention : **die Hose** est au singulier en allemand (« le pantalon »), alors qu'en français on dit parfois « un pantalon ».

## 2. Dire ce qu'on porte : « Ich trage… »

Le verbe **tragen** veut dire « porter ».

| Français | Allemand |
|---|---|
| Je porte un pull. | **Ich trage einen Pullover.** |
| Tu portes une robe. | **Du trägst ein Kleid.** |
| Il porte une veste. | **Er trägt eine Jacke.** |

Remarque l'Umlaut qui apparaît : **ich trage** mais **du trägst**, **er trägt**.

## 3. Décrire avec une couleur

On place la couleur devant le vêtement.

| Français | Allemand |
|---|---|
| un pull rouge | **ein roter Pullover** |
| une robe bleue | **ein blaues Kleid** |
| des chaussures noires | **schwarze Schuhe** |

Pour l'oral, tu peux déjà dire simplement : **Der Pullover ist rot.** (Le pull est rouge.)

## 4. Les erreurs à éviter

- Chaque vêtement a son article : **der** Pullover, **die** Hose, **das** Kleid.
- Tous les noms prennent une majuscule : **die Jacke**, pas *die jacke*.
- Avec **du** et **er**, le verbe devient **trägst / trägt** (Umlaut).
- **die Schuhe** est un pluriel (les chaussures).

## À retenir

- **die Kleidung** = les vêtements.
- Chaque vêtement a un article : der / die / das.
- Pour dire ce qu'on porte : **Ich trage…**
- Le verbe **tragen** prend un Umlaut : *du trägst*, *er trägt*.
