# Vocabulaire : la nourriture et les repas

> Parler de ce que l'on aime manger est l'un des premiers plaisirs quand on apprend
> l'anglais. Ce lexique te permet de commander un repas, de dire ce que tu préfères
> et de comprendre un menu ou une recette.

## 1. Les repas de la journée

| Anglais | Français |
|---|---|
| breakfast | le petit-déjeuner |
| lunch | le déjeuner |
| dinner | le dîner |
| a snack | un goûter, un en-cas |
| a meal | un repas |

Exemple : *I have breakfast at seven.* → Je prends le petit-déjeuner à sept heures.

## 2. Les fruits et les légumes

| Anglais | Français |
|---|---|
| an apple | une pomme |
| a banana | une banane |
| an orange | une orange |
| a strawberry | une fraise |
| a carrot | une carotte |
| a potato | une pomme de terre |
| a tomato | une tomate |
| an onion | un oignon |

Exemple : *I like apples but I don't like onions.* → J'aime les pommes mais je n'aime pas les oignons.

## 3. Les autres aliments et les boissons

| Anglais | Français |
|---|---|
| bread | le pain |
| cheese | le fromage |
| meat | la viande |
| chicken | le poulet |
| fish | le poisson |
| an egg | un œuf |
| rice | le riz |
| a cake | un gâteau |
| water | l'eau |
| milk | le lait |
| juice | le jus |

Exemple : *Can I have some water, please?* → Puis-je avoir de l'eau, s'il te plaît ?

## 4. Dire ce que l'on veut

- *I'm hungry.* → J'ai faim.
- *I'm thirsty.* → J'ai soif.
- *I'd like a sandwich.* → Je voudrais un sandwich.
- *to eat* → manger, *to drink* → boire, *to cook* → cuisiner.

## 5. Les erreurs à éviter

- « bread », « water », « rice », « meat » sont **indénombrables** : pas de pluriel,
  on dit *some bread*, jamais *a bread* ni *breads*.
- Attention à l'orthographe : *breakfast* (un seul mot), *vegetable*.
- « chicken » = le poulet (la viande) ; l'animal vivant est aussi *a chicken* / *a hen*.
- Ne confonds pas *to cook* (cuisiner) et *a cook / a cooker* : *a cook* est un cuisinier,
  *a cooker* est une cuisinière (l'appareil).

## À retenir

- Les repas : *breakfast*, *lunch*, *dinner*, *a snack*.
- Les fruits : *apple*, *banana*, *orange*, *strawberry*.
- Les légumes : *carrot*, *potato*, *tomato*, *onion*.
- Boissons : *water*, *milk*, *juice*.
- *I'm hungry* / *I'm thirsty* / *I'd like…* pour demander à manger ou à boire.
