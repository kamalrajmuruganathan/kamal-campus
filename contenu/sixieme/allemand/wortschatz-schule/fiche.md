# Vocabulaire : die Schule

> L'école (**die Schule**) est le premier univers que l'on décrit en allemand :
> les personnes, les objets et les activités de la classe. On apprend chaque nom
> **avec son article**, car le genre allemand ne suit pas le français.

## 1. Les personnes et les lieux

| Allemand | Français |
|---|---|
| die Schule | l'école |
| das Klassenzimmer | la salle de classe |
| der Lehrer / die Lehrerin | le professeur / la professeure |
| der Schüler / die Schülerin | l'élève |
| die Klasse | la classe |
| die Pause | la récréation |
| der Unterricht | le cours |

## 2. Le matériel scolaire

On apprend le vocabulaire du cartable **avec l'article**.

| Allemand | Français |
|---|---|
| das Buch | le livre |
| das Heft | le cahier |
| der Bleistift | le crayon (à papier) |
| der Kugelschreiber | le stylo |
| der Radiergummi | la gomme |
| das Lineal | la règle |
| die Schere | les ciseaux |
| der Rucksack | le sac à dos |
| die Tafel | le tableau |

## 3. Les activités et les mots utiles

| Allemand | Français |
|---|---|
| lernen | apprendre |
| schreiben | écrire |
| lesen | lire |
| rechnen | calculer |
| das Fach | la matière |
| die Note | la note |
| die Hausaufgaben | les devoirs |
| die Prüfung | l'examen |

Exemple : *Ich lerne Deutsch in der Schule.* (J'apprends l'allemand à l'école.)

## 4. Les erreurs à éviter

- Ne pas apprendre le nom sans article : dis **die** Schule, **das** Buch, **der** Lehrer.
- « der Lehrer » (homme) / « die Lehrerin » (femme) : le **-in** marque le féminin.
- « das Fach » = la matière (Mathe, Deutsch...) ; « der Unterricht » = le cours.
- Tous les noms prennent une **majuscule** : die Schule, das Heft, der Stift.

## À retenir

- On apprend chaque nom **avec son article** : die Schule, das Buch, der Lehrer.
- Personnes : der Lehrer / die Lehrerin, der Schüler / die Schülerin.
- Matériel : das Heft, der Bleistift, das Lineal, die Schere, der Rucksack.
- Activités : lernen, schreiben, lesen, rechnen.
