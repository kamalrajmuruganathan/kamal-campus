# Vocabulaire : Essen und Mahlzeiten

> Manger (**essen**) et boire (**trinken**) font partie du quotidien : c'est un
> des tout premiers thèmes que l'on décrit en allemand. On apprend chaque aliment
> **avec son article**, car le genre allemand ne suit jamais le genre français.

## 1. Les repas de la journée

| Allemand | Français |
|---|---|
| die Mahlzeit | le repas |
| das Frühstück | le petit-déjeuner |
| das Mittagessen | le déjeuner |
| das Abendessen | le dîner |
| der Hunger | la faim |
| der Durst | la soif |

Exemple : *Ich habe Hunger.* (J'ai faim.) — mot à mot « j'ai de la faim ».

## 2. Les aliments

On apprend chaque nom **avec son article**.

| Allemand | Français |
|---|---|
| das Brot | le pain |
| das Brötchen | le petit pain |
| der Käse | le fromage |
| die Wurst | la saucisse / la charcuterie |
| das Ei | l'œuf |
| das Fleisch | la viande |
| der Fisch | le poisson |
| das Gemüse | les légumes |
| das Obst | les fruits |
| der Apfel | la pomme |
| die Kartoffel | la pomme de terre |
| der Kuchen | le gâteau |

## 3. Les boissons

| Allemand | Français |
|---|---|
| das Wasser | l'eau |
| die Milch | le lait |
| der Saft | le jus |
| der Kaffee | le café |
| der Tee | le thé |

## 4. Les verbes et les mots utiles

| Allemand | Français |
|---|---|
| essen | manger |
| trinken | boire |
| kochen | cuisiner |
| schmecken | avoir bon goût, plaire (au goût) |
| der Zucker | le sucre |
| das Salz | le sel |

Exemple : *Der Kuchen schmeckt gut.* (Le gâteau est bon.) — À table, on souhaite
**Guten Appetit!** (Bon appétit !)

## 5. Les erreurs à éviter

- Ne jamais apprendre un aliment sans son article : dis **das** Brot, **der** Apfel, **die** Milch.
- « essen » = manger (pour les personnes) ; « fressen » se réserve aux animaux.
- « das Obst » (les fruits) et « das Gemüse » (les légumes) sont des noms au **singulier** en allemand.
- Tous les noms prennent une **majuscule** : das Brot, der Käse, die Wurst.

## À retenir

- On apprend chaque aliment **avec son article** : das Brot, der Apfel, die Milch.
- Les repas : das Frühstück, das Mittagessen, das Abendessen.
- Verbes clés : essen, trinken, kochen, schmecken.
- Expressions : Ich habe Hunger / Durst, Guten Appetit!
