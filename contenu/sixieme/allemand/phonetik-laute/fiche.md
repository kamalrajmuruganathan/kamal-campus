# Die Laute und das Alphabet

> L'allemand s'écrit avec les 26 lettres de l'alphabet latin, plus trois lettres à
> tréma (**ä, ö, ü**) et un signe particulier, le **ß**. Ce chapitre porte sur ce
> qui se **voit à l'écrit** : les lettres, les groupes de lettres et les rimes.

## 1. L'alphabet et les Umlaute

L'alphabet allemand de base compte **26 lettres** (a à z). On y ajoute :

| Lettre | Nom | Description |
|---|---|---|
| ä | a-Umlaut | un « a » avec deux points |
| ö | o-Umlaut | un « o » avec deux points |
| ü | u-Umlaut | un « u » avec deux points |
| ß | Eszett (scharfes S) | remplace parfois « ss » |

Un **Umlaut**, ce sont **deux points** au-dessus d'une voyelle : seuls **a, o, u**
peuvent en recevoir (ä, ö, ü). Les voyelles simples sont : **a, e, i, o, u**.

## 2. Les groupes de lettres (ch, sch)

Certains sons s'écrivent avec plusieurs lettres :

| Groupe | Nb de lettres | Exemples |
|---|---|---|
| ch | 2 lettres | Bu**ch**, i**ch**, na**ch** |
| sch | 3 lettres | **Sch**ule, Fi**sch**, **sch**ön |

**sch** s'écrit avec **trois lettres** mais note **un seul son**.

## 3. Le ß et les voyelles longues

Le **ß** (Eszett) ne se trouve **jamais au début** d'un mot. On le voit dans
*Straße*, *groß*, *Fuß*, *weiß*. Une voyelle écrite **double** est longue :
*See* (ee), *Boot* (oo), *Saal* (aa).

## 4. Les rimes

Deux mots riment quand ils se terminent par le même son écrit :

| Mot | Rime avec |
|---|---|
| Haus | Maus |
| Baum | Traum |
| klein | Bein |
| Katze | Tatze |

## À retenir

- L'alphabet de base a **26 lettres** ; on ajoute **ä, ö, ü** et le **ß**.
- Un Umlaut = **deux points** sur a, o ou u → ä, ö, ü.
- **ch** = 2 lettres, **sch** = 3 lettres (un seul son).
- Le **ß** n'est jamais en début de mot (Straße, Fuß, groß).
