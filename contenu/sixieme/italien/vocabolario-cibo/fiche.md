# Vocabulaire : il cibo (la nourriture)

> La cuisine, *la cucina*, est au cœur de la culture italienne. Ce chapitre te donne le
> lexique pour parler des repas, des aliments et pour commander au restaurant.

## 1. I pasti e la tavola (les repas et la table)

| Italien | Français |
|---|---|
| la colazione | le petit-déjeuner |
| il pranzo | le déjeuner |
| la cena | le dîner |
| la merenda | le goûter |
| il piatto | l'assiette, le plat |
| il bicchiere | le verre |
| la forchetta | la fourchette |
| il coltello | le couteau |
| il cucchiaio | la cuillère |

Exemple : *A colazione bevo un bicchiere di latte.* → Au petit-déjeuner je bois un verre de lait.

## 2. Gli alimenti (les aliments)

| Italien | Français |
|---|---|
| il pane | le pain |
| la pasta | les pâtes |
| il formaggio | le fromage |
| la carne | la viande |
| il pesce | le poisson |
| la frutta | les fruits |
| la verdura | les légumes |
| il latte | le lait |
| l'acqua | l'eau |

Exemple : *Mangio la pasta con il formaggio.* → Je mange des pâtes avec du fromage.

## 3. Al ristorante (au restaurant)

| Italien | Français |
|---|---|
| il menù | le menu |
| l'antipasto | l'entrée |
| il primo (piatto) | le premier plat (pâtes, soupe…) |
| il secondo (piatto) | le plat principal (viande, poisson) |
| il dolce | le dessert |
| il conto | l'addition |
| il cameriere, la cameriera | le serveur, la serveuse |
| Vorrei… | Je voudrais… |
| Buon appetito! | Bon appétit ! |

Exemple : *Vorrei un primo e un dolce, per favore.* → Je voudrais un premier plat et un dessert, s'il vous plaît.

## 4. Les erreurs à éviter

- *la frutta* (les fruits) et *la verdura* (les légumes) sont des **singuliers collectifs** : on dit *mangio la frutta*, pas « i frutti ».
- Ne confonds pas *la pasta* (les pâtes / la pâte) et *il pane* (le pain).
- « Je voudrais » se dit *vorrei* (forme polie), pas *voglio* (je veux), plus direct.
- Attention aux doubles consonnes : *la fo**rch**etta*, *il cu**cch**iaio*, *il forma**gg**io*, *il co**lt**ello*.
- En italien, le repas de midi est *il pranzo* ; *la cena* est le repas du soir.

## À retenir

- Les repas : *la colazione*, *il pranzo*, *la cena*, *la merenda*.
- Le couvert : *il piatto*, *il bicchiere*, *la forchetta*, *il coltello*, *il cucchiaio*.
- Les aliments : *il pane*, *la pasta*, *la carne*, *il pesce*, *la frutta*, *la verdura*.
- Au restaurant : *l'antipasto*, *il primo*, *il secondo*, *il dolce*, *il conto*.
- Pour commander poliment : *Vorrei…, per favore.*
