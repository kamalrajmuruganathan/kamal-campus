# Il presente dei verbi regolari (-are/-ere/-ire)

> En italien, les verbes réguliers se classent en trois groupes selon leur terminaison :
> **-are**, **-ere**, **-ire**. Pour conjuguer, on enlève la terminaison et on ajoute
> les désinences du présent.

## 1. Les verbes en -are : *parlare* (parler)

| Personne | Forme | Traduction |
|---|---|---|
| io | parl**o** | je parle |
| tu | parl**i** | tu parles |
| lui/lei | parl**a** | il/elle parle |
| noi | parl**iamo** | nous parlons |
| voi | parl**ate** | vous parlez |
| loro | parl**ano** | ils/elles parlent |

## 2. Les verbes en -ere : *prendere* (prendre)

| Personne | Forme |
|---|---|
| io | prend**o** |
| tu | prend**i** |
| lui/lei | prend**e** |
| noi | prend**iamo** |
| voi | prend**ete** |
| loro | prend**ono** |

## 3. Les verbes en -ire : *dormire* (dormir)

| Personne | Forme |
|---|---|
| io | dorm**o** |
| tu | dorm**i** |
| lui/lei | dorm**e** |
| noi | dorm**iamo** |
| voi | dorm**ite** |
| loro | dorm**ono** |

**Cas particulier :** certains verbes en -ire ajoutent **-isc-** : *capire* → io cap**isco**, tu cap**isci**, lui cap**isce**, noi cap**iamo**, voi cap**ite**, loro cap**iscono**.

## 4. Les erreurs à éviter

- Ne pas mélanger les groupes : *parlate* (-are) mais *prendete* (-ere) et *dormite* (-ire).
- « noi » fait toujours **-iamo** dans les trois groupes.
- La 3e personne du pluriel : -are → **-ano**, -ere/-ire → **-ono**.

## À retenir

- Trois groupes : -are, -ere, -ire.
- « io » → -o, « tu » → -i, « noi » → -iamo (partout).
- « voi » : -ate / -ete / -ite selon le groupe.
- « loro » : -ano (-are) ou -ono (-ere/-ire).
