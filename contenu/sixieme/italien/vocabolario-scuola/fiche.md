# Vocabulaire : la scuola (l'école)

> L'école, *la scuola*, est le premier univers que tu apprends à décrire en italien.
> Connaître le nom des lieux, des personnes, des matières et du matériel te permet de
> comprendre ton professeur et de parler de ta journée.

## 1. I luoghi e le persone della scuola (les lieux et les personnes)

| Italien | Français |
|---|---|
| la scuola | l'école |
| l'aula | la salle de classe |
| il cortile | la cour |
| la biblioteca | la bibliothèque |
| la palestra | le gymnase |
| l'insegnante / il professore, la professoressa | le professeur |
| l'alunno, l'alunna | l'élève |
| il compagno, la compagna | le, la camarade |
| il preside | le principal, le proviseur |

Exemple : *La professoressa è in aula.* → La professeure est dans la salle de classe.

## 2. Il materiale scolastico (le matériel)

| Italien | Français |
|---|---|
| lo zaino | le cartable, le sac à dos |
| l'astuccio | la trousse |
| la penna | le stylo |
| la matita | le crayon |
| la gomma | la gomme |
| il quaderno | le cahier |
| il libro | le livre |
| il diario | le cahier de textes |
| la lavagna | le tableau |

Exemple : *Nello zaino ho due quaderni e un libro.* → Dans mon sac, j'ai deux cahiers et un livre.

## 3. Le materie e la giornata (les matières et la journée)

| Italien | Français |
|---|---|
| la matematica | les mathématiques |
| l'italiano | l'italien |
| la storia | l'histoire |
| le scienze | les sciences |
| l'educazione fisica | l'EPS, le sport |
| la lezione | le cours, la leçon |
| l'intervallo / la ricreazione | la récréation |
| i compiti | les devoirs |
| il voto | la note |

Exemple : *Oggi ho matematica e storia.* → Aujourd'hui j'ai maths et histoire.

## 4. Les erreurs à éviter

- *la matita* = le crayon (bois), à ne pas confondre avec *la penna* = le stylo.
- *la gomma* signifie « la gomme » mais aussi « le pneu » : le contexte de l'école lève le doute.
- *i compiti* (les devoirs) est un pluriel : on dit *fare i compiti* (faire ses devoirs).
- « le professeur » se dit *il professore* (masc.) ou *la professoressa* (fém.) ; *l'insegnante* est valable pour les deux.
- Attention à l'orthographe : *la ma**tt**ina* (le matin, deux t), *l'inse**gn**ante* (gn), *l'a**u**la* et *lo za**i**no* (voyelles à bien écrire).

## À retenir

- Les lieux : *la scuola*, *l'aula*, *il cortile*, *la biblioteca*, *la palestra*.
- Les personnes : *il professore / la professoressa*, *l'alunno*, *il compagno*.
- Le matériel : *lo zaino*, *l'astuccio*, *la penna*, *la matita*, *il quaderno*.
- Les matières : *la matematica*, *l'italiano*, *la storia*, *le scienze*.
- *i compiti* = les devoirs (pluriel) ; *fare i compiti* = faire ses devoirs.
