# Les classes grammaticales (nature des mots)

> Chaque mot appartient à une famille : c'est sa **classe grammaticale** (ou nature).
> Un mot garde toujours la même nature, quelle que soit sa place dans la phrase.
> Bien connaître les classes, c'est pouvoir accorder, conjuguer et analyser sans se tromper.

## 1. Les mots variables et les mots invariables

Certains mots **changent de forme** (genre, nombre, personne) : ce sont les mots **variables**.
D'autres ne changent **jamais** : ce sont les mots **invariables**.

| Type | Classes | Exemple |
|---|---|---|
| Variables | nom, déterminant, adjectif, pronom, verbe | *un chat* → *des chats* |
| Invariables | adverbe, préposition, conjonction, interjection | *vite* reste *vite* |

## 2. Les principales classes variables

| Classe | Rôle | Exemples |
|---|---|---|
| Nom | désigne une personne, une chose, une idée | *chien, Paris, courage* |
| Déterminant | se place devant le nom, l'annonce | *le, une, mon, ce, trois* |
| Adjectif qualificatif | précise, décrit le nom | *grand, rouge, gentil* |
| Pronom | remplace un nom ou un groupe nominal | *il, elle, celui-ci, le mien* |
| Verbe | exprime une action ou un état | *courir, être, penser* |

Exemple analysé : dans *« Le petit chien aboie »*, **le** est un déterminant, **petit** un adjectif, **chien** un nom, **aboie** un verbe.

## 3. Les principales classes invariables

| Classe | Rôle | Exemples |
|---|---|---|
| Adverbe | modifie un verbe, un adjectif ou un autre adverbe | *bien, souvent, très, ne… pas* |
| Préposition | introduit un complément | *à, de, dans, pour, avec, sans* |
| Conjonction | relie des mots ou des propositions | *mais, ou, et, donc, car, que, quand* |
| Interjection | exprime une émotion | *Oh !, Aïe !, Hélas !* |

## 4. Une même forme, plusieurs classes

Un mot peut appartenir à des classes différentes selon la phrase. Il faut regarder son **emploi**.

| Mot | Phrase | Classe |
|---|---|---|
| le | **Le** train part. | déterminant |
| le | Je **le** regarde. | pronom |
| rouge | un pull **rouge** | adjectif |
| rouge | Le **rouge** te va bien. | nom |

## 5. Les erreurs à éviter

- Ne confonds pas **nature** et **fonction** : la nature, c'est la classe du mot (nom, verbe…) ; la fonction, c'est son rôle dans la phrase (sujet, COD…).
- **Déterminant ≠ adjectif** : *mon, ce, trois* sont des déterminants, pas des adjectifs qualificatifs.
- Le mot *que* n'est pas toujours un pronom : ce peut être une conjonction (*Je crois que tu as raison*).
- *Très* est un adverbe, jamais un adjectif : on ne l'accorde pas.
- La négation *ne… pas* est faite de deux adverbes ; ils encadrent le verbe.

## À retenir

- La **classe grammaticale** (ou nature) est la famille à laquelle un mot appartient.
- Mots **variables** : nom, déterminant, adjectif, pronom, verbe. Mots **invariables** : adverbe, préposition, conjonction, interjection.
- Un même mot peut changer de classe selon son emploi dans la phrase.
- La **nature** est fixe ; la **fonction** dépend de la phrase.
