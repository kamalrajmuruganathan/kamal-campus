# Le passé composé et l'accord du participe

> Le passé composé est le temps du passé le plus utilisé à l'oral et dans les textes du quotidien.
> Il se forme avec deux morceaux : un **auxiliaire** et un **participe passé**.
> Tout l'enjeu, c'est de choisir le bon auxiliaire et d'accorder correctement le participe.

## 1. Comment se forme le passé composé

Passé composé = **auxiliaire (être ou avoir) au présent** + **participe passé** du verbe.

| Sujet | Auxiliaire | Participe passé | Phrase |
|---|---|---|---|
| J' | ai | mangé | J'**ai mangé** une pomme. |
| Elle | est | partie | Elle **est partie**. |
| Nous | avons | fini | Nous **avons fini**. |

## 2. Le participe passé selon le groupe

| Groupe | Terminaison du participe | Exemple |
|---|---|---|
| 1er (-er) | -é | chanter → chant**é** |
| 2e (-ir) | -i | finir → fin**i** |
| 3e (variable) | -i, -u, -is, -t… | partir → part**i**, voir → v**u**, prendre → pr**is**, faire → fai**t** |

## 3. Quel auxiliaire choisir ?

**La plupart des verbes** se conjuguent avec **avoir**.
On utilise **être** avec :
- les verbes de déplacement/état : *aller, venir, arriver, partir, entrer, sortir, monter, descendre, tomber, rester, devenir, naître, mourir…*
- **tous les verbes pronominaux** : *se laver → il s'est lavé*.

## 4. L'accord du participe passé (la règle clé)

| Auxiliaire | Règle | Exemple |
|---|---|---|
| **être** | le participe s'accorde avec le **sujet** (genre et nombre) | Elle est part**ie**. Ils sont part**is**. |
| **avoir** | le participe **ne s'accorde pas** avec le sujet | Elles ont mang**é**. (pas de -es) |

Comparaison directe :

| Phrase | Auxiliaire | Accord |
|---|---|---|
| Les filles **sont arrivées**. | être | accord avec le sujet (fém. plur.) → -es |
| Les filles **ont mangé**. | avoir | aucun accord avec le sujet → -é |

## 5. Les erreurs à éviter

- Ne pas accorder le participe avec **avoir** quand le sujet est féminin ou pluriel : *elles ont chanté*, pas *elles ont chantées*.
- Bien accorder avec **être** : *elle est venue*, *ils sont venus*.
- Ne pas confondre le participe passé en **-é** et l'infinitif en **-er** : *j'ai mangé* (participe) / *je vais manger* (infinitif). Astuce : remplace par *vendu/vendre* (*j'ai vendu* → -é ; *je veux vendre* → -er).
- Verbes pronominaux : auxiliaire **être** (*elle s'est levée*).
- Ne pas oublier l'auxiliaire : on dit *j'ai fini*, jamais *j'fini*.

## À retenir

- Passé composé = **auxiliaire (être/avoir) au présent + participe passé**.
- Participe passé : 1er groupe **-é**, 2e groupe **-i**, 3e groupe variable.
- Avec **être** → le participe s'accorde avec le **sujet**.
- Avec **avoir** → **pas d'accord** avec le sujet.
- Piège -é / -er : teste avec *vendu / vendre*.
