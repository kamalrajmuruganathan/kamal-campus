# Imparfait et passé simple dans le récit

> Dans un conte ou un roman, deux temps du passé travaillent ensemble : l'**imparfait**
> plante le décor et dit ce qui dure, le **passé simple** raconte les actions qui surviennent.
> Savoir les alterner, c'est écrire un vrai récit.

## 1. L'imparfait : le temps de l'arrière-plan

L'imparfait décrit le **décor**, les **habitudes**, ce qui **dure** dans le passé. Ses terminaisons sont **les mêmes pour tous les verbes**.

| Personne | Terminaison | Exemple (regarder) |
|---|---|---|
| je | -ais | je regard**ais** |
| tu | -ais | tu regard**ais** |
| il/elle/on | -ait | il regard**ait** |
| nous | -ions | nous regard**ions** |
| vous | -iez | vous regard**iez** |
| ils/elles | -aient | ils regard**aient** |

Astuce : le radical de l'imparfait se trouve avec « nous » au présent (*nous finiss-ons* → *je finiss-ais*).

## 2. Le passé simple : le temps des actions

Le passé simple raconte les **actions principales**, brèves, qui font **avancer l'histoire**. On le rencontre surtout à la 3e personne dans les récits.

| Groupe | il/elle | ils/elles | Exemple |
|---|---|---|---|
| 1er (-er) | -a | -èrent | il chant**a**, ils chant**èrent** |
| 2e (-ir) | -it | -irent | il fin**it**, ils fin**irent** |
| 3e (souvent) | -it / -ut | -irent / -urent | il part**it**, il v**int**, il f**ut** |

Verbes fréquents : *il fut* (être), *il eut* (avoir), *il fit* (faire), *il vint* (venir), *il prit* (prendre).

## 3. Comment ils se répartissent le travail

| Imparfait (décor, durée) | Passé simple (action soudaine) |
|---|---|
| Il **faisait** nuit, la forêt **était** silencieuse… | …quand soudain un loup **surgit**. |
| La princesse **dormait** paisiblement… | …lorsque le prince **arriva**. |

L'imparfait pose la scène ; le passé simple déclenche l'événement. On le voit dans les contes de **Charles Perrault** ou les fables de **Jean de La Fontaine**.

## 4. Repérer le bon temps

- Mots qui appellent souvent l'**imparfait** : *souvent, tous les jours, autrefois, pendant que, tandis que*.
- Mots qui appellent souvent le **passé simple** : *soudain, tout à coup, alors, ce jour-là, puis*.

## 5. Les erreurs à éviter

- Imparfait : ne pas oublier le **i** aux personnes « nous » et « vous » (*nous criions*, *vous étudiiez*).
- Ne confonds pas *il chantait* (imparfait, action qui dure) et *il chanta* (passé simple, action brève).
- Passé simple, 1er groupe : *il chanta* (avec -a), jamais *il chantit*.
- « je » de l'imparfait finit toujours par **-ais** (avec un s), même s'il ne s'entend pas.
- Ne pas mélanger passé simple et passé composé dans un même récit littéraire.

## À retenir

- L'**imparfait** décrit le décor, les habitudes, ce qui dure ; terminaisons -ais, -ais, -ait, -ions, -iez, -aient.
- Le **passé simple** raconte les actions soudaines qui font avancer l'histoire (surtout la 3e personne).
- Dans un récit, l'imparfait pose la scène, le **passé simple** déclenche l'action.
- Des mots repères aident à choisir : *pendant que* (imparfait) / *soudain* (passé simple).
