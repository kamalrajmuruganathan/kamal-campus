# Le fonctionnement d'un objet technique

On sait à quoi sert un objet (sa **fonction d'usage**). Mais **comment
fonctionne-t-il** ? Pour le comprendre, on regarde ses **fonctions techniques**,
les **solutions** choisies pour les réaliser, et comment l'**énergie** et
l'**information** circulent dans l'objet.

## Fonction technique et solution technique

Pour rendre son service, un objet doit accomplir plusieurs **fonctions
techniques**. Une **fonction technique** est une **tâche que l'objet doit
réaliser** pour fonctionner.

Chaque fonction technique est assurée par une **solution technique** : la
**pièce** ou le **mécanisme** choisi pour réaliser cette tâche.

Exemple avec un **vélo** :

- Fonction technique « **freiner** » → solution technique : les **freins**.
- Fonction technique « **faire avancer** » → solution technique : le
  **pédalier** et la **chaîne**.
- Fonction technique « **diriger** » → solution technique : le **guidon**.

> Retiens : la fonction technique dit **ce qu'il faut faire** ; la solution
> technique dit **avec quoi on le fait**.

## L'objet a besoin d'énergie

Un objet technique a souvent besoin d'**énergie** pour fonctionner. L'énergie
peut venir :

- de l'**électricité** (secteur ou pile/batterie) : lampe, téléphone ;
- des **muscles** de l'être humain : un vélo, une trottinette classique ;
- d'un **carburant** (essence) : une voiture thermique ;
- du **vent**, de l'**eau** ou du **Soleil** : une éolienne, un panneau solaire.

## La chaîne d'énergie

Dans l'objet, l'énergie suit un chemin appelé **chaîne d'énergie**. Elle est
d'abord **reçue** (par une source ou une prise), parfois **stockée** (une pile),
puis **transformée** pour produire une **action** (tourner, chauffer, éclairer,
avancer).

Exemple, une **lampe de poche** : la **pile** fournit l'électricité →
l'**interrupteur** laisse passer le courant → l'**ampoule** transforme
l'électricité en **lumière**. L'action utile est **éclairer**.

## La chaîne d'information

Beaucoup d'objets doivent aussi **traiter des informations** : c'est la **chaîne
d'information**. Elle **acquiert** une information (un **capteur** ou un
bouton), la **traite** (une partie qui décide), puis **commande** une action.

Exemple, une **lampe à détecteur** : un **capteur** détecte quelqu'un qui passe
→ l'objet **traite** cette information → il **commande** l'allumage de la lampe.

- Un **capteur** sert à **détecter ou mesurer** (mouvement, lumière,
  température).
- Un **actionneur** est la partie qui **agit** (le moteur qui tourne, la lampe
  qui s'allume, le buzzer qui sonne).

## Ce qu'il faut retenir

- Une **fonction technique** est une tâche que l'objet doit réaliser ; la
  **solution technique** est la pièce ou le mécanisme qui la réalise.
- Un objet a souvent besoin d'**énergie** (électricité, muscles, carburant,
  vent, Soleil…).
- La **chaîne d'énergie** : l'énergie est **reçue**, parfois **stockée**, puis
  **transformée** en action (éclairer, avancer, chauffer).
- La **chaîne d'information** : une information est **acquise** (capteur),
  **traitée**, puis **commande** une action.
- Un **capteur** détecte/mesure ; un **actionneur** agit.

## Les erreurs à éviter

- **Confondre fonction technique et solution technique.** La fonction = la
  tâche (« freiner ») ; la solution = la pièce (« les freins »).
- **Confondre fonction d'usage et fonction technique.** L'usage = le service
  global ; la fonction technique = une tâche interne nécessaire au fonctionnement.
- **Oublier que l'énergie est transformée, pas créée.** L'ampoule transforme
  l'électricité en lumière.
- **Confondre capteur et actionneur.** Le capteur détecte l'information ;
  l'actionneur exécute l'action.
