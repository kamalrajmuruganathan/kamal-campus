# Vocabulaire : la sociedad y el mundo

> Immigration, inégalités, environnement, mondialisation : les grands débats de société
> exigent un lexique riche et précis. Cette fiche réunit le vocabulaire de l'actualité
> et des enjeux du monde contemporain, pour lire la presse et argumenter en espagnol.

## 1. La sociedad (la société)

| Espagnol | Français |
|---|---|
| la desigualdad | l'inégalité |
| la pobreza / la riqueza | la pauvreté / la richesse |
| los derechos humanos | les droits humains |
| la ciudadanía | la citoyenneté |
| la igualdad | l'égalité |
| la manifestación | la manifestation |
| la huelga | la grève |
| la libertad de expresión | la liberté d'expression |

Exemple : *La desigualdad entre ricos y pobres aumenta.* → L'inégalité entre riches et pauvres augmente.

## 2. La inmigración y la convivencia

| Espagnol | Français |
|---|---|
| el/la inmigrante | l'immigré(e) |
| el/la refugiado/a | le/la réfugié(e) |
| la frontera | la frontière |
| la integración | l'intégration |
| el mestizaje | le métissage |
| la convivencia | le vivre-ensemble |
| el racismo | le racisme |
| acoger | accueillir |

Exemple : *Muchos refugiados cruzan la frontera.* → Beaucoup de réfugiés traversent la frontière.
Attention : **la convivencia** = le fait de vivre ensemble (pas de traduction directe en français).

## 3. El mundo : medio ambiente y globalización

| Espagnol | Français |
|---|---|
| el medio ambiente | l'environnement |
| el calentamiento global | le réchauffement climatique |
| el desarrollo sostenible | le développement durable |
| la contaminación | la pollution |
| el reciclaje | le recyclage |
| la globalización / la mundialización | la mondialisation |
| la crisis | la crise |
| el paro juvenil | le chômage des jeunes |

Exemple : *El calentamiento global amenaza el planeta.* → Le réchauffement climatique menace la planète.

## 4. Les erreurs à éviter

- **el medio ambiente** s'écrit en deux mots ; « environnement » ne se dit pas *environamiento*.
- Faux-ami : **la contaminación** = la pollution (et non « la contamination » seulement).
- **la manifestación** = la manifestation (rassemblement), à ne pas confondre avec *demostración* (démonstration).
- **la huelga** est féminin : *una huelga general*.

## À retenir

- Société : *la desigualdad, la pobreza, los derechos humanos, la huelga, la manifestación*.
- Immigration : *el inmigrante, el refugiado, la frontera, la integración, la convivencia*.
- Monde : *el medio ambiente, el calentamiento global, la contaminación, la globalización*.
- Faux-amis : *la contaminación* (pollution), *la manifestación* (manifestation).
