# Vocabulaire : société et monde

> Migrations, inégalités, environnement, droits humains : ce lexique de niveau B2 te permet d'analyser les grands enjeux de société et de construire une argumentation nuancée sur le monde contemporain en italien.

## 1. Le grandi sfide (les grands défis)

| Italien | Français | Remarque |
|---|---|---|
| la sfida | le défi | *affrontare una sfida* = relever un défi |
| la migrazione | la migration | *l'emigrazione / l'immigrazione* |
| il profugo / il rifugiato | le réfugié | |
| la disuguaglianza | l'inégalité | *le disuguaglianze sociali* |
| la povertà | la pauvreté | *combattere la povertà* |
| l'integrazione (f.) | l'intégration | |
| la convivenza | la coexistence, le vivre-ensemble | |

**Exemples :**
- *L'integrazione dei migranti è una sfida per l'Europa.* → L'intégration des migrants est un défi pour l'Europe.
- *Le disuguaglianze sono aumentate negli ultimi anni.* → Les inégalités ont augmenté ces dernières années.

## 2. Ambiente e diritti (environnement et droits)

| Italien | Français |
|---|---|
| l'ambiente (m.) | l'environnement |
| lo sviluppo sostenibile | le développement durable |
| il cambiamento climatico | le changement climatique |
| l'inquinamento (m.) | la pollution |
| i diritti umani | les droits de l'homme |
| la parità | l'égalité, la parité |
| la tolleranza | la tolérance |
| il pregiudizio | le préjugé |

**Exemples :**
- *Dobbiamo lottare contro il cambiamento climatico.* → Nous devons lutter contre le changement climatique.
- *I pregiudizi ostacolano l'integrazione.* → Les préjugés entravent l'intégration.

## 3. Les erreurs à éviter

- **il profugo** et **il rifugiato** sont proches ; *rifugiato* insiste sur le statut juridique.
- **la parità** = l'égalité/la parité (ex. *parità di genere*), à distinguer de *l'uguaglianza* (plus général).
- **l'inquinamento** = la pollution : soigne le mot, très fréquent au bac.
- **sostenibile** = durable (développement) : ne pas traduire par *« soutenable »* au sens courant.

## À retenir

- Un défi = **una sfida** ; l'affronter = **affrontare una sfida**.
- Migrations : **la migrazione**, **il rifugiato**, **l'integrazione**.
- Environnement : **lo sviluppo sostenibile**, **il cambiamento climatico**, **l'inquinamento**.
- Enjeux de société : **la disuguaglianza**, **i diritti umani**, **il pregiudizio**.
