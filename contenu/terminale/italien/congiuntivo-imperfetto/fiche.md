# Le subjonctif imparfait et l'hypothèse

> Le *congiuntivo imperfetto* est le pilier de l'hypothèse irréelle : « Se avessi tempo, verrei ». C'est un temps incontournable pour exprimer le souhait, le regret et l'irréel du présent.

## 1. La formation régulière
On part du radical de l'infinitif + les terminaisons :

| Personne | -ARE (parlare) | -ERE (leggere) | -IRE (dormire) |
|---|---|---|---|
| io | parl**assi** | legg**essi** | dorm**issi** |
| tu | parl**assi** | legg**essi** | dorm**issi** |
| lui/lei | parl**asse** | legg**esse** | dorm**isse** |
| noi | parl**assimo** | legg**essimo** | dorm**issimo** |
| voi | parl**aste** | legg**este** | dorm**iste** |
| loro | parl**assero** | legg**essero** | dorm**issero** |

## 2. Les verbes irréguliers principaux

| Verbe | Formes (io, tu, lui, noi, voi, loro) |
|---|---|
| essere | fossi, fossi, **fosse**, fossimo, foste, fossero |
| dare | dessi, dessi, desse, dessimo, deste, dessero |
| stare | stessi, stessi, stesse, stessimo, steste, stessero |
| fare | fac**essi**, facesse, facessimo... (radical *face-*) |
| dire | dic**essi**... (radical *dice-*) |
| bere | bev**essi**... (radical *beve-*) |

## 3. L'hypothèse irréelle du présent
C'est l'emploi central. Structure :

| Subordonnée (se) | Principale | Exemple |
|---|---|---|
| congiuntivo imperfetto | condizionale presente | **Se avessi** tempo, **verrei**. |

- Se **fossi** ricco, **comprerei** una casa. → Si j'étais riche, j'achèterais une maison.
- Se **potessi**, ti **aiuterei**. → Si je pouvais, je t'aiderais.

## 4. Autres emplois
- Après une principale au passé (concordance) : Pensavo che **fosse** vero.
- Le souhait avec *magari* : **Magari piovesse!** → Si seulement il pleuvait !
- « Se fossi in te... » → Si j'étais toi / à ta place...

## 5. Les erreurs à éviter
- Ne jamais mettre le conditionnel dans la subordonnée en *se* : ✗ *Se avrei tempo* → ✓ **Se avessi tempo**.
- Ne pas confondre avec l'imparfait de l'indicatif (parlavo ≠ parlassi).
- Attention aux radicaux irréguliers : fare → facessi, dire → dicessi, bere → bevessi.

## À retenir
- Terminaisons : -assi (-are), -essi (-ere), -issi (-ire).
- Hypothèse irréelle : **se + congiuntivo imperfetto → condizionale presente**.
- Jamais de conditionnel après *se*.
- *Magari + congiuntivo imperfetto* = souhait.
