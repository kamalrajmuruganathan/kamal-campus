# Vocabulaire : économie et mondialisation

> Marché, entreprises, échanges, croissance et crise : ce lexique de niveau B2 te donne les mots pour analyser l'économie et la mondialisation, et pour argumenter sur leurs conséquences en italien.

## 1. L'economia (l'économie)

| Italien | Français | Remarque |
|---|---|---|
| il mercato | le marché | *il mercato del lavoro* |
| l'impresa (f.) / l'azienda | l'entreprise | |
| la crescita | la croissance | *la crescita economica* |
| la crisi | la crise | invariable au pluriel : *le crisi* |
| lo sviluppo | le développement | |
| il consumo / i consumi | la consommation | |
| il debito | la dette | *il debito pubblico* |
| la ricchezza | la richesse | ≠ *la povertà* |

**Exemples :**
- *La crescita economica è rallentata.* → La croissance économique a ralenti.
- *Il debito pubblico è molto elevato.* → La dette publique est très élevée.

## 2. La globalizzazione (la mondialisation)

| Italien | Français |
|---|---|
| la globalizzazione | la mondialisation |
| lo scambio / gli scambi | l'échange / les échanges |
| il commercio | le commerce |
| la concorrenza | la concurrence |
| la delocalizzazione | la délocalisation |
| il mercato mondiale | le marché mondial |
| la multinazionale | la multinationale |
| lo sfruttamento | l'exploitation |

**Exemples :**
- *La globalizzazione favorisce gli scambi commerciali.* → La mondialisation favorise les échanges commerciaux.
- *Molte aziende ricorrono alla delocalizzazione.* → Beaucoup d'entreprises recourent à la délocalisation.

## 3. Les erreurs à éviter

- **la concorrenza** = la concurrence (faux ami : ce n'est pas un « concours »).
- **l'impresa** = l'entreprise ; c'est aussi « l'exploit » selon le contexte.
- **la crisi** est invariable : *una crisi, molte crisi*.
- **lo sfruttamento** = l'exploitation (des travailleurs, des ressources) : mot clé du sujet.

## À retenir

- Le marché = **il mercato** ; l'entreprise = **l'impresa / l'azienda**.
- Croissance = **la crescita**, crise = **la crisi** (invariable), dette = **il debito**.
- Mondialisation : **la globalizzazione**, **gli scambi**, **la concorrenza**, **la delocalizzazione**.
- L'exploitation = **lo sfruttamento**.
