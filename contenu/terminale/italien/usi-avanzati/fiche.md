# Emplois avancés : essere, stare, andare

> Trois verbes essentiels dépassent largement leur sens premier : *essere* (auxiliaire, passif), *stare* (action en cours, imminence) et *andare* (mouvement, passif d'obligation). Les maîtriser distingue l'italien de niveau B2.

## 1. ESSERE : auxiliaire, existence, passif
- **Auxiliaire** des verbes de mouvement et pronominaux : Lei **è** andata a casa.
- **Passif** de base : La lettera **è** scritta da Marco. Il ponte **fu** costruito nel 1900.
- **Localisation / existence** : Dove **è** il libro?

## 2. STARE : action en cours et imminence

| Structure | Sens | Exemple |
|---|---|---|
| stare + gerundio | action en cours | **Sto** studiando. (je suis en train d'étudier) |
| stare per + infinitif | action imminente | Il treno **sta per** partire. |
| stare (santé, lieu) | aller, se trouver | Come **stai**? — **Sto** bene. |
| imperatif : sta' / stai | reste | **Sta' fermo!** |

## 3. ANDARE : mouvement, passif d'obligation, progression

| Structure | Sens | Exemple |
|---|---|---|
| andare (mouvement) | aller | **Vado** a scuola. |
| andare + participe passé | doit être + participe (passif d'obligation) | Questo **va** fatto subito. |
| andare + gerundio | progression graduelle | La situazione **va** migliorando. |
| andarsene | s'en aller | Me ne **vado**. |

> **andare + participe passé** = obligation : *Il modulo va compilato* = le formulaire doit être rempli. Le participe s'accorde : Le regole **vanno** rispettate.

## 4. Comparaison des trois passifs
- essere + participe → passif neutre : è fatto (c'est fait).
- venire + participe → passif d'action : viene fatto (c'est fait / on le fait).
- andare + participe → passif d'obligation : va fatto (doit être fait).

## 5. Les erreurs à éviter
- Ne pas confondre *stare + gerundio* (en cours) et le présent simple (habitude).
- Ne pas oublier l'accord du participe après *andare* passif : Le regole **vanno** rispettate.
- *stare per* + infinitif (jamais + gerundio) pour l'imminence.

## À retenir
- *essere* = auxiliaire + passif neutre + existence.
- *stare + gerundio* = action en cours ; *stare per* + infinitif = imminence.
- *andare + participe passé* = obligation (doit être fait), avec accord.
- *andare + gerundio* = progression graduelle.
