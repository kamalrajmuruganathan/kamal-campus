# Wortschatz: Wirtschaft und Globalisierung

> Entreprise, marché, commerce mondial, développement durable : ce chapitre
> rassemble le vocabulaire allemand de l'économie et de la mondialisation pour
> analyser et argumenter au niveau B2.

## 1. L'économie (die Wirtschaft)

| Allemand | Traduction |
|---|---|
| **die Wirtschaft** | l'économie |
| **das Unternehmen** | l'entreprise |
| **der Markt** | le marché |
| **der Gewinn** | le bénéfice / le profit |
| **die Arbeitslosigkeit** | le chômage |
| **das Wachstum** | la croissance |
| **der Verbraucher** | le consommateur |
| **die Nachfrage** | la demande |

## 2. La mondialisation (die Globalisierung)

| Allemand | Traduction |
|---|---|
| **die Globalisierung** | la mondialisation |
| **der Welthandel** | le commerce mondial |
| **die Ausfuhr / der Export** | l'exportation |
| **die Einfuhr / der Import** | l'importation |
| **der Wettbewerb** | la concurrence |
| **die Lieferkette** | la chaîne d'approvisionnement |
| **die Auslagerung** | la délocalisation |
| **der Konzern** | le groupe / la multinationale |

## 3. Enjeux et développement durable (Herausforderungen)

| Allemand | Traduction |
|---|---|
| **die Entwicklung** | le développement |
| **die Nachhaltigkeit** | la durabilité |
| **die Ungleichheit** | l'inégalité |
| **der Fortschritt** | le progrès |
| **investieren** | investir |
| **herstellen** | produire / fabriquer |
| **verringern** | réduire / diminuer |
| **fördern** | encourager / favoriser |

*Débat : « Die Globalisierung **fördert** das Wachstum, aber sie **verstärkt** die
Ungleichheit. » (La mondialisation favorise la croissance mais renforce l'inégalité.)*

## 4. Les erreurs à éviter

- Ne confonds pas **fördern** (encourager, favoriser) et **fordern** (exiger).
- **der Gewinn** = le bénéfice ; ne le traduis pas par « gain » au hasard selon le contexte.
- **herstellen** (fabriquer) est à particule séparable : *Die Firma stellt Autos **her**.*
- Genre à mémoriser : **die** Wirtschaft, **das** Unternehmen, **der** Markt, **der** Konzern.

## À retenir

- Économie : die Wirtschaft, das Unternehmen, der Markt, der Gewinn, die Arbeitslosigkeit.
- Mondialisation : die Globalisierung, der Welthandel, der Export, der Import, der Wettbewerb.
- Enjeux : die Nachhaltigkeit, die Ungleichheit, der Fortschritt, das Wachstum.
- Verbes clés : investieren, herstellen, verringern, fördern (≠ fordern).
