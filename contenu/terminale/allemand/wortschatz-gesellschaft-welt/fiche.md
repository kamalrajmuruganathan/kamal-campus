# Wortschatz: Gesellschaft und Welt

> Environnement, démocratie, migrations, droits humains : le vocabulaire allemand
> des grands débats de société, indispensable pour argumenter au niveau B2.

## 1. Société et politique (Gesellschaft und Politik)

| Allemand | Traduction |
|---|---|
| **die Gesellschaft** | la société |
| **die Demokratie** | la démocratie |
| **die Regierung** | le gouvernement |
| **die Wahl / wählen** | l'élection / voter |
| **die Menschenrechte** | les droits humains |
| **die Gleichberechtigung** | l'égalité des droits |
| **die Meinung** | l'opinion |
| **die Freiheit** | la liberté |

## 2. Environnement et avenir (Umwelt und Zukunft)

| Allemand | Traduction |
|---|---|
| **die Umwelt** | l'environnement |
| **der Klimawandel** | le changement climatique |
| **der Umweltschutz** | la protection de l'environnement |
| **die Nachhaltigkeit** | la durabilité |
| **die Verantwortung** | la responsabilité |
| **der Fortschritt** | le progrès |
| **die Entwicklung** | le développement / l'évolution |

## 3. Vivre ensemble (Zusammenleben)

| Allemand | Traduction |
|---|---|
| **die Migration** | la migration |
| **die Integration** | l'intégration |
| **die Flüchtlinge** (pl.) | les réfugiés |
| **die Toleranz / die Vielfalt** | la tolérance / la diversité |
| **die Gerechtigkeit** | la justice |
| **die Diskriminierung** | la discrimination |
| **das Vorurteil** | le préjugé |
| **sich engagieren** | s'engager |

Exemple : *Viele Jugendliche engagieren sich für den Umweltschutz.* (Beaucoup de
jeunes s'engagent pour la protection de l'environnement.)

## 4. Les erreurs à éviter

- **die Politik** = la politique (le domaine) ; **der Politiker** = l'homme politique.
- **wählen** signifie à la fois « voter » et « choisir » selon le contexte.
- **die Menschenrechte** et **die Flüchtlinge** s'emploient surtout au pluriel.
- **die Entwicklung** couvre « développement » ET « évolution » : attention au contexte.

## À retenir

- Politique : die Demokratie, die Regierung, die Wahl, die Menschenrechte, die Freiheit.
- Environnement : die Umwelt, der Klimawandel, die Nachhaltigkeit, der Umweltschutz.
- Vivre ensemble : die Migration, die Integration, die Toleranz, die Gerechtigkeit.
- Verbe utile pour argumenter : **sich engagieren für** (s'engager pour).
