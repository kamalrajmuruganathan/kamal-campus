# L'irréel et les hypothèses (conditionnels mixtes)

> Dire ce qui n'est pas, ce qui aurait pu être, ce qu'on regrette : l'anglais code l'irréel par un **décalage temporel**. Un prétérit pour l'irréel du présent, un past perfect pour l'irréel du passé. Ce « recul » du temps est la clé de tout le chapitre.

## 1. Les trois conditionnels de base

| Type | Sens | If-clause | Principale | Exemple |
|---|---|---|---|---|
| 0 | vérité générale | présent | présent | If you **heat** ice, it **melts**. |
| 1 | possible (futur réel) | présent | will + BV | If it **rains**, I**'ll stay** in. |
| 2 | irréel du présent | prétérit | would + BV | If I **had** more time, I**'d travel**. |
| 3 | irréel du passé | past perfect | would have + PP | If I **had known**, I**'d have come**. |

Règle d'or : **jamais** *will* ni *would* dans la proposition en *if*.

## 2. L'irréel du présent (type 2)

On imagine une situation contraire à la réalité actuelle. Le prétérit y a une valeur **modale**, pas temporelle.

| Réalité | Hypothèse |
|---|---|
| I don't have a car. | If I **had** a car, I **would drive** you. |
| He isn't here. | If he **were** here, he **would help**. |

Au type 2, *be* devient **were** à toutes les personnes en anglais soigné : *If I **were** you, I would apologize.*

## 3. L'irréel du passé (type 3)

On imagine un passé différent → regret ou reproche. *If they **had left** earlier, they **wouldn't have missed** the flight.* (mais ils sont partis tard, donc ils l'ont raté)

## 4. Les conditionnels mixtes

On croise les deux axes quand la condition et la conséquence n'appartiennent pas au même moment.

| Type mixte | Condition | Conséquence | Exemple |
|---|---|---|---|
| passé → présent | past perfect | would + BV | If I **had studied** medicine, I **would be** a doctor now. |
| présent → passé | prétérit | would have + PP | If I **weren't** so shy, I **would have spoken** to her. |

## 5. Autres formulations de l'irréel

- **wish / if only + prétérit** : regret sur le présent. *I **wish** I **knew** the answer.* (mais je ne la connais pas)
- **wish / if only + past perfect** : regret sur le passé. *I **wish** I **had studied** harder.*
- **wish + would** : agacement, souhait de changement chez autrui. *I **wish** you **would stop** shouting.*
- **would rather + prétérit** : préférence. *I**'d rather** you **didn't** smoke.*
- **It's (high) time + prétérit** : *It's time we **left**.*

## 6. Les erreurs à éviter

- Mettre *would* dans la proposition en *if* : *If I **would have** time* → *If I **had** time*.
- Traduire « si j'avais su » par un prétérit simple : c'est *If I **had known*** (past perfect).
- Oublier le décalage après *wish* : *I wish I **have*** → *I wish I **had***.
- Employer un futur après *wish* : *I wish it **will*** → *I wish it **would***.

## À retenir

- L'irréel se code par un recul du temps : prétérit (présent) / past perfect (passé).
- Type 2 = irréel du présent ; type 3 = irréel du passé ; mixtes = les deux croisés.
- Jamais *will* ni *would* dans la proposition en *if*.
- *were* à toutes les personnes au type 2 en anglais soutenu.
- *wish/if only + prétérit* (présent), *+ past perfect* (passé), *+ would* (agacement).
