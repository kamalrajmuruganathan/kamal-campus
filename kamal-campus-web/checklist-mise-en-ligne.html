Checklist de mise en ligne

L'ordre exact pour publier la vitrine et la version web de l'appli sur GitHub Pages. Coche au fur et à mesure — ta progression est gardée sur cet appareil.

Progression 0 / 0
✓ Tout est en ligne — bravo !
Phase A

Mettre la vitrine en ligne

Rapide (~5 min) et faisable tout de suite, même avant la version web de l'appli.

  • Créer un dépôt GitHub publicEx. nommé kamal-campus (ou réutiliser le dépôt de l'appli).
  • Déposer les 3 pages dans web-vitrine/index.html, politique-confidentialite.html, parite-web-mobile.html.
  • Activer GitHub PagesSettings → Pages → Source = Deploy from a branch (ou GitHub Actions si tu utilises le workflow).
  • Vérifier l'URL publiquehttps://TONCOMPTE.github.io/kamal-campus/ s'affiche bien.
Phase B

Construire la version web de l'appli

Dans ton Codespace. Tout le code nécessaire est dans le kit web.

  • Ajouter VisionneuseFiche.web.jsÀ placer juste à côté de VisionneuseFiche.js.
  • Générer le template web + coller le CSS KaTeXnpx expo customize web/index.html, puis coller le snippet dans <head>.
  • Masquer le scan QR sur le webGarde Platform.OS !== 'web' autour du bouton de scan (message « Disponible sur l'appli mobile »).
  • Régler le baseUrl dans app.json"experiments": { "baseUrl": "/kamal-campus/app" } — indispensable pour un sous-dossier.
  • Installer les dépendances webnpx expo install react-dom react-native-web @expo/metro-runtime
  • Tester en localnpx expo start --web — vérifie une fiche (formules), un jeu, un outil.
  • Exporter la version webnpx expo export --platform web → produit dist/.
Phase C

Déploiement automatique

Pour que tout se republie tout seul à chaque git push.

  • Copier le workflow.github/workflows/deploy-pages.yml dans le dépôt.
  • Adapter la branche et le dossierDans le YAML : branches = ta branche, working-directory = dossier de l'appli.
  • Pages → Source = GitHub ActionsSettings → Pages → Build and deployment → Source.
  • git push et vérifier l'onglet ActionsLe job « build » puis « deploy » doivent passer au vert.
  • Tester l'appli en lignehttps://TONCOMPTE.github.io/kamal-campus/app/ — le bouton « Lancer l'appli » de la vitrine y mène.
💡

Écran blanc après déploiement ? 9 fois sur 10, c'est le baseUrl mal réglé ou le .nojekyll manquant (ce dernier est géré par le workflow).
