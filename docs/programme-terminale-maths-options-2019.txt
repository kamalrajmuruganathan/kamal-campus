############ MATHÉMATIQUES EXPERTES ############

=== Nombres complexes — point de vue algébrique ===
Contenus : ensemble ℂ, partie réelle et imaginaire, opérations ; conjugaison et
propriétés ; inverse d'un complexe non nul ; formule du binôme dans ℂ ; équations
du second degré à coefficients réels.
Capacités : effectuer des calculs algébriques ; résoudre az = b ; résoudre une
équation faisant intervenir z et z̄ ; résoudre une équation du second degré à
coefficients réels dans ℂ.

=== Nombres complexes — point de vue géométrique ===
Contenus : image et affixe (point, vecteur) ; module (|z|² = z·z̄), module d'un
produit/quotient/puissance ; ensemble 𝕌 des complexes de module 1 ; arguments et
forme trigonométrique ; exponentielle imaginaire e^{iθ}, forme exponentielle ;
formules d'Euler et de Moivre.
Capacités : déterminer module et arguments ; passer de la forme algébrique à la
forme trigonométrique/exponentielle et inversement ; interpréter géométriquement
|z−z'| et arg ; utiliser Euler et Moivre.

=== Arithmétique (divisibilité et congruences) ===
Contenus : divisibilité dans ℤ ; division euclidienne ; congruences dans ℤ et
compatibilité avec les opérations ; PGCD, algorithme d'Euclide ; entiers premiers
entre eux ; théorèmes de Bézout et de Gauss ; nombres premiers, infinitude,
décomposition en facteurs premiers ; petit théorème de Fermat.
Capacités : déterminer diviseurs et PGCD ; résoudre ax ≡ b [n] ; inverse de a
modulo n ; établir des tests de divisibilité ; résoudre des équations diophantiennes simples.

=== Graphes et matrices ===
Contenus : graphe (sommets, arêtes, ordre, degré), chaîne, longueur, connexité ;
matrices (carrée, ligne, colonne), opérations, inverse, puissances ; matrice
d'adjacence ; suites Uₙ₊₁ = A·Uₙ + C ; chaîne de Markov à 2 ou 3 états, matrice de
transition, distribution invariante.
Capacités : modéliser par un graphe ou une matrice ; calculer inverse et puissances
d'une matrice ; compter les chemins de longueur donnée ; étudier une chaîne de Markov.


############ MATHÉMATIQUES COMPLÉMENTAIRES ############
(Enseignement plus léger que la spécialité, organisé autour de thèmes d'étude.
Chapitres retenus par contenu mathématique.)

=== Continuité et théorème des valeurs intermédiaires ===
Contenus : continuité d'une fonction ; théorème des valeurs intermédiaires ; cas
strictement monotone (existence et unicité d'une solution de f(x)=k).
Capacités : justifier l'existence/l'unicité d'une solution ; l'encadrer.

=== Dérivation, variations et convexité ===
Contenus : dérivée, sens de variation, extremums ; fonctions de référence ;
convexité, point d'inflexion (lecture graphique).
Capacités : étudier les variations ; exploiter la convexité pour des inégalités ou
l'allure d'une courbe.

=== Suites et modèles d'évolution ===
Contenus : suites récurrentes ; suites géométriques ; suites arithmético-
géométriques ; limites de suites.
Capacités : étudier le comportement d'une suite ; modéliser une évolution ;
déterminer une limite.

=== Fonctions logarithme et exponentielle ===
Contenus : fonction exponentielle (rappels) ; fonction logarithme népérien,
propriétés algébriques, dérivée, variations, limites ; croissances comparées.
Capacités : résoudre équations et inéquations ; utiliser log/exp dans un problème.

=== Primitives et équations différentielles ===
Contenus : primitives des fonctions usuelles ; équation différentielle y' = a·y + b.
Capacités : déterminer des primitives ; résoudre y' = ay + b ; exploiter une
solution particulière.

=== Calcul intégral (calculs d'aires) ===
Contenus : intégrale d'une fonction continue positive (aire) ; lien primitive-
intégrale ; linéarité, positivité ; valeur moyenne.
Capacités : calculer une intégrale à l'aide d'une primitive ; une aire ; une valeur moyenne.

=== Probabilités : conditionnelles, Bayes et loi binomiale ===
Contenus : probabilités conditionnelles, formule des probabilités totales, formule
de Bayes ; épreuve et loi de Bernoulli ; schéma de Bernoulli, loi binomiale.
Capacités : représenter par un arbre ; appliquer Bayes ; calculer des probabilités
avec la loi binomiale ; espérance de la loi binomiale.

=== Lois à densité : temps d'attente ===
Contenus : lois à densité ; loi uniforme ; loi exponentielle ; propriété d'absence
de mémoire ; espérance.
Capacités : calculer une probabilité et une espérance pour une loi uniforme ou
exponentielle ; modéliser un temps d'attente.
