Aide-mémoire — mathématiques Première et Terminale technologiques. L'essentiel, par thème.

## Dérivation (Première)

- Nombre dérivé : $\boxed{f'(a)=\lim\limits_{h\to 0}\dfrac{f(a+h)-f(a)}{h}}$.
- Tangente en $a$ : $\boxed{y=f'(a)(x-a)+f(a)}$.
- Produit : $\boxed{(uv)'=u'v+uv'}$ ; quotient : $\boxed{\left(\tfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^2}}$.
- Signe de $f'$ = sens de variation de $f$ ; extremum où $f'$ s'annule en changeant de signe.

## Fonctions de la variable réelle (Première)

- Taux de variation : $\boxed{\tau=\dfrac{f(b)-f(a)}{b-a}}$.
- Second degré $f(x)=ax^2+bx+c$ : sommet $S(\alpha;f(\alpha))$ avec $\boxed{\alpha=-\dfrac{b}{2a}}$.

## Suites (Première + Terminale)

- Arithmétique : $\boxed{u_{n+1}=u_n+r}$, $\boxed{u_n=u_0+nr}$.
- Géométrique : $\boxed{u_{n+1}=q\,u_n}$ ($q\neq 0$), $\boxed{u_n=u_0\,q^n}$.
- Lien pourcentage : $\boxed{q=1+\dfrac{t}{100}}$.
- Trois termes consécutifs : arithmétique $\boxed{2b=a+c}$, géométrique $\boxed{b^2=ac}$.
- Moyennes de deux nombres : arithmétique $\boxed{m=\dfrac{a+b}{2}}$, géométrique $\boxed{g=\sqrt{ab}}$.
- Somme arithmétique : $\boxed{S=\text{nb de termes}\times\dfrac{\text{premier}+\text{dernier}}{2}}$.
- Somme géométrique : $\boxed{S=u_0\times\dfrac{1-q^n}{1-q}}$.

## Fonction inverse (Terminale)

- $\boxed{f(x)=\dfrac{1}{x}}$, définie sur $]-\infty;0[\cup]0;+\infty[$ ; asymptotes : axes $y=0$ et $x=0$.
- $\boxed{f'(x)=-\dfrac{1}{x^2}}$ ; décroissante sur chacun des deux intervalles.
- Pour $f(x)=ax+b+\dfrac{c}{x}$ : $\boxed{f'(x)=a-\dfrac{c}{x^2}}$.

## Fonctions exponentielles $x\mapsto a^x$ (Terminale)

- Définie pour $a>0$ ; $\boxed{a^0=1, \quad a^1=a}$.
- $\boxed{a>1 : \text{croissante} \qquad 0<a<1 : \text{décroissante}}$.
- $\boxed{a^{x+y}=a^x a^y \qquad a^{x-y}=\dfrac{a^x}{a^y} \qquad a^{nx}=(a^x)^n}$
- Taux moyen équivalent à $n$ évolutions : $\boxed{c_m=C^{1/n}, \ \ t_m=c_m-1}$.
- Modèle : $\boxed{f(x)=k\times a^x}$ avec $k$ = valeur initiale, $a=1+\tfrac{t}{100}$.

## Logarithme décimal (Terminale)

- $\boxed{\log b \text{ est la solution de } 10^x=b}$, soit $10^{\log b}=b$.
- $\boxed{\log 1=0, \quad \log 10=1, \quad \log(10^n)=n}$ ; croissante sur $]0;+\infty[$.
- $\boxed{\log(ab)=\log a+\log b \qquad \log(a^n)=n\log a}$
- Résoudre $a^x=b$ : $\boxed{x=\dfrac{\log b}{\log a}}$.

## Statistiques à deux variables (Première + Terminale)

- Point moyen : $\boxed{G(\bar x;\bar y)}$ ; ajustement affine $y=ax+b$ passe par $G$.
- Changement de variable (nuage courbe) : $\boxed{(x;y)\xrightarrow{z=f(y)}(x;z)\ \text{rectiligne}\xrightarrow{\text{moindres carrés}} z=ax+b \xrightarrow{\text{retour}} y}$.
- $z=\log y \Rightarrow \boxed{y=10^{ax+b}}$ ; $z=\tfrac{1}{y}\Rightarrow \boxed{y=\tfrac{1}{ax+b}}$ ; $z=y^2 \Rightarrow \boxed{y=\sqrt{ax+b}}$.

## Probabilités conditionnelles (Terminale)

- $\boxed{P_A(B)=\dfrac{P(A\cap B)}{P(A)}}$ ; produit : $\boxed{P(A\cap B)=P(A)\,P_A(B)}$.
- Somme des branches d'un même nœud $=1$.
- Probabilités totales : $\boxed{P(B)=\sum_i P(A_i)\,P_{A_i}(B)}$.
- Remonter l'arbre : $\boxed{P_B(A)=\dfrac{P(A\cap B)}{P(B)}}$.

## Variables aléatoires et loi binomiale (Première + Terminale)

- Loi : $\boxed{\sum p_i=1}$ ; espérance : $\boxed{E(X)=x_1p_1+\cdots+x_np_n}$ ; jeu équitable $\iff E(X)=0$.
- Bernoulli : $\boxed{E(X)=p}$.
- Coefficients binomiaux (Pascal) : $\boxed{\dbinom{n}{k}=\dbinom{n-1}{k-1}+\dbinom{n-1}{k}}$.
- Binomiale $B(n,p)$ : $\boxed{P(X=k)=\dbinom{n}{k}p^k(1-p)^{n-k}}$ ; $\boxed{E(X)=np}$.

## Logique et ensembles (Terminale)

- $\boxed{A\subset E}$ ; $\boxed{A\cap B : \text{« et »} \quad A\cup B : \text{« ou »} \quad \bar A : \text{« non »}}$.
- Produit cartésien : $\boxed{A\times B=\{(a;b),\ a\in A, b\in B\}}$, $\boxed{n\times p}$ couples.
- $\boxed{\text{Un seul contre-exemple suffit à réfuter une proposition}}$.
- $\boxed{\text{Une proposition peut être vraie et sa réciproque fausse}}$.

## Géométrie STD2A : coniques et perspective (Terminale)

- Sections planes d'un cône : cercle, ellipse, parabole, hyperbole.
- Tangente au cercle de centre $O$ en $M$ : perpendiculaire au rayon $[OM]$.
- Perspective centrale : un faisceau de parallèles (non frontales) devient des droites concourant en un point de fuite ; $\boxed{r=d\times\tan\alpha}$.

## Algorithmique et programmation (Python, Terminale)

- Affectation : `a = b` signifie « $a$ reçoit la valeur de $b$ » (pas une égalité).
- Fonction : `def nom(arguments): ... return resultat`.
- Filtrer une liste : liste vide $\to$ parcours $\to$ `if` condition $\to$ `append`.
