Les **homophones** se prononcent pareil mais s'écrivent différemment. Un test simple pour chacun.

## a / à
- **a** = verbe *avoir* (remplaçable par *avait*). *Il **a** faim → il **avait** faim.*
- **à** = préposition. *Je vais **à** Paris.*

## et / est
- **et** = conjonction (= *et puis*). *Paul **et** Marie.*
- **est** = verbe *être* (= *était*). *Il **est** grand → il **était** grand.*

## on / ont
- **on** = pronom (= *il*). ***On** part.*
- **ont** = verbe *avoir* (= *avaient*). *Ils **ont** faim → ils **avaient** faim.*

## son / sont
- **son** = déterminant possessif (= *mon*). ***Son** vélo → **mon** vélo.*
- **sont** = verbe *être* (= *étaient*). *Ils **sont** là → ils **étaient** là.*

## ce / se
- **ce** = déterminant/pronom démonstratif (devant un nom : *ce livre*, ou *ce qui, ce que*).
- **se** = pronom réfléchi (devant un verbe : *il **se** lave*).

## ces / ses
- **ces** = démonstratif pluriel (= *ceux-là*). ***Ces** enfants.*
- **ses** = possessif pluriel (= *les siens*). ***Ses** parents.*

## ou / où
- **ou** = choix (= *ou bien*). *Café **ou** thé ?*
- **où** = lieu ou temps. *Le pays **où** je vis.*

## la / là / l'a
- **la** = déterminant/pronom (*la porte*, *je **la** vois*).
- **là** = adverbe de lieu (*viens **là***).
- **l'a** = *le/la* + *a* (verbe avoir) : *il **l'a** vu*.

## ce / c'est / s'est / ses / ces (récap difficile)
- **c'est** = *cela est* (*c'est beau*).
- **s'est** = pronom *se* + *est*, devant un participe (*il **s'est** levé*).

## À retenir
- Le meilleur réflexe : **remplacer** par un mot du même type (*avait, était, avaient, mon…*). Si la phrase reste correcte, on tient la bonne graphie.
- Les formes verbales (**a, est, ont, sont**) se remplacent par le **même verbe à l'imparfait**.
