L'essentiel de la conjugaison espagnole : terminaisons régulières, verbes irréguliers très fréquents, et emplois de *ser* / *estar*. Pronoms : **yo, tú, él/ella/usted, nosotros, vosotros, ellos/ellas/ustedes**.

## Présent de l'indicatif — verbes réguliers

| | -AR (hablar) | -ER (comer) | -IR (vivir) |
|---|---|---|---|
| yo | habl**o** | com**o** | viv**o** |
| tú | habl**as** | com**es** | viv**es** |
| él/ella | habl**a** | com**e** | viv**e** |
| nosotros | habl**amos** | com**emos** | viv**imos** |
| vosotros | habl**áis** | com**éis** | viv**ís** |
| ellos | habl**an** | com**en** | viv**en** |

## Présents irréguliers très fréquents

| | ser | estar | tener | ir | hacer | poder |
|---|---|---|---|---|---|---|
| yo | soy | estoy | tengo | voy | hago | puedo |
| tú | eres | estás | tienes | vas | haces | puedes |
| él/ella | es | está | tiene | va | hace | puede |
| nosotros | somos | estamos | tenemos | vamos | hacemos | podemos |
| vosotros | sois | estáis | tenéis | vais | hacéis | podéis |
| ellos | son | están | tienen | van | hacen | pueden |

**Diphtongues** (changement de radical) : e→ie (*querer → quiero*), o→ue (*poder → puedo*, *dormir → duermo*), e→i (*pedir → pido*). Les formes *nosotros* / *vosotros* ne diphtonguent pas.

## Pretérito indefinido (passé simple) — réguliers

| | -AR (hablar) | -ER/-IR (comer/vivir) |
|---|---|---|
| yo | hablé | comí |
| tú | hablaste | comiste |
| él/ella | habló | comió |
| nosotros | hablamos | comimos |
| vosotros | hablasteis | comisteis |
| ellos | hablaron | comieron |

**Irréguliers courants :** ser/ir → *fui, fuiste, fue, fuimos, fuisteis, fueron* ; tener → *tuve…* ; hacer → *hice, hiciste, hizo…* ; estar → *estuve…* ; poder → *pude…* ; decir → *dije…*

## Imperfecto (imparfait)

-AR : *hablaba, hablabas, hablaba, hablábamos, hablabais, hablaban* — -ER/-IR : *comía, comías…* Trois irréguliers seulement : **ser** (era…), **ir** (iba…), **ver** (veía…).

## Ser ou estar ?

- **ser** : identité, origine, nationalité, profession, heure, description permanente. *Soy francés. Son las tres.*
- **estar** : localisation, état passager, *estar + gerundio*. *Estoy en casa. Está cansado. Estoy comiendo.*

## À retenir

- Le sujet est souvent omis (la terminaison suffit) : *hablo* = « je parle ».
- *gustar* se construit à l'envers : **me gusta** el café, **me gustan** los libros.
- Passé récent : *acabar de + infinitif*. Futur proche : *ir a + infinitif*.
