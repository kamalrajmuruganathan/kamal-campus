Aide-mémoire — physique-chimie pour la santé, série ST2S (Première + Terminale). L'essentiel par thème : formules encadrées, unités, valeurs de référence. Surveille toujours les conversions d'unités : c'est là que se gagnent les points.

## Ondes, rayonnements et son

- Onde électromagnétique dans le vide : $\boxed{\lambda = \dfrac{c}{f}}$, $c = 3{,}0\times10^{8}$ m·s⁻¹ ($\lambda$ en m, $f$ en Hz).
- Loi de Wien (corps chaud) : $\boxed{\lambda_{max}\times T = 2{,}9\times10^{-3}\ \text{m·K}}$ ; conversion $\boxed{T(\text{K}) = \theta(°\text{C}) + 273}$.
- Période / fréquence : $\boxed{f = \dfrac{1}{T}}$ (Hz ↔ s).
- Domaine audible : $\boxed{20\ \text{Hz} \le f \le 20\,000\ \text{Hz} = 20\ \text{kHz}}$.
- Niveau d'intensité sonore : $\boxed{L = 10\log\!\left(\dfrac{I}{I_0}\right)}$, $I_0 = 10^{-12}$ W·m⁻² ($L$ en dB) ; inverse $\boxed{I = I_0\times10^{\,L/10}}$.

## Optique : vision et lentilles

- Vergence : $\boxed{V = \dfrac{1}{f'}}$ ($V$ en dioptries δ, $f'$ en m). Convergente $f'>0$, divergente $f'<0$.
- Lentilles accolées : $\boxed{V = V_1 + V_2}$.
- Grandissement : $\boxed{\gamma = \dfrac{\overline{A'B'}}{\overline{AB}}}$ (sans unité ; signe = sens de l'image, $|\gamma|$ = agrandissement).

## Cinématique et sécurité routière

- Conversion vitesse : $\boxed{v\,(\text{m·s}^{-1}) = \dfrac{v\,(\text{km/h})}{3{,}6}}$ ; inverse $\times 3{,}6$.
- Énergie cinétique : $\boxed{E_c = \tfrac{1}{2}\,m\,v^{2}}$ ($E_c$ en J, $m$ en kg, $v$ en m·s⁻¹). Vitesse ×2 ⟹ $E_c$ ×4.
- Distance d'arrêt : $\boxed{d_a = d_r + d_f}$ (réaction + freinage), distance de réaction $\boxed{d_r = v\times t_r}$.

## Électricité et risques

- Tension alternative sinusoïdale : $\boxed{f = \dfrac{1}{T}}$ ; valeur efficace $\boxed{U = \dfrac{U_{max}}{\sqrt{2}}}$ (le multimètre AC lit l'efficace).
- Seuils de l'intensité traversant le corps (alternatif) : $\approx 1$ mA perception ; $\approx 10$ mA tétanisation ; $\approx 30$ mA asphyxie (seuil des différentiels) ; $\ge 100$ mA fibrillation cardiaque.

## Quantité de matière, concentrations, dilution

- Quantité de matière : $\boxed{n = \dfrac{m}{M}}$ ($n$ en mol, $m$ en g, $M$ en g·mol⁻¹).
- Concentration massique : $\boxed{C_m = \dfrac{m}{V}}$ (g·L⁻¹) ; molaire : $\boxed{C = \dfrac{n}{V}}$ (mol·L⁻¹).
- Lien : $\boxed{C = \dfrac{C_m}{M}} \iff C_m = C\times M$.
- Dilution (conservation de la matière) : $\boxed{C_1 V_1 = C_2 V_2}$ ; facteur $\boxed{F = \dfrac{C_1}{C_2} = \dfrac{V_2}{V_1}}$ ($F>1$).

## pH et acide-base

- pH : $\boxed{\mathrm{pH} = -\log\,[\mathrm{H_3O^+}]}$ ; inverse $\boxed{[\mathrm{H_3O^+}] = 10^{-\mathrm{pH}}}$ ($[\mathrm{H_3O^+}]$ en mol·L⁻¹).
- Échelle à 25 °C : pH < 7 acide, = 7 neutre, > 7 basique. **+1 en pH = ×10 moins de $\mathrm{H_3O^+}$**.
- Acide = donneur de $\mathrm{H^+}$, base = accepteur (Brønsted) ; couple $\mathrm{AH/A^-}$.
- Autoprotolyse de l'eau : $\boxed{2\,\mathrm{H_2O} \rightleftharpoons \mathrm{H_3O^+} + \mathrm{HO^-}}$ ; produit ionique $\boxed{K_e = [\mathrm{H_3O^+}][\mathrm{HO^-}] = 1{,}0\times10^{-14}}$ (à 25 °C).

## Oxydoréduction

- $\boxed{\text{réducteur} = \text{donneur d'e}^- \quad|\quad \text{oxydant} = \text{accepteur d'e}^-}$.
- Demi-équation électronique : $\boxed{\text{Ox} + n\,e^- = \text{Red}}$ (équilibrer : éléments, puis O avec $\mathrm{H_2O}$, H avec $\mathrm{H^+}$, charges avec $e^-$).

## Chimie organique et biomolécules

- Règle de l'octet — nombre de liaisons : $\boxed{\text{H}:1 \quad \text{O}:2 \quad \text{N}:3 \quad \text{C}:4}$.
- Fonctions organiques :

| Fonction | Groupe | Formule |
|---|---|---|
| Alcool | hydroxyle | $\mathrm{R\!-\!OH}$ |
| Aldéhyde | carbonyle terminal | $\mathrm{R\!-\!CHO}$ |
| Cétone | carbonyle interne | $\mathrm{R\!-\!CO\!-\!R'}$ |
| Acide carboxylique | carboxyle | $\mathrm{R\!-\!COOH}$ |
| Amine | amino | $\mathrm{R\!-\!NH_2}$ |
| Ester | ester | $\mathrm{R\!-\!COO\!-\!R'}$ |
| Amide | amide | $\mathrm{R\!-\!CO\!-\!NH_2}$ |

- Isomères de constitution = même formule brute, enchaînement différent.
- Glucides : $\boxed{\text{oses} \to \text{diholosides} \to \text{polyosides}}$ ; simples = oses + diholosides, complexes = polyosides.
  - Hydrolyse de l'amidon : $\boxed{(\mathrm{C_6H_{10}O_5})_n + n\,\mathrm{H_2O} \to n\,\mathrm{C_6H_{12}O_6}}$.
  - Condensation : $\boxed{\mathrm{C_6H_{12}O_6 + C_6H_{12}O_6 \to C_{12}H_{22}O_{11} + H_2O}}$.
- Lipides : saturé = que des liaisons C–C simples, insaturé = au moins une C=C.
  - Estérification : $\boxed{\text{glycérol} + 3\ \text{acides gras} \to \text{triglycéride} + 3\,\mathrm{H_2O}}$.
- Acides aminés / protéines : liaison peptidique $\boxed{\mathrm{-COOH} + \mathrm{H_2N-} \to \mathrm{-CO\!-\!NH-} + \mathrm{H_2O}}$. Urée $\mathrm{CO(NH_2)_2}$.
- Eau : liaison hydrogène $\mathrm{O\!-\!H^{\delta+}\cdots{}^{\delta-}O}$ ; règle de solubilité $\boxed{\text{polaire dissout polaire, apolaire dissout apolaire}}$.

## Énergie et alimentation

- Conversion : $\boxed{1\ \mathrm{cal} = 4{,}18\ \mathrm{J} \quad|\quad 1\ \mathrm{kcal} = 4180\ \mathrm{J}}$.
- Dépense énergétique : $\boxed{\text{DEJ} = \text{métabolisme de base} + \text{dépense liée à l'activité}}$.
- Valeurs énergétiques : $\boxed{\text{glucides} \approx 17 \quad \text{lipides} \approx 38 \quad \text{protides} \approx 17}$ (kJ·g⁻¹).
- Conversion biologique : $\text{énergie chimique} \to \text{énergie mécanique} + \text{chaleur}$.

## Fluides et pression sanguine

- Débit volumique : $\boxed{D = \dfrac{V}{\Delta t}}$ ; aussi $\boxed{D = v\times S}$ (v vitesse, S section).
- Débit cardiaque : $\boxed{DC = f_C \times VES}$ (fréquence cardiaque × volume d'éjection systolique).
- Pression : $\boxed{p = \dfrac{F}{S}}$ (Pa = N·m⁻²). Conversions $\boxed{1\ \text{cmHg} = 10\ \text{mmHg}}$, $\boxed{1\ \text{mmHg} \approx 133\ \text{Pa}}$.
- Pression hydrostatique (colonne de fluide) : $\boxed{\Delta p = \rho\,g\,h}$ ($\rho$ en kg·m⁻³, $g\approx 9{,}81$ N·kg⁻¹, $h$ en m).
