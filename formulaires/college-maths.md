Synthèse du cycle 4 (5e-4e-3e), orientée brevet. Que l'essentiel à savoir par cœur.

## Nombres et arithmétique

- Division euclidienne : $\boxed{a = b \times q + r \quad (0 \leqslant r < b)}$
- $b$ divise $a \iff$ il existe un entier $q$ tel que $\boxed{a = b \times q}$
- Divisible par $3$ (resp. $9$) $\iff$ la somme des chiffres est multiple de $3$ (resp. $9$).
- Décomposition en facteurs premiers : ex. $60 = \boxed{2^2 \times 3 \times 5}$.
- Fraction irréductible : le seul diviseur commun au numérateur et au dénominateur est $1$.
- Signes : $\boxed{\text{identiques} \Rightarrow +\qquad \text{contraires} \Rightarrow -}$ (produit et quotient).

## Fractions

$$\boxed{\frac{a}{b} = \frac{a\times k}{b\times k}} \qquad \boxed{\frac{a}{b}\times\frac{c}{d} = \frac{ac}{bd}} \qquad \boxed{\frac{a}{b}\div\frac{c}{d} = \frac{a}{b}\times\frac{d}{c}}$$

- Inverse de $\dfrac{a}{b}$ : $\dfrac{b}{a}$. Opposé de $\dfrac{a}{b}$ : $-\dfrac{a}{b}$.
- « $\dfrac{a}{b}$ de $N$ » $= \dfrac{a}{b}\times N$.

## Puissances

$$\boxed{a^m \times a^n = a^{m+n}} \qquad \boxed{\frac{a^m}{a^n} = a^{m-n}} \qquad \boxed{a^n\times b^n = (ab)^n} \qquad \boxed{\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}}$$

$$\boxed{a^0 = 1} \qquad \boxed{a^{-n} = \frac{1}{a^n}} \qquad \boxed{10^{-n} = \frac{1}{10^n}} \qquad (a\neq 0)$$

- Notation scientifique : $\boxed{a\times 10^n}$ avec $1 \leqslant a < 10$.

## Calcul littéral et identités remarquables

$$\boxed{k(a+b) = ka+kb} \qquad \boxed{(a+b)(c+d) = ac+ad+bc+bd}$$

$$\boxed{(a+b)^2 = a^2 + 2ab + b^2} \qquad \boxed{(a-b)^2 = a^2 - 2ab + b^2} \qquad \boxed{(a-b)(a+b) = a^2 - b^2}$$

- Équation-produit : $\boxed{A\times B = 0 \iff A=0 \text{ ou } B=0}$.
- Pair $=2k$, impair $=2k+1$.
- Inéquation : multiplier ou diviser par un **négatif inverse** le sens de l'inégalité.

## Racine carrée

- $\sqrt{a}$ est le nombre **positif** tel que $(\sqrt{a})^2 = a$ ; existe seulement si $a\geqslant 0$.
- $\boxed{(\sqrt{a})^2 = a} \qquad \sqrt{a^2}=a \quad(a\geqslant 0)$
- Équation : $\boxed{x^2 = a \iff x = \sqrt{a}\ \text{ou}\ x = -\sqrt{a}}$ (pour $a>0$).
- $\sqrt{\ }$ désigne **un seul** nombre : ne jamais écrire $\sqrt{25} = \pm 5$.

## Géométrie : Pythagore, Thalès, trigonométrie

- **Pythagore** (triangle rectangle en A) : $\boxed{BC^2 = AB^2 + AC^2}$ ; réciproque pour prouver l'angle droit.
- **Thalès** (droites parallèles) : $\boxed{\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}}$
- **Droites des milieux** : $\boxed{IJ = \dfrac{BC}{2}}$ (parallèle au 3e côté).
- **Trigonométrie** — SOH-CAH-TOA :
$$\boxed{\cos\widehat{B} = \frac{\text{adjacent}}{\text{hypoténuse}} \qquad \sin\widehat{B} = \frac{\text{opposé}}{\text{hypoténuse}} \qquad \tan\widehat{B} = \frac{\text{opposé}}{\text{adjacent}}}$$
- Somme des angles d'un triangle : $\boxed{\widehat{A}+\widehat{B}+\widehat{C} = 180°}$.

## Aires et volumes

$$\mathcal{A}_{\text{disque}} = \boxed{\pi r^2} \qquad \mathcal{A}_{\text{parallélogramme}} = \text{base}\times\text{hauteur}$$

$$\boxed{V_{\text{pavé}} = L\ell h} \quad \boxed{V_{\text{prisme/cylindre}} = \mathcal{A}_{\text{base}}\times h} \quad \boxed{V_{\text{pyr./cône}} = \frac{\mathcal{A}_{\text{base}}\times h}{3}} \quad \boxed{V_{\text{boule}} = \frac{4}{3}\pi R^3}$$

- Conversions : $\boxed{1\text{ L} = 1\text{ dm}^3}$, $1\text{ mL}=1\text{ cm}^3$, $1\text{ m}^3 = 1000\text{ L}$ (×/÷ 1000 d'une unité de volume à la suivante).

## Proportionnalité

- Quatrième proportionnelle : $\dfrac{a}{b} = \dfrac{x}{c} \Rightarrow \boxed{x = \dfrac{a\times c}{b}}$.
- $\boxed{t\% \text{ de } N = \dfrac{t}{100}\times N}$
- Coefficient multiplicateur : augmentation $\boxed{1+\dfrac{t}{100}}$, diminution $\boxed{1-\dfrac{t}{100}}$.
- Taux d'évolution : $\boxed{t = \dfrac{V_a - V_d}{V_d}\times 100}$.

## Fonctions

- Notation : $\boxed{f : x \longmapsto f(x)}$.
- Fonction linéaire : $\boxed{f(x) = ax}$ (représentation : droite par l'origine).
- Fonction affine : $\boxed{f(x) = ax+b}$ ; coefficient directeur $a = \dfrac{\text{variation des ordonnées}}{\text{variation des abscisses}}$.

## Statistiques

- Fréquence $= \dfrac{\text{effectif}}{\text{effectif total}}$ ; angle (secteur) $= \text{fréquence}\times 360°$.
- $\boxed{\text{moyenne} = \dfrac{\text{somme des }(\text{valeur}\times\text{effectif})}{\text{effectif total}}}$
- **Médiane** : valeur qui partage la série rangée en deux moitiés. Étendue $= \max - \min$.

## Probabilités

$$\boxed{0 \leqslant P(A) \leqslant 1} \qquad \boxed{P(A) = \frac{\text{issues favorables}}{\text{issues possibles}}}$$

$$\boxed{P(\overline{A}) = 1 - P(A)} \qquad \boxed{P(A\cup B) + P(A\cap B) = P(A) + P(B)}$$

- La somme des probabilités de toutes les issues vaut $1$.

## Transformations et vecteurs

- Symétrie axiale : $(d)$ médiatrice de $[MM']$. Symétrie centrale : $O$ milieu de $[MM']$.
- Translation : même direction, même sens, même longueur ; l'image d'une droite est une droite parallèle.
- $\boxed{\overrightarrow{AB} = \overrightarrow{CD} \iff ABDC \text{ est un parallélogramme}}$
- $\boxed{\overrightarrow{BA} = -\overrightarrow{AB}} \qquad \boxed{\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}}$ (relation de Chasles)

## Repérage

- Sur une droite : $A(x)$. Dans le plan : $\boxed{A(x\,;y)}$ (abscisse ; ordonnée).
